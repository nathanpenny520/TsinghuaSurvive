两者冲突时（比如上游写"可用"、仓库其实已经归档）**以更保守的为准，并把冲突写在卡片上**。
核对日期（2026-10-03）显示在清单顶部 —— **它不是一个会自己保鲜的字段**，过期了就重跑一遍。

## 用之前的四条底线

这不是吓唬人：这些工具里的大多数确实好用，但**它们要的东西和校内系统一样多**。

1. **看清它要什么权限，再决定装不装。**
   油猴脚本和浏览器扩展能读你打开的页面内容 —— 包括成绩单、课表、选课操作。
   App 要你的账号密码。**能用官方入口就先别用第三方**；一定要用，去项目页看一眼源码和 Issue，
   比看别人推荐更有用。
2. **别把密码写进命令行和脚本。**
   进程列表、shell history、同步到公开仓库的配置文件，都是密码泄漏的常见途径。
   优先选支持令牌或二次验证的工具，配置文件永远不要提交到公开仓库。
3. **用脚本代替你操作课程相关系统，可能直接违反规定。**
   自动刷视频、刷时长、批量提交这类"省事"脚本，属于[学术规范的边界](/academics/academic-integrity/)里说的问题：
   **被发现不是"用了工具"，而是学术不端。** 省下的那几个小时不值这个代价。
4. **看到 "整合版 / 破解版 / 免登录版"，一律不用。**
   来源不明的安装包是这类工具里最危险的一种，因为它同时要你的账号和你的设备。

## 我们特意不收录的几类

- **教参平台、文泉学堂的"批量下载器"**：图书馆与出版社的授权是"在线浏览"，批量导出会超出授权范围，
  构成侵权风险。缺书可以按图书馆页面上的方式申请扫描，那是正规路径。
- **绕开认证、流量计费或端口限制的做法**：见[校园网进阶](/campus/network-advanced/)最后一节，边界一样。
- **把校园网账号托管给第三方"代认证"的服务**：等于把你的账号交给陌生人，账还算在你头上。
- **公开的 PT 站与影视资源站**：与"生存指南"无关，且风险由你承担。

## 打不开链接时

这一页的工具**大多托管在 GitHub**。站内 2026-09-30 的实测结论是校园网里 `github.com` 网页端打不开，
但 **2026-10-03 在校园网内复测，`github.com` 连续 5 次都返回 200**（详见[校内常用链接](/guides/links/#校园网里打不开的东西)）。
所以卡片上的「需代理」要这样读：**打不开的时候挂代理**，而不是"必须挂代理才能访问"。

- 只是要看说明文档 → 打不开就挂代理，或者等出了校园网再看；
- 要拿代码 → `git clone` 走 SSH 一直很稳（实测），比网页端可靠；
- 油猴脚本 → greasyfork 在校园网内不稳定（实测超时）。thuservices 仓库的 `misc/` 目录里有两份
  **油猴脚本原件**（选课冲突标记、GPA 计算器）可以救急；
  但**不要**顺手把那个目录里的 Python 脚本也用了 —— 它们把密码当命令行参数传，同机其他用户
  从进程列表里就能看到（这正是上面"底线 2"说的那类做法）。
- 第三方工具不是学校官方产物，装之前先看一眼项目的 Issue 与权限说明。

## 数据在哪、怎么更新

工具清单在 `src/data/tools.ts`，加一条记录就行：名称、地址、干什么、平台、维护状态、校内可达性。
**维护状态不要凭印象填「活跃」**：先抄上游项目自己写的，再对一遍 GitHub 仓库的
`archived` 与最近一次提交（脚本没法在这一页自动跑，所以页面顶部会显示这次核对的日期）。
这一个字会被别人当成"可以放心用"。

上游清单是社区维护的 [thu.services](https://thu.services/)（thuservices）的《一些脚本和工具》，
比这一页全得多；我们只挑了对在校生日常有用的部分，并补上可达性与边界。

## 使用约定

:::caution[下载前请知悉]
1. **我们不对文件内容做担保**。下载后请自行判断是否适用于你的院系和年份。
2. **链接可能失效**。网盘会清理、会限速，这是常态。
3. **上传前请自查隐私**。任何包含姓名、学号、成绩、联系方式的文件，请先删掉这些信息再上传。
4. **涉及官方表格的，请以学校发布的原始版本为准**。我们提供的模板只是"帮你少走弯路"的整理版本。
:::

## 手上有现成的资料？

非常欢迎。两种方式：

- 把文件传到你的网盘，然后把**链接和提取码**发到 [GitHub Issues](https://github.com/nathanpenny520/TsinghuaSurvive/issues/new)。
- 或者直接改 `src/data/resources.ts`，加一条记录后提 PR。

:::tip[推荐用长期稳定的网盘]
校内可访问、不容易限速、不强制登录的网盘体验最好。**如果链接需要填写一堆信息或者跳转多次，读者基本会放弃**——宁可不放。
:::

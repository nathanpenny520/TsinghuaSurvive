这一页分两类：

- **站内工具**（标着「站内」）——点开就能用：清单可以勾选、表格会自动算，数据存在你自己的浏览器里，不用下载任何文件；
- **网盘资料**——文件本体**不存放在本站**，只给第三方网盘的外链。链接失效是常态。

## 为什么有的东西做成了站内页面，而不是发个模板文件

因为发过，然后发现没人用：

| 做成站内页面 | 做成模板文件 |
| --- | --- |
| 清单能直接勾，下次打开还记得勾到哪 | 下载一个 PDF，打印出来，勾完不知道丢哪了 |
| 表格改了数字立刻看到结果 | 下载一个 xlsx，公式被人改坏也没人知道 |
| 永远不会「链接失效」 | 网盘清一次，链接就死了 |
| 手机能直接用 | 手机上打开 xlsx 是一团糟 |

所以**能站内做的就不发文件**。真需要文件（要打印、要交给老师）的时候再说。

## 使用约定

:::caution[下载网盘资料前请知悉]
1. **我们不对文件内容做担保**。下载后请自行判断是否适用于你的院系和年份。
2. **链接可能失效**。网盘会清理、会限速，这是常态。
3. **上传前请自查隐私**。任何包含姓名、学号、成绩、联系方式的文件，请先删掉这些信息再上传。
4. **涉及官方表格的，请以学校发布的原始版本为准**。我们提供的只是「帮你少走弯路」的整理版。
:::

## 暂时没有的几样东西，以及为什么

| 曾经打算做的 | 现在的结论 |
| --- | --- |
| 「选课时间线与决策表」 | **拆成两半处理**。「时间线」**不做**：时间节点每年变，站内放一份没人维护的表只会误导人，以教务通知为准。「决策」做成了[选课决策工作台](/academics/course-decision/)——它只整理你自己填的判断，不含任何日期或制度数字；决策顺序写在[各类课程怎么选](/academics/course-types/) |
| 「简历模板（docx）」 | **不做**。简历模板版本极多，求职季学校和院系通常会发官方版本；用来源不明的模板反而容易踩格式坑 |
| 「培养方案阅读笔记模板」 | **改做在线表格**：[学分缺口拆解表](/academics/credit-planner/) |
| 「新生报到物品清单（PDF）」 | **改做在线清单**：[报到第一周清单](/freshman/arrival-checklist/) |
| 「套磁信模板」 | **改成站内说明**：[怎么和老师、导师、辅导员沟通](/mindset/talking-to-advisors/)（结构比模板重要） |

## 手上有现成的资料？

非常欢迎。两种方式：

- 把文件传到你的网盘，然后把**链接和提取码**发到 [GitHub Issues](https://github.com/nathanpenny520/TsinghuaSurvive/issues/new)；
- 或者直接改 `src/data/resources.ts`，加一条记录后提 PR。
  站内条目写 `internal: true` + 站内路径（`/xxx/`）；网盘文件写完整链接 + `code`。

:::tip[收录标准]
- **校内可访问、不强制登录、不反复跳转**的网盘体验最好；要填一堆信息才能拿到的，宁可不放。
- **不收录**：含个人信息或内部系统的文件、需要绕开权限才能拿到的材料、付费内容。
- 体积大的（比如几十 MB 的课件包），建议放网盘而不是站内 —— 本站跑在 Cloudflare 上，流量和体积都有成本。
:::

课程资料从来不止一个来源。有人整理往年题，有人写复习提纲，有人把课件和作业答案放上云盘，
还有人专门做「上这门课需要会什么工具」的引导文档。**它们的强项、更新节奏和版权状态都不一样**，
所以这一页不做简单罗列，而是把每个库的分工和边界写清楚。

## 怎么把资料库拿到本地

在线翻页适合找单个文件；想批量用（比如 grep 自己的笔记），克隆到本地更快。几条实测经验：

```bash
# 校内 GitLab 镜像：校园网内最快，也不消耗国际流量
git clone https://git.tsinghua.edu.cn/pkuanonym/REKCARC-TSC-UHT.git

# 只看课程目录结构、不要历史（仓库里有大量 PDF，完整克隆很大）
git clone --depth 1 <镜像地址>
```

:::caution[仓库体积比想象中大]
课程资料库里 PDF、PPT 很多。实测**完整克隆计算机系课程攻略会占用约 10 GB 磁盘**。
如果只是想要某一两门课，优先用网页端进目录逐个下载，或者用 Git 的稀疏检出
（`git sparse-checkout`）只拉需要的目录 —— 先在校园网里试 `--depth 1`，别一上来就全量克隆。
:::

:::note[校园网里的现实]
GitHub 在国内**时通时不通**（网页端延迟高、有时超时；`git clone` 走 SSH 一般没问题）。
所以上面这些仓库优先找校内 GitLab 镜像；没有镜像的，打不开时挂代理再拉。
判断方法与实测见[校内常用链接](/guides/links/#校园网里打不开的东西)。
:::

## 找到资料之后

资料本身不会告诉你「怎么用才不算越界」。三条最短的规则：

1. **往年题看题型和难度，不背答案**：题目每年会变，押题通常会失望。
2. **作业答案对照思路，不复制**：看完自己重写，和粘贴是两件事。
3. **发现侵权内容走原库 Issue**：本站只做索引，不代为删除第三方内容。

完整版写在[作业、引用与 AI：学术规范的边界](/academics/academic-integrity/)，
以及上面那份「不能越过的那几条线」。

## 想补充一个新资料库

如果某个库确实值得推荐（公开、可访问、有持续维护），可以在
[怎么贡献一篇经验帖](/contribute/) 里提 Issue 或 PR。我们收录的标准是：

- **公开可访问**：不需要付费、不需要把账号借给别人；
- **说清来源**：谁维护的、内容许可是什么；
- **不违反红线**：不收录含内部材料、他人隐私、付费导流的资源。

数据都在 `src/data/archives.ts` 里，加一条记录就行。

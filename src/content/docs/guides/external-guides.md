同样是「学生自发维护的经验站」，**能不能引用、能不能改写，差别很大**。这一页把三个校外站分开讲清楚：它是什么、许可状况如何、我们怎么用它、哪些内容我们**碰都不碰**。

先给结论：

| 站点 | 内容 | 许可状况 | 本站的使用方式 |
| --- | --- | --- | --- |
| [thubook.help](https://thubook.help/thubook/newstudent.html) | 校内生活 + 学习百科 | **无任何许可证**（默认保留全部权利）；robots.txt 写明 `ai-train=no, use=reference` | **纯外链，一个字都不搬** |
| [feiyue.online](https://feiyue.online/main/about/) | 出国（境）深造申请指南 | **CC BY-NC 4.0**，可非商业转载 / 改编，需署名 | 可改写，但必须署名 + 回链 + 注明已改写 |
| [mathloveyou.github.io](https://mathloveyou.github.io/main/about/) | 数学公共基础课学习指南 | 无正式许可证，但作者明示「不删改作者信息即可转载」 | 可链接 + 署名引用，改写保留作者信息 |

:::note[事实来源与时效]
本页的判断来自 2026-10-06 对三个站点的调研（许可声明位置、robots.txt、页脚、更新记录）。
**三个站都是第三方站点，随时可能改许可、改内容或停止维护**，以你打开时页面上写明的为准。
:::

:::caution[三个站在大陆的可达性均未实测]
下文的「大陆可达性未实测」不是「打不开」的意思，也不是「能打开」的意思 —— 就是**没人测过**。
三个站分别托管在 Cloudflare 与 GitHub Pages 上，其中依赖 Google Fonts、jsdelivr 等外部资源的页面，
在大陆网络下容易缺样式或缺字体。**你自己点开一次，比这一页的判断准。**
:::

## thubook.help —— 校内生活百科，但我们只给链接

**是什么**：清华在校生共建的「校内生活 + 学习」百科，正文在 `/thubook/` 路径下。覆盖选课、GPA、转专业、辅修、SRT、奖学金、军训、交通、快递、校医院、宿舍、食堂、体育、社团、校历、校园卡、休学退学、出国、海外交换、勤工助学、志愿者等专题，另有校内生活设施、梗词典与专业简称等栏目。同一域名根下还有 **THU 选课社区 `/thucourse/`**（课程评分与点评，自称非官方）。

**谁维护的**：学生共建，托管在 GitHub 的 `THUxk/thubook` 仓库。**维护相对活跃**：仓库有 200 多次提交，最近一次推送在 2026-09-30，站内更新日志最新条目为 2026-09-14（该次更新主动删掉了若干已失效的条目）。

**许可状况与我们的使用方式**：**无任何许可证。**

- 仓库里**没有 LICENSE 文件**，页面上也**没有任何版权、CC 或转载字样**；
- 首页只说「已经开源在 THUxk/thubook」—— **开源仓库不等于授权内容**，把代码公开和允许转载文字是两件事；
- 它的 robots.txt 明确写着 `Content-Signal: search=yes, ai-train=no, use=reference`，并对多个 AI 爬虫设为 `Disallow`。

结论：**这是「默认保留全部权利」的状态 —— 本站对 thubook 只做纯外链，一个字都不搬：不摘编、不改写、不镜像。**

**时效性**：站内**多篇内容自认 2024 年未复核**。用的时候先看一眼该页有没有更新记录，涉及流程和数字的部分尤其要回官方渠道核对。

**大陆可达性**：**未实测**（站点托管在 Cloudflare，静态资源自托管）。

**最有用的几条外链**：

- [常用网站及 App](https://thubook.help/thubook/websites.html) —— 网址大全
- [选课](https://thubook.help/thubook/专题/xuanke.html)

- [更新日志](https://thubook.help/thubook/log.html) —— 判断某页内容新不新，先看这里

### 为什么我们不碰它的选课社区

thubook 同域下的 `/thucourse/` 收录了**真实教师姓名、课程评分与点评正文**。

这与本站「**不指名评价任何老师**」的边界**直接冲突**。所以本站对 `/thucourse/`：

- **不链接**；
- **不引用**其评分或点评；
- **不搬运**任何一条数据。

这条边界不是针对 thubook。理由在本站其它页面里写过：**往年评价的样本有偏差、课程会随开课老师和大纲变化、你和写评价的人目标函数不同** —— 详见[各类课程怎么选](/academics/course-types/)。一条点评对做决定的价值，远低于它带来的误伤。

同理，thubook 里的电话簿、群号这类**易变的个人信息**，本站也不镜像、不转载。

## feiyue.online —— 清华大学飞跃手册：许可允许改写，但要署名

**是什么**：清华出国（境）深造申请指南。由已出国深造的毕业生组成的编写委员会维护，页脚署 `Copyright © 2024 THU Feiyue Team`。结构分三块：

- **前言**：为什么出国、硕士还是博士、国家与地区选择、信息收集、中介还是 DIY、时间线；
- **准备**：GPA 与标化、经历、推荐信、选校定位、套磁、文书（CV / PS / SOP / RP 等）、网申、面试、学信网认证 / 家考 / APS 等具体手续；
- **录取及之后**：Funding、等待与比较、签证、前往、租房。

另有「案例」「文章阅读」「友链」（收录全国 20 多所高校的飞跃手册）等栏目。

**谁维护的**：THU Feiyue Team（已出国深造的毕业生编写委员会）。

**许可状况与我们的使用方式**：**CC BY-NC 4.0**，仓库 LICENSE、README 的声明段、站点页脚三处一致。也就是说：**允许非商业的转载与改编，条件是署名**。本站可以改写其中内容，但必须：

1. **署名**；
2. **回链原文**；
3. **注明已改写**。

署名行按这个格式写：

> 改写自《清华大学飞跃手册》（THU Feiyue Team，CC BY-NC 4.0）

:::caution[一个协议细节上的稳妥做法]
CC BY-NC 4.0 **没有 SA（相同方式共享）条款**，而本站整体使用 CC BY-NC-SA 声明。
把 NC 内容套进 BY-NC-SA 框架在解释上存在争议（这属于法律解释，未经权威确认）。
所以稳妥的做法是：**逐页标注来源与许可 + 注明已改写**，而不是笼统地把它并进本站的许可声明。
:::

**时效性**：正文半活跃 —— 仓库最新提交是 2026-08-25 的依赖升级，正文内容最后一次改动在 2025-03-03。**关联的「飞跃数据库」明显更活跃**（最近更新 2026-10-05，约 6 小时自动重建一次）。

**大陆可达性**：**未实测**。站点是 MkDocs Material + GitHub Pages，依赖 Google Fonts、jsdelivr 与 giscus 评论，**大陆环境下容易缺字体或评论组件**。

**最有用的几条外链**：

- [关于 / 声明](https://feiyue.online/main/about/) —— 许可声明的原文在这里，引用前自己看一眼
- [为什么出国](https://feiyue.online/preface/why/) —— 决策的第一步
- [时间线](https://feiyue.online/preface/timeline/) —— 什么时候该做什么
- [中介 or DIY](https://feiyue.online/preface/diy/) —— 最容易花冤枉钱的地方
- [准备总览](https://feiyue.online/prepare/) —— 从 GPA 到网申的全流程入口
- [飞跃数据库](https://database.feiyue.online/) —— 申请案例库

:::danger[「飞跃数据库」只链接，不搬运]
飞跃数据库收录的是**个人的 GPA、背景与录取结果**，属于个人信息。
本站**只给链接**，不抓取、不转载、不把它整理成本站的表格。
数据库自己声明：提交内容即同意以 CC BY-NC-SA 4.0 发布。即便如此，**是否公开某条案例是提交者个人的选择**，我们不做二次扩散。
:::

另外，该站「文章阅读」栏目整页是第三方微信公众号文章，**不可复制正文**；站内涉及留学中介的部分属于商业内容，引用时要去掉推广表述。

## mathloveyou.github.io —— 数学学习指南：已停更，只能当 2023 年的经验

**是什么**：面向大一**非数学类**学生的公共数学基础课学习指南，内容包括新生指南（综述 / 学习方略）、课程纵览（微积分 / 线性代数 / 概率论）、微积分葵花宝典、作者杂谈（答疑周记），另有读者须知、投稿邀请、反馈和加入、更新与维护等页面。

**内容类型**：学习方法论长文 + 课程学习路线（理论线、计算线、应用线）+ 教材与习题集推荐 + 答疑周记（数学语言、证明书写、放缩技巧）。**没有试题库、没有试卷下载、没有教师评价** —— 所以它在本站的三条红线面前是干净的。

**谁维护的**：一位数学专业本科生，页脚署 `Copyright © LagrangeKMnO4`。

**许可状况与我们的使用方式**：**没有正式许可证**（仓库的 LICENSE 与 README 均不可用），但作者在[读者须知](https://mathloveyou.github.io/main/about/)里明写：「**只要不删除、篡改作者信息，欢迎大家通过各种方式进行转载**。」

这是**署名即可转载的明示许可**，但没有提商用、改作和再许可。所以本站的做法是：

- 可以**链接**，并**署名引用**；
- 改写时必须**完整保留作者信息**（`LagrangeKMnO4`）并附原文链接；
- **不要把它并进本站的 CC BY-NC-SA 声明** —— 作者没有给出这个授权。

:::caution[必须标注：2023 年版、已停更]
该站**已停更**：站点最近修改时间为 2023-10-14，仓库只有一次提交（2023-08-28）。
所以引用时**必须标注「2023 年版，已停更」**——特别是涉及**选课与课程设置**的部分很可能已经变了。
它的学习方法论部分（怎么读数学书、怎么写证明）比课程信息部分更耐久，看的时候分开对待。
:::

还有一条要留意：可以引用它推荐的教材与习题集**名称**，但**不要提供这些书的 PDF 下载链接**（盗版）。

**大陆可达性**：**未实测**（GitHub Pages）。

## 本站对第三方内容的三条处理原则

三个站的许可差异很大，但本站的处理方式可以用三条说清：

1. **能改写的，署名 + 回链。** 有明确开放许可（如 CC BY-NC 4.0）或作者明示允许转载的，我们改写后会注明来源、注明已改写，并链回原文。**读者的第一手来源永远是原站。**
2. **没许可的，只链接。** 没有许可证、也没有转载声明的站点，默认保留全部权利。我们只提供链接，**不摘编、不改写、不镜像文件** —— 哪怕它看起来「只是学生自己整理的」。
3. **含个人评价与个人信息的，一律不碰。** 教师点评、个人申请案例（GPA、背景、录取结果）、电话与群号，都不进本站。**本站不做「评价具体老师」这件事，也不做个人信息的二次扩散。**

理由很简单：前两条是法律与礼貌问题，第三条是**对读者和你自己都更安全**的问题。一条过期的点评可能让你错过一门好课，一条被转发的个人信息可能给当事人带来实际麻烦。

这套原则同样适用于本站引用校内官方资料的场景 —— 例如[官方学习手册](/guides/study-skill-handbooks/)那一页，因为对方没有任何转载许可，所以整页只给链接。

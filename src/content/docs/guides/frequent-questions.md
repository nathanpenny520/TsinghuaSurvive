这一页回答的是**那些"问一句就想马上知道"的小事**——卡号在哪看、讨论室怎么约、快递几点关、半夜哪个门能进。答案来自**清小搭（学校官方 AI 助手）导出的常见问答**，本站做了筛选和改写。

清小搭本身是什么、现在谁能用、想在上面自己搭一个智能体该从哪下手，见[清小搭：学校自己的 AI 助手](/qingxiaoda/)。

:::caution[这一页是什么、不是什么]
- **不是官方文件**。清小搭的答案是 AI 生成的，很多条**没有日期、年份混杂**，制度细节也没有逐条对照官方文件核实过。
- **它只是线索，不是依据**。办事、交材料之前，仍以**官方通知、院系口径和现场公示**为准。
- **与站内其他页面冲突时，以本条为准**。站主已确认清小搭的口径更新；冲突条目的答案后面标了"与站内旧稿不一致，以本条为准"。
- 涉及**账号、密码、口令**的内容一律不收；过时的年份数字（招生人数、某年校历与军训安排等）也不收。
:::

:::note[事实来源与时效]
素材为清小搭导出的 197 条常见问答。经过筛除（过时年份、疫情期政策、需要登录内部系统的操作细节、商业推广、追不到来源的说法）后留下约 90 条，改写成本页。**未经官方文件逐条核对**，所以本页仍标为待核对。点名到具体品牌、金额与位置的条目，请当作"二次线索"看。
:::

## 校园卡与账号

| 问题 | 答案 |
| --- | --- |
| 怎么查看校园卡号 | 卡正面个人照片下方的号码就是卡号 |
| 有电子卡吗 | 有。微信小程序「清华校园卡」里就是电子卡；手机绑定校园卡后也能当电子学生证用 |
| 手机 NFC 能刷食堂吗 | 能。下载**北京一卡通**，点「高校服务」，按指引绑定学生卡 |
| 怎么解绑校园卡微信 | 搜「清华校园卡」小程序，首页有解绑入口；也可登录校园卡综合服务网站 <https://card.tsinghua.edu.cn>，或用自助终端 |
| 校园卡丢了怎么办 | 先在「清华校园卡」或校园卡综合服务网站挂失，再到**紫荆 C 楼 102** 或**六教 A 区零层**的自助机补卡 |
| 补卡要带什么证件 | 清小搭说**不需要证件，本人去即可**。补卡机在自助设备区，带校园卡号更稳妥 |
| 忘记带校园卡怎么出校 | 跟门卫说明，可以报学号或出示紫荆码 |
| 紫荆码在哪 | 微信小程序「清华紫荆」里绑定身份后即可显示 |
| 校医院只买药不挂号行不行 | 不行。药房凭医生处方发药，要先挂号、就诊 |
| 拍胸部 CT 去哪 | 校医院 |
| 清华邮箱要开二次验证吗 | 要绑手机号做二次认证，操作说明在信息化用户服务平台 <https://its.tsinghua.edu.cn/> |
| info（信息门户）能干什么 | 选课、查成绩与考试安排、看培养方案、约场馆、查公共通知。入口 <https://info.tsinghua.edu.cn>；也有第三方 App「THUinfo」可看课表 |

:::caution[待核对]
上面「补卡不需要证件」两条来自清小搭，与站内[新生报到清单](/freshman/arrival-checklist/)里"带证件办卡"的写法不完全一致。**带上学生证或身份证复印件去**，不会白跑。
:::

## 宿舍与后勤

| 问题 | 答案 |
| --- | --- |
| 紫荆公寓哪些楼是女寝 | 清小搭的答案是**紫 4、紫 5、紫 8、紫 9 为男女混住**。楼栋分配每年可能调整，以宿舍管理部门通知为准 |
| 宿舍可以留人过夜吗 | 不允许容留非本宿舍学生过夜 |
| 亲友来访要报备吗 | 要。走「清华大学信息服务系统 → 在线服务系统 → 亲友入校报备」；报备成功后会出现在「已办结的事项」里，绑定企业微信的还会收到办结通知 |
| 报备有名额限制吗 | 清小搭写的是**每天 5 人、每月 15 人**。名额口径会调，以报备页面当时显示为准 |
| 报备带小孩怎么办 | 8 岁以下不用预约，超过 8 岁要单独预约 |
| 报备进校当天能多次出入吗 | 可以。当天在开放时间内可多次刷证入校 |
| 亲友来访怎么知道报备成功没 | 在线服务系统的「正在办理中的事项」里，成功后会转到「已办结的事项」 |
| 卫生成绩有什么要求 | 见官方标准 <https://mp.weixin.qq.com/s/6LxfGH-X0eZZU32WzUFA7Q>。宿管检查不合格通常先提醒、再记入卫生成绩 |
| 校内哪里能修表 | 澜园超市西侧、照澜院日杂商店、照澜院西区集贸市场、家属区西区便民服务站、紫 11 四单元附近 |
| 校内哪里能贴膜 | 不少宿舍楼下有手机维修门面，家属区也有贴膜店 |
| 学校机房怎么用 | 主楼后的**中央计算机实验室**向全校开放，工作时间直接去、无需预约；文科图书馆的「从游空间」也提供免费电脑。各系馆机房另有规定 |
| 学生社区管理服务中心在哪 | C 楼 331，电话 010-62782461 |
| 学生活动中心（C 楼）几点关门 | 三楼公共区域晚上不关门，0:00 起不再允许进入，1:00 登记留宿人员信息 |
| 学校哪些公共空间 12 点后不关门 | 清小搭只列了 **C 楼**。深夜留在校内建筑里请遵守登记与门禁规定 |

:::caution[待核对]
C 楼三楼的**具体清场与登记时点**（0:00 停止进入、1:00 登记）来自清小搭，属于会调整的现场规定，以楼内公示为准。
:::

## 快递与出行

| 问题 | 答案 |
| --- | --- |
| 快递能直接送到宿舍楼吗 | 不能。学校设了**紫荆快递服务站**（紫荆 14 号楼后）和**南区快递服务站**（南区 23 号楼南），就近自取 |
| 紫荆片区快递站几点营业 | 荷清快递自提点 24 小时可取；学生区快递服务站 9:00–19:00 |
| 近邻宝放到几点 | 放快递柜的 24 小时可取，一般要求三天内取走；放在快递点的当天 19:00 前取 |
| 紫荆快递柜 9 号柜在哪 | 紫荆篮球场东侧，沿篮球场与网球场之间的路向东，在三角地足球场和紫荆雕塑园之间 |
| 怎么寄东西 | 就近邮局或快递代理点。校内邮局有 **C 楼中国邮政**和**照澜院中国邮政** |
| 外卖放哪 | 有些楼的外卖柜在单元口。点之前和外卖员确认具体位置 |
| 半夜能进哪个校门 | 西门、东侧门、南 9 楼出入口全天 24 小时；北门、西北门、东南门全天开放；东北门、油库门、南门、蓝旗营北门 6:00–24:00 |
| 各校门谁能走 | 东北门、油库门、东侧门、东南门、南 9 楼可通行机动车；北门、西北门、二校门、老龄大学出入口限步行与非机动车。**东侧门工作日 7:00–10:00 暂停机动车**，车辆走罗姆楼东侧 |
| 游泳馆出入口几点开 | 7:00–19:00 |
| 亲友车辆怎么进校 | 只能走允许机动车通行且支持"预约报备车辆"的门（油库门、东北门、南 9 楼等），由校内人员先报备 |

各门的开放时间与通行方式每年微调，出行前看保卫部当月通知；地铁对应关系见[校门与校园交通](/campus/getting-around/)。

## 网络与邮箱

| 问题 | 答案 |
| --- | --- |
| 校园网有 50GB 限制吗 | **没有超额收费**——学生账号不收超出套餐的流量费，可以理解为免费。看当月用量在校园网自助服务平台 <https://usereg.tsinghua.edu.cn> 的「账户信息」 |
| 本科生能用 SSL VPN 吗 | 能。有 Web 和客户端两种方式，说明见信息化技术中心 <https://www.itc.tsinghua.edu.cn/> 的 VPN 帮助页 |
| 邮箱怎么开 IMAP | 在邮箱界面左下角进设置 → 安全 → 客户端密码认证，生成专用密码用于 IMAP。**这个密码只用于客户端，不要外传** |
| IPv6 怎么配 | 校园网配置说明见 <https://its.tsinghua.edu.cn/>，按你所用系统选对应文档 |

校园网计费、WebVPN、镜像加速与连不上的排查顺序，已经写在[校园网、流量与镜像加速](/campus/network-and-traffic/)里，这里只给结论。

## 场馆与运动

| 问题 | 答案 |
| --- | --- |
| 场馆在哪预约 | **体育场馆预约系统** <https://www.sports.tsinghua.edu.cn/venue/#/home>，可约全部体育场馆。台球在「西体育馆」栏目，羽毛球也在同一系统 |
| 有室外羽毛球场吗 | 没有，羽毛球都在室内，在同一个场馆系统里约 |

| 射箭馆学生能用吗 | 能 |
| 哪里有健身房 | 综合体育馆、北体育馆内都有健身房。清小搭另提到校内一家商业健身房 |
| 北体健身中心怎么收费 | 清小搭写的是**年卡 1180 元、次卡 35 元**（与站内旧稿"需单独办会员卡"的写法不一致，以本条为准） |
| 哪里能滑雪滑冰 | 北体育馆地下二层有室内冰场和滑雪机，可提前预约，或参加周一至周五早上的免费场 |
| 冰场免费场怎么知道时间 | 免费场为**周一至周五 8:00–9:00**，没有周末免费场；具体场次看「清华大学体育部场馆中心」公众号公告 |
| 冰场怎么收费 | 清小搭写的是**学生 30 元**，免费提供冰鞋、护具和滑冰助手（不提供头盔）；散滑可直接到场按场次购票 |
| 办深水证要带什么 | 清小搭写的是**15 元现金和一张照片** |
| 游泳馆约了不去会怎样 | 会计违约，违约过多会被停止使用权限，具体次数由游泳馆酌情决定 |
| 场地晚上几点关 | 清小搭写的是**紫操 22:30 熄灯、西操 22:00 关门** |

:::caution[待核对]
本节的**金额（年卡、次卡、冰场票价、深水证工本费）、免费场时段与闭场时间**都来自清小搭，是会逐年调整的数字，用前请在预约系统或场馆现场确认。体育课与体测的一般逻辑见[运动与场馆](/campus/sports-and-venues/)。

**另外提醒**：清小搭原文给的场馆预约网址 `50.tsinghua.edu.cn` 实测**已经打不开**，本页换成了实测可用的体育部场馆系统。这类老网址在清小搭的答案里不止一处，**看到打不开的域名，用「体育部场馆中心」公众号或[校内常用链接](/guides/links/)里的入口**。
:::

## 图书馆与自习

| 问题 | 答案 |
| --- | --- |
| 图书馆有漫画书吗 | 没有仅供娱乐的漫画书；有漫画史、漫画研究、漫画技法类藏书，可在 <https://lib.tsinghua.edu.cn/> 检索 |
| 图书馆里的书能拍照吗 | 能，但不能用于商业用途 |
| 可以在手机上办签离吗 | 不行。手机只能预约和取消，**签离必须用校园卡在馆内机器上刷**；不到结束时间想走，直接刷卡签离即可 |
| 老馆要选座吗 | 不用，老馆无需选座 |
| 一次能约几个座位 | 一次只能约一个 |
| 研讨间能提前进场吗 | 不能，按预约时段使用 |
| 违约几次会被停权 | 清小搭写的是**违约 5 次停用图书馆 3 天**（与站内旧稿"累计 3 次停 30 天"不一致，以本条为准） |
| 单人研读间/研讨间怎么算违约 | 超过预约时刻 **20 分钟**未刷卡签到 → 该项预约自动取消并记违约；团体研讨间**到场不足 3 人**时房间可继续用，但组长记违约 1 次 |
| 图书馆各层有什么 | 以开架阅览区和阅览座位为主，分布见 <https://lib.tsinghua.edu.cn/kj/kjbj.htm> |
| 隔音舱（静音舱）都在哪 | 图书馆：北馆 4 个单人舱；西馆 1 单人 + 1 四人；文图 3 单人 + 3 四人；法图 5 单人 + 4 四人；美术 1 单人 + 2 四人。教学楼：三教 2 个单人舱，建华楼 14 个单人舱 + 1 个四人舱（无需预约可直接用） |
| 隔音舱要预约吗 | 单人舱可自由进入；除建华楼外，多人舱需到服务台预约登记。**别把它当自习室长时间占用** |
| 三教有静音舱吗 | 清小搭的答案自相矛盾：一处说三教有 2 个单人舱，另一处说三教不设。以楼内现场标识为准 |
| 10 点以后去哪自习 | 六教教室一般到 22:30；**C 楼 308 深夜自习室 23:00–次日 3:00**；李文正馆西侧下沉广场的**邺架轩 24 小时**；观畴园旁的清青咖啡夜间自习至 3:00。**长期熬夜不划算，别把通宵当常态** |
| 新清华学堂能自习吗 | 一、二层教室在没有被划为某班专用时，开放时间内可自习；地下一层教室无需预约可直接进 |
| 文图几点关 | 22:00 |
| 六教几点关 | 22:30 |

:::danger[这条冲突最要紧]
**图书馆违约的后果**：清小搭说"违约 5 次停用图书馆 3 天，3 次没事"，站内[吃饭、自习与出门](/campus/food-and-study/)写的是"累计 3 次暂停 30 天预约权"。按站主"冲突时以清小搭为准"的要求，本页采用清小搭的说法，并在此标明**与站内旧稿不一致**。
两种口径的差别会直接影响你敢不敢爽约，**建议核对图书馆读者指南后统一口径**。在统一之前，稳妥做法仍是：去不了就尽早取消。
:::

## 学习与考试

| 问题 | 答案 |
| --- | --- |
| 一学时多长 | 45 分钟 |
| 引体向上做几个及格 | 清小搭写的是**13 个及格、21 个满分**（男生体测项目，得分 = 个数 − 1）（与站内"不写达标线"的处理不一致，以本条为准） |
| 阳光长跑怎么算 | 大一要同时参加阳光锻炼和阳光长跑，在体育课里合计占 20 分；大二、大三只需完成 **24 次阳光长跑**，占 10 分。男生每次至少 3000 米。每学期初年级群或班级群会发具体安排 |
| 听讲座有学分吗 | 一般没有 |
| 英语四级要自带耳机吗 | 不用，考场统一广播 |
| 电子教材去哪找 | 图书馆的电子资源库，以及**清华大学教参服务平台**（专门提供课程教参的电子版） |
| 教学楼里能拍照吗 | 非上课时间基本可以 |
| 本科生能用的 LaTeX 平台 | 校内 Overleaf：<https://overleaf.tsinghua.edu.cn/>，统一身份认证后直接用 |

选课流程、绩点算法、重修与退课、转专业与辅修，站内已有专页，见页末索引表。分级考试的科目与年份安排以入学当年通知为准。

## 证件与手续

| 问题 | 答案 |
| --- | --- |
| 学籍卡片去哪补领 | 先找**所在院系**领取；本来就没领过的也走院系 |

## 角标怎么看

四个角标分别回答四个不同的问题，**别把它们混成一个「可信 / 不可信」的判断**：

| 角标 | 谁测的 | 它能证明什么 |
| --- | --- | --- |
| **需校园网 / 公网可开 / 未实测** | 人工判断 | 这个入口要不要连校园网或 WebVPN |
| **实测可访问** | 脚本（`npm run check:links`） | 域名活着，返回 HTTP < 400。**不证明内容还是你要找的那个** |
| **实测打不开** | 脚本 | 最近一次实测失败。可能真的挂了，也可能只是要校园网 |
| **脚本被拦** | 脚本 + 人 | 该站对**非浏览器请求**返回反爬状态码（如 412），脚本永远测不过；**浏览器里正常**，已由人点开确认。这一条不要当成「打不开」 |
| **脚本核对 2026-09-30** | 脚本（`npm run verify:links`） | 把页面抓下来，比对标题与关键词，确认**地址还指向那个服务** |
| **人工核对 2026-09-30** | 人 | 有人点开确认过「这个入口现在还是干这件事」，含登录后的实际使用 |

:::caution[「脚本核对」和「人工核对」不是一个可信度级别]
- **脚本核对**：程序抓页面，能确认「这个地址打开的确实是清华的网络学堂 / 图书馆 / 就业网」，
  证据（状态码、最终跳转地址、页面标题、命中的关键词）留在仓库的 `.review/link-verification.json`。
  **它看不到登录后的内容**，也发现不了「页面里功能挪了位置」。
- **人工核对**：有人真的点进去用过。页面上写「人工核对」的条目才是这个级别。
- **核对：待补**：两者都没做过。**看到它就别直接转发**，先自己点一下。
:::

:::note[校园系统的「没有标题」是正常的]
校内不少系统是登录页或单页应用，抓下来标题是空的（例如校内 GitLab 跳到 `/users/sign_in`）。
脚本对这类页面的判断依据是「落到了同机构的登录端点」，而不是标题里有字。
另外个别老系统是 GBK 编码，脚本会按页面声明的编码解码后再比对。
:::

## 校园网里打不开的东西

国内访问 GitHub **时通时不通**：网页端延迟高、有时直接超时，要稳定访问就挂代理。
`git clone` / `git push`（SSH）与 `api.github.com` 一般没问题，所以**拉代码比点网页可靠**。

| 通道 | 实测 | 说明 |
| --- | --- | --- |
| `git clone` / `git push`（SSH） | ✅ 通 | 拉代码走这条路 |
| `api.github.com` | ✅ 通 | 接口能调 |
| `github.com` 网页端 | ⚠️ 时通时不通 | 2026-09-30 超时；2026-10-03 连续 5 次 200（1.6–2.2 s） |
| `raw.githubusercontent.com` | ⚠️ 时通时不通 | 2026-10-03 三次里两次成功 |
| 校内系统（教学门户、网络学堂、info） | ✅ 通 | 校外需要先连 [WebVPN](https://webvpn.tsinghua.edu.cn/) |

所以链接上标的「**需代理**」读作：**打不开的时候就挂代理**，不是「必须挂代理才能访问」。
要资料优先找[校内 GitLab 镜像](/guides/archives/)；以上是一次实测，**你自己的实测优先于这张表**。

## 链接失效了怎么办

```bash
npm run check:links        # 跑一遍实测，结果写进 src/data/link-status.json
```

脚本只判断「域名活着」，不会帮你判断「入口还是不是干这件事」。所以处理顺序是：

1. 跑一次 `npm run check:links`，看哪些条目变成了「实测打不开」；
2. 打不开的，**先去信息门户里找一遍** —— 大部分校内系统都能从门户跳转过去，那里的入口永远最新；
3. 确认新地址后改 `src/data/links.ts`（改 `url`，顺手更新 `reach` 和 `note`），
   再填上你核对当天的 `reviewedAt`；
4. 提 PR。改动只落在这一个文件上。

## 想加一个链接

改 `src/data/links.ts` 就够了：加一条记录，写清 `desc`（它到底能干什么）、
`reach`（要不要校园网）和 `origin`（从哪知道的），然后提 PR。
具体流程见[怎么贡献一篇经验帖](/contribute/)。

:::tip[不收录什么]
含个人账号信息的地址（带 `sid`、带 ticket 的链接）、付费导流、以及需要绕开权限才能访问的入口，
一律不收 —— 这些链接既不稳定，也不该被公开转发。
:::

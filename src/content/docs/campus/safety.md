**把三个电话号码存进手机，比记十条建议有用。**

这篇只写三件事：怎么不被骗、宿舍里哪些事绝对不能做、出事时打哪个电话。**先说结论，再给理由。**

## 先把这几个电话存进手机

**保卫部在哪**：校内文南楼南侧、新清华学堂西侧。**24 小时综合值班电话同时也是紧急求助入口。**

:::tip[两条使用习惯]
1. **存名字，别只存号码**。「保卫部 24h」「校园反诈」这样存，出事了才敢按。
2. **能说清位置就打**。报警时先报**你现在在哪一栋、哪一层、哪个门**，比说「我在宿舍」有用得多。
:::

## 四类最常见的诈骗

手段一直在翻新，但**目的只有一个：让你转钱**。下面四类的套路值得背下来——遇到时你会立刻认出它。

### 一、冒充公检法

骗子伪造「通缉令」等材料，说你涉案，或者说你正处于危险境地，让你把钱转到所谓的「安全账户」。

**你该做的**：公检法**不会**通过电话、微信办案，更**不存在**「安全账户」。对方越急、越不让你挂电话、越不让你告诉别人，就越可疑。**直接挂断，然后打 96110 或 62796110 核实。**

### 二、冒充熟人

用领导、老师、同学、朋友的照片做头像，用其姓名做微信名加你。先拉近感情，再以「帮领导送礼」「接待亲戚」「帮忙付款」为由让你转账。

**你该做的**：**换一个渠道核实**。头像和昵称都能伪造，用你原来就有的那个号码打过去问一句，就够了。**凡是「换号了、这是新号、别打旧号」的，一律先当骗子处理。**

### 三、冒充网购客服

以退款、补偿、重新确认为由，诱导你操作银行卡，或者去开通「借呗」「白条」，最后把钱打进骗子账户。

**你该做的**：退款只走**购物平台自己的入口**，不点对方发来的链接，不共享屏幕，不加对方私聊。**任何让你先借钱、先贷款的「退款」，都是诈骗。**

### 四、兼职刷单

先小额返本金和佣金，让你建立信任。等你投入大额资金后就不再返还，还继续诱导你追加。

**你该做的**：**刷单本身就不合法**，也不存在「需要你先垫钱的兼职」。赚到的那点佣金是饵，**第一笔大额投进去就出不来**。

:::danger[这一页的底线]
本站不写任何「绕过规则」或「刷分」的办法，只写**怎么防、怎么求助**。

记住四句：**未知链接不点击，陌生来电不轻信；个人信息不透露，转账汇款多核实。**

建议下载「**全民反诈**」APP。接到 **96110** 或校园反诈中心的电话要接听，**事中听劝不转钱**；**一旦被骗，立刻报案**——越早报案，止付和追回的可能越大。
:::

## 宿舍防火：禁止项清单

学生宿舍是火灾易发地。**下面每一条都是禁止项，不是「建议」。**

- **严禁私拉乱接电线。** 插线板不要串接，也不要压在床垫下。
- **严禁使用**炊事用电器、额定功率 **1000W 以上**的电器，以及无自动断电保护装置的电器、质量低劣或无国家级安全认证的电器。
- **严禁把电动车电池带进宿舍，严禁在宿舍为电动车电池充电。** 这一条是近年新增的重点，**不是小事**。
- **严禁吸烟和使用明火。**
- **严禁存放**液化气罐、酒精炉等易燃易爆物品。
- **严禁遮挡、挪用、毁损**消防设备设施与消防标识。
- **严禁在安全通道、楼梯、电梯前室、安全出口内外堆物或停车。** 你堆的东西，就是逃生时最大的障碍。
- **严禁在插线板、插座、电线、电器旁堆放可燃物。**
- **离开宿舍切断电源。**

## 真起火了：报警、逃生、灭火器

### 报警：先打出去，再说清楚

打**校园安全求助电话 62782001**、**62783996**，或者直接打 **119**。接通后按顺序讲清这七件事：

1. **着火的单位名称与地址**——哪一栋、哪一层、哪个房间。
2. **燃烧物的性质**——烧的是什么。
3. **有无被困人员。**
4. **有无爆炸或毒气。**
5. **火势情况**——多大、往哪蔓延。
6. **报警人姓名与电话。**
7. **火场有无明显标志或参照物**——方便消防车快速找到。

**报完派人到主要路口迎接消防车。不得谎报火警。**

### 逃生：稳定情绪，先报警

- **先稳住，先报警**，不要只顾着收拾东西。
- **初起阶段**可以用灭火器和消火栓控制火势。
- 撤离走**疏散通道和安全出口**，**不贪财物、不乘电梯**，**低姿沿走廊墙根迅速撤离**，不在浓烟处停留。
- 用**湿毛巾或口罩捂住口鼻**；打湿床单被褥**塞住门缝**；情况紧急时可用布匹结绳自救。
- **被困时在窗口挥手呼救**，或挥动鲜艳物品，让外面能看见你。
- 影院等**人员密集场所**听从现场指挥有序撤离，**防止踩踏**。

### 灭火器：两种，用法不同

**干粉灭火器**

- 站在**上风口**，离火源 **3–5 米**。
- **拔去保险销**，一手握喷嘴瞄准火焰，另一手压下压把。
- 对准**火焰根部**左右横扫，**由远及近**。
- 扑救油类等易燃液体时，**避免冲击液面**。

**二氧化碳灭火器**

- 站在**上风处**，一手握住喷筒的**胶质喷管处**（防止冻伤）。
- 拔销后**压下压把**。
- **室内使用后注意通风**，防止窒息。

## 电脑与账号加固

**电脑有漏洞就容易被攻击。** 装机时按下面的顺序做，比事后补救省事：

1. **装学校提供的正版操作系统与杀毒软件**。下载地址 `its.tsinghua.edu.cn`，**建议提前存到 U 盘**——重装系统时你可能正好上不了网。
2. **安装时改掉 Windows 用户登录名，并设高强度密码**：至少 **10 个字符**，包含大写、小写、特殊字符、数字中的**三类以上**。
3. **删除或禁用来宾账户（guest）。**
4. **系统装好先不联网，先装杀毒软件**，再连网。
5. **禁用远程桌面共享、远程协助、远程登录与远程控制。**
6. **封禁共享端口 135、137、138、139、445、3389。**
7. **把 Windows 更新地址改成校内更新服务器**，连上校园网后更新病毒库与系统补丁。

账号认证、校园网流量和连不上时的排查顺序，见[校园网、流量与镜像加速](/campus/network-and-traffic/)；宿舍场景下的用电与门禁口径，见[宿舍、门禁与校园网](/freshman/dorm-and-network/)。

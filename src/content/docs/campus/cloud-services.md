## 先解决登录：统一身份认证

校内绝大多数系统的通行证是**统一身份认证**，也就是常说的 **info 账号密码**。记住这一层，剩下的事情都能推出来：

- **改密码的入口**在这里：<https://id.tsinghua.edu.cn/do/off/ui/pwd/change>
- **账号可在线设备数上限为 1–8 台**。也就是说，同一时间登录的设备太多会挤掉其中一些，表现可能是「莫名其妙要重新登录」。
- **选课建议用 Firefox 或 Chrome**。教务类系统对浏览器的兼容性要求比较挑，用别的浏览器出问题很难判断是网络还是页面本身。

登不进去、账号有问题、密码要重置，都找**信息化技术中心**：

| 事项 | 地点与联系方式 |
| --- | --- |
| **用户服务室** | **李兆基科技大楼东门一层 B104 室**；电话 **010-62784859**；邮箱 its@tsinghua.edu.cn；工作日 **8:00–12:00、13:00–17:00** |
| **密码重置窗口** | 同一地点；工作日 **8:00–12:00、13:00–17:00** |
| **缴费窗口** | 同一地点；工作日 **13:00–16:00**（注意只有下午） |

:::tip[先分清「登不上」还是「连不上」]
打不开页面、一直转圈，多半是网络接入的问题，走[校园网、流量与镜像加速](/campus/network-and-traffic/)的排查顺序；
页面能打开、但提示账号或密码不对，才是账号问题，走上面的密码重置窗口或信息化技术中心。
**把这两件事混在一起描述，会拖慢处理速度。**
:::

这张表的用法不是「都打开一遍」，而是**先认门牌**：遇到一件事，先判断它属于哪一类，再去对应的那一个。几条经验：

- **正事去 info，上课去 learn，借地方去 student。** 这三条能覆盖新生期的绝大多数需求。
- **信息化用户服务平台（its）是「系统本身出问题」时该去的地方**：正版软件从哪装、网络服务怎么开、账号相关事务怎么办，先看这里，因为这里的说明是官方口径、更新最快。
- **邮箱和云盘建议在报到后尽快各打开一次**，确认自己能用，别等到要交材料的那天才发现登不上。
- **注意 `learn` 和 `lib` 是两套不同的入口**：课程在 learn，文献和研读间在 lib，不要互相找。

:::caution[入口以首页为准]
上表的地址是 2026 年的入口。系统每年可能改版、也可能把功能合并进别的平台。
**真正靠得住的做法是从 <https://its.tsinghua.edu.cn> 或信息门户里点进去**，而不是背地址——背下来的旧地址失效时，你甚至不知道是网络坏了还是入口变了。
:::

## 在校外：WebVPN 与 SSLVPN

放假回家、出校实习期间要进校内系统，有两条官方路线，**都不要用来路不明的第三方代理**：

- **WebVPN**：<https://webvpn.tsinghua.edu.cn> —— 在校外访问校内系统用，**需双因素认证**。
- **SSLVPN 客户端**：下载地址 <https://deny.tsinghua.edu.cn>。

:::danger[不要用来路不明的第三方代理]
这类「校园 VPN」「加速器」看起来只是省事，实际上**等于把账号交出去**：
你的访问记录、登录凭据都要经过对方的服务器，出事时后果算在你头上。
需要用校外资源，就走上面的 WebVPN 或图书馆的校外访问入口。
:::

:::tip[双因素认证不是可以绕过去的步骤]
WebVPN 要求双因素认证，是为了在密码之外再加一道验证。
**不要为了省一步去找「跳过验证」的办法**，也不要把认证信息转给他人代收。具体设置方式看信息化用户服务平台的说明。
:::

## 场地预约：三套系统别找错

这是校内最容易被「找错入口」耽误的事。**教室、研读间、体育场馆是三套完全独立的系统**，规则也不一样：

| 要借什么 | 入口 | 规则（2026 年口径） |
| --- | --- | --- |
| **教室、学生活动室** | <https://student.tsinghua.edu.cn>（资源手册：<https://student.tsinghua.edu.cn/post/site-resources>） | **至少提前 5 天**申请，**最多提前 2 周**；逾期或距活动 3 天以内的，改用《清华大学教室（学生）借用审批表》走线下流程 |
| **图书馆研读间 / 研讨间** | <https://lib.tsinghua.edu.cn>（路径：空间 – 研讨） | 刷卡签到，违约会被停权；**清小搭口径是 5 次停用 3 天**，[吃饭、自习与出门](/campus/food-and-study/)里有更细的违约算法 |
| **体育场馆** | <https://www.sports.tsinghua.edu.cn/venue> | 有**诚信记录**，需网上缴费；**爽约有代价** |

三张表背后是同一个道理：**这三类场地归不同的单位管**，所以规则、时间窗、违约代价都不一样。找错入口不只是白点几下，而是**可能在错误的系统里等一个永远不会放出来的场**。

:::caution[三条别踩的线]
1. **别等临近了才去 student 借教室**。它要提前 5 天，且最多提前 2 周——「下周三的活动、今天才想起来」在这个系统里已经来不及了，只能走线下审批表。
2. **图书馆研读间的违约是累计的**。刷卡签到这一步别嫌麻烦，**没去就尽早按规则取消**——停权的次数口径有两套说法（见[吃饭、自习与出门](/campus/food-and-study/)），用前先核实，但「爽一次约」从来都不划算。
3. **体育场馆要先缴费、并且有诚信记录**。约到了就去，去不了就按规则取消；**代订、转借、脚本抢场都属于违规**，具体规则以官方说明为准。
:::

**借到之后怎么用、约不到怎么办**，以及场馆预约的完整流程与替代方案，见[运动与场馆](/campus/sports-and-venues/)；教室与活动空间的具体申请路径，也和[吃饭、自习与出门](/campus/food-and-study/)里写的是同一套流程。

## 网络学堂与教室：使用规则

上面那张表说的是"从哪进"。这里补的是**进去之后会被什么规则约束**——这两份规定都是校内正式规章，不是"建议"。

### 网络学堂（learn）能干什么、不能放什么

**谁能用**：用户包括**经学校统一电子身份认证的教职工、有学籍的学生**，以及经注册中心身份认定的其他用户。登录后，**任课教师、助教、选课学生**可以进入「我的课程」，使用教学活动相关的资源和服务；**其他用户只能浏览开放课程资源**。**办理离校的教职工和学生不再提供网络学堂使用服务。**

**它承担什么**：网络学堂是学校信息系统的组成部分，是**辅助人才培养的综合性网络教学系统**，由**注册中心**负责管理和服务。日常用到的就是**课件、作业提交、讨论区**这些教学活动相关的资源与服务。

:::note[关于成绩查询]
成绩的权威出口是**信息门户（info）**，不是网络学堂。网络学堂里呈现的是什么，**以你登录后看到的为准**；本文不替它描述功能清单。
:::

**内容上的硬规则**：

- **课件、作业和讨论区中只能存放与学习和学术交流有关的文件**。凡是**与学习和学术交流无关的音频、视频、游戏、软件、小说等文件都不能存放**；也不得上传或发布**损害或妨碍系统运行**的内容。一旦发现不符合规定的文件，**管理部门有权在不通知用户的情况下直接删除**；情形严重者，**取消其使用本区域功能的权限**。
- **禁止以上载、发布、传播等方式发布不良信息**，包括违反宪法确定的基本原则、危害国家安全、损害国家荣誉和利益、煽动民族仇恨与歧视、破坏国家宗教政策、散布谣言、散布淫秽色情赌博暴力内容、侮辱诽谤他人、含有病毒木马等危害计算机安全的内容，以及法律行政法规禁止的其它内容。
- **不得侵犯第三方合法权益**：用户应确保上传、发布、传播的信息不侵犯他人的专利权、著作权、商标权、名誉权或其它合法权益，**不得进行任何有损学校名誉和利益的活动**。
- **责任自负**：用户上载、发布、传播信息所产生的**纠纷和责任由用户个人解决和承担**。

**账号与登录上的注意点**：

- **必须通过官方网站和入口登录**。官方网址是 <https://learn.tsinghua.edu.cn>，微信端入口是微信企业号「清华大学信息服务 → 网络学堂」，也可以登录信息门户后点击链接访问。**不通过官方入口访问的，系统不保证个人信息与访问操作受到安全保护。**
- **网络学堂账户与学校统一身份认证系统中的账户一致**，它**不单独设置账户，也不提供账户管理服务**——所以密码问题一律走统一身份认证那条线（见上文「先解决登录」）。
- 网络学堂**会单独采集用户的邮箱、电话信息**并允许用户自行编辑修改；个人信息**仅限系统内部使用**，不提供给其他系统共享、转让、披露。
- **微信版的群消息存在第三方服务器上**：网络学堂微信版提供课程教师微信群、课程微信群，**在微信群里发布的信息会借助第三方工具存储在第三方服务器上**，用户应确保这些信息同样遵守上面的内容规则，**并且不会泄露学校各项保密管理规定的内容**。
- **建议自行备份**：系统会为与正常教学活动有关的资料提供存储与查询服务，但**建议用户在非网络学堂的其它存储介质上及时备份**自己上载、发布的信息，以免误操作导致资料丢失。

**违规后果**：视情节轻重给予**删除信息、暂停或终止使用、通报批评**等处罚；同时违反学校其它规定或国家法律法规的，移交有关部门处理。

**来源**：《清华大学学生手册（2024）》所收《清华大学网络学堂管理办法》（2024 年口径）。

### 教室管理：借用流程、禁止项与开放时间

教室的**预约时间窗**（至少提前 5 天、最多提前 2 周）在上面场地预约那张表里。这里补的是**审批链条和教室里不能做的事**。

**一、教室归谁管、借用的审批链条**

- **公用教室由学校统一管理，专用教室由各有关院（系、所）管理**；全校教室需**优先保证教学计划的落实**，由**注册中心统一依据本科及研究生教学计划调配使用**。
- **公用教室原则上仅限校内教师、学生开展教学活动或学生团体开展活动使用**。教室资源在最大化服务教学之后仍有空余时，可在相关部门审批后用于支持与人才培养相关的活动。
- **审批要求**：各院（系、所）、部处借用教室须由**本单位相关负责人审核活动内容**通过；**学生团体借用教室须由学生部、研工部或团委审核活动内容通过**；与人才培养相关的活动借用教室须经**校办、保卫部、宣传部**等相关部门审核通过。
- **概不借用的情形**：**以商业宣传为目的的各类讲座、培训**，以及**举办晚会、放映影视作品**及其他可能影响教学的活动。
- **可能产生费用**：非教学活动（如开会、培训）使用教室按校内收费及标准核定小组批准的标准收费；**活动受益方为学校学生且没有经费支持的活动、会议或讲座**，教育部或上级主管部门安排的活动，学校各部处面向全校的工作安排会议等可申请费用减免。需缴费的借用方须在**教室使用前 24 小时足额缴费**，未按时缴费者**取消教室借用**。
- **实际使用内容应与借用表一致**。若有违反，一经查实，按情节轻重对相关个人、单位进行**批评、通报或停借教室**等处理。

| 类别 | 规则 |

## 公众号怎么挑

学校的官方公众号数量很多，各部门、各院系都有自己的号。按用途大致分成这几类：

| 类别 | 大致包含什么 |
| --- | --- |
| **校园综合服务** | 如「**清华大学信息服务**」——绑定后可接收通知，并办理学习教务、财务、网络、图书馆等事项 |
| **学业类** | 与课程、教务、图书馆等相关的官方号 |
| **生活类** | 后勤、宿舍、餐饮、场馆等生活服务相关的官方号 |
| **学生组织类** | 校团委、学生会及各学生组织的号 |
| **宣传类** | 学校层面与各部门的宣传号 |

**怎么挑：按你的用途选，不要一次性全关注。**

- **必须关注的是「校园综合服务」这一类**，尤其是「清华大学信息服务」——绑定之后通知能直接推到微信，这是最省事的一步。
- **其次按你需要补**：常去图书馆就补图书馆的号，关心住宿和报修就补后勤类的号，参加学生组织就补对应组织的号。
- **宣传类可以少关注**。信息密度和你的实际需求不一定匹配，关注太多只会让通知被淹没。
- **凡是涉及登录、绑定、缴费的公众号，一律先核对是不是官方认证的主体**，别在来路不明的「服务号」里填账号密码。

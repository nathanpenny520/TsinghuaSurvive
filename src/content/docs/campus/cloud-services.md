**先记三个地址：`info` 办正事、`learn` 上课、`student` 借地方。**

- <https://info.tsinghua.edu.cn> —— **信息门户**，成绩、通知、财务、教务的总入口；
- <https://learn.tsinghua.edu.cn> —— **网络学堂**，课程资料、作业提交、课程通知；
- <https://student.tsinghua.edu.cn> —— **学生清华**，学生活动空间与教室借用。

其余的邮箱、云盘、图书馆、后勤、场地预约，都是围绕这三件事长出来的。这一页只回答四个问题：
**有哪些系统、各自干什么、从哪进、用什么登录**。

:::note[这一页不写什么]
**怎么连网、怎么换镜像源**在[校园网、流量与镜像加速](/campus/network-and-traffic/)里，这一页不重复。
**C 楼的楼层分布、超市与打印点、后勤服务入口**在[C 楼与日常服务](/campus/daily-services/)里。
**场馆预约的一般流程与替代方案**在[运动与场馆](/campus/sports-and-venues/)里。

另外，本文**不写任何密码、初始口令、验证码或账号格式**——只写到「用什么登录」这一层。凭据类信息请按官方指引在校内渠道自行设置和保管。
:::

## 先解决登录：统一身份认证

校内绝大多数系统的通行证是**统一身份认证**，也就是常说的 **info 账号密码**。记住这一层，剩下的事情都能推出来：

- **改密码的入口**在这里：<https://id.tsinghua.edu.cn/do/off/ui/pwd/change>
- **账号可在线设备数上限为 1–8 台**。也就是说，同一时间登录的设备太多会挤掉其中一些，表现可能是「莫名其妙要重新登录」。
- **选课建议用 Firefox 或 Chrome**。教务类系统对浏览器的兼容性要求比较挑，用别的浏览器出问题很难判断是网络还是页面本身。

登不进去、账号有问题、密码要重置，都找**信息化技术中心**：

| 事项 | 地点与联系方式 |
| --- | --- |
| **用户服务室** | **李兆基科技大楼东门一层 B104 室**；电话 **010-62784859**；邮箱 its@tsinghua.edu.cn；工作日 **8:00–12:00、13:00–17:00** |
| **密码重置窗口** | 同一地点；工作日 **8:00–12:00、13:00–17:00** |
| **缴费窗口** | 同一地点；工作日 **13:00–16:00**（注意只有下午） |

:::tip[先分清「登不上」还是「连不上」]
打不开页面、一直转圈，多半是网络接入的问题，走[校园网、流量与镜像加速](/campus/network-and-traffic/)的排查顺序；
页面能打开、但提示账号或密码不对，才是账号问题，走上面的密码重置窗口或信息化技术中心。
**把这两件事混在一起描述，会拖慢处理速度。**
:::

## 常用系统一览

| 系统 | 地址 | 干什么 |
| --- | --- | --- |
| **信息门户** | <https://info.tsinghua.edu.cn> | 校内事务的总入口：通知、成绩、财务、教务通知等 |
| **网络学堂** | <https://learn.tsinghua.edu.cn> | 课程资料、作业提交与课程通知 |
| **信息化用户服务平台** | <https://its.tsinghua.edu.cn> | 网络服务、正版软件、账号相关事务 |
| **学生邮箱** | <https://mails.tsinghua.edu.cn> | 学生邮箱，容量 **50GB**；教师邮箱为 mail.tsinghua.edu.cn |
| **云盘** | <https://cloud.tsinghua.edu.cn> | 校内云盘，容量 **1TB** |
| **图书馆** | <https://lib.tsinghua.edu.cn> | 图书馆主页：借阅、数据库与空间预约的入口 |
| **学生清华** | <https://student.tsinghua.edu.cn> | 学生活动空间与教室借用 |
| **校园网自助服务** | <https://usereg.tsinghua.edu.cn> | 校园网账号相关的自助服务 |
| **网络登录页** | <http://login.tsinghua.edu.cn> | 网络登录页面 |

这张表的用法不是「都打开一遍」，而是**先认门牌**：遇到一件事，先判断它属于哪一类，再去对应的那一个。几条经验：

- **正事去 info，上课去 learn，借地方去 student。** 这三条能覆盖新生期的绝大多数需求。
- **信息化用户服务平台（its）是「系统本身出问题」时该去的地方**：正版软件从哪装、网络服务怎么开、账号相关事务怎么办，先看这里，因为这里的说明是官方口径、更新最快。
- **邮箱和云盘建议在报到后尽快各打开一次**，确认自己能用，别等到要交材料的那天才发现登不上。
- **注意 `learn` 和 `lib` 是两套不同的入口**：课程在 learn，文献和研读间在 lib，不要互相找。

:::caution[入口以首页为准]
上表的地址是 2026 年的入口。系统每年可能改版、也可能把功能合并进别的平台。
**真正靠得住的做法是从 <https://its.tsinghua.edu.cn> 或信息门户里点进去**，而不是背地址——背下来的旧地址失效时，你甚至不知道是网络坏了还是入口变了。
:::

## 在校外：WebVPN 与 SSLVPN

放假回家、出校实习期间要进校内系统，有两条官方路线，**都不要用来路不明的第三方代理**：

- **WebVPN**：<https://webvpn.tsinghua.edu.cn> —— 在校外访问校内系统用，**需双因素认证**。
- **SSLVPN 客户端**：下载地址 <https://deny.tsinghua.edu.cn>。

:::danger[不要用来路不明的第三方代理]
这类「校园 VPN」「加速器」看起来只是省事，实际上**等于把账号交出去**：
你的访问记录、登录凭据都要经过对方的服务器，出事时后果算在你头上。
需要用校外资源，就走上面的 WebVPN 或图书馆的校外访问入口。
:::

:::tip[双因素认证不是可以绕过去的步骤]
WebVPN 要求双因素认证，是为了在密码之外再加一道验证。
**不要为了省一步去找「跳过验证」的办法**，也不要把认证信息转给他人代收。具体设置方式看信息化用户服务平台的说明。
:::

## 场地预约：三套系统别找错

这是校内最容易被「找错入口」耽误的事。**教室、研读间、体育场馆是三套完全独立的系统**，规则也不一样：

| 要借什么 | 入口 | 规则（2026 年口径） |
| --- | --- | --- |
| **教室、学生活动室** | <https://student.tsinghua.edu.cn>（资源手册：<https://student.tsinghua.edu.cn/post/site-resources>） | **至少提前 5 天**申请，**最多提前 2 周**；逾期或距活动 3 天以内的，改用《清华大学教室（学生）借用审批表》走线下流程 |
| **图书馆研读间 / 研讨间** | <https://lib.tsinghua.edu.cn>（路径：空间 – 研讨） | 刷卡签到，违约累计 **3 次暂停 30 天**预约权 |
| **体育场馆** | <https://www.sports.tsinghua.edu.cn/venue> | 有**诚信记录**，需网上缴费；**爽约有代价** |

三张表背后是同一个道理：**这三类场地归不同的单位管**，所以规则、时间窗、违约代价都不一样。找错入口不只是白点几下，而是**可能在错误的系统里等一个永远不会放出来的场**。

:::caution[三条别踩的线]
1. **别等临近了才去 student 借教室**。它要提前 5 天，且最多提前 2 周——「下周三的活动、今天才想起来」在这个系统里已经来不及了，只能走线下审批表。
2. **图书馆研读间的违约是累计的**。刷卡签到这一步别嫌麻烦，**没去就尽早按规则取消**，暂停 30 天预约权的代价比爽一次约大得多。
3. **体育场馆要先缴费、并且有诚信记录**。约到了就去，去不了就按规则取消；**代订、转借、脚本抢场都属于违规**，具体规则以官方说明为准。
:::

**借到之后怎么用、约不到怎么办**，以及场馆预约的完整流程与替代方案，见[运动与场馆](/campus/sports-and-venues/)；教室与活动空间的具体申请路径，也和[吃饭、自习与出门](/campus/food-and-study/)里写的是同一套流程。

## 后勤与宿舍：报修与缴费

日常生活的报修与缴费有两套入口，**先把地址存下来**：

- **后勤综合服务平台**：<http://hq.tsinghua.edu.cn>
- **清华家园网**：<http://myhome.tsinghua.edu.cn>（也有同名**微信服务号**）

两个具体流程，记住「从哪进去、点哪一项」就够了：

| 要办的事 | 怎么走 |
| --- | --- |
| **网上报修** | 在平台里走「**社区服务**」下拉 → 「**添加报修记录**」 |
| **电费充值** | 先登录（**学号 + info 密码**），再走「**快速通道 – 电费充值**」，用**支付宝**支付 |

:::tip[报修写清楚，比催进度有用]
提交报修记录时把**位置、设备、现象、开始时间**写具体，并**留好记录编号**。
平台上有记录，后面催进度时你有依据；口头说一句「我报修过了」通常不算数。
:::

**后勤服务平台的完整功能（部门电话、订车订房、校医院挂号等）、C 楼的窗口与自助服务厅、注册中心能办的事项**，
都在[C 楼与日常服务](/campus/daily-services/)里，这一页不重复。

## 公众号怎么挑

学校的官方公众号数量很多，各部门、各院系都有自己的号。按用途大致分成这几类：

| 类别 | 大致包含什么 |
| --- | --- |
| **校园综合服务** | 如「**清华大学信息服务**」——绑定后可接收通知，并办理学习教务、财务、网络、图书馆等事项 |
| **学业类** | 与课程、教务、图书馆等相关的官方号 |
| **生活类** | 后勤、宿舍、餐饮、场馆等生活服务相关的官方号 |
| **学生组织类** | 校团委、学生会及各学生组织的号 |
| **宣传类** | 学校层面与各部门的宣传号 |

**怎么挑：按你的用途选，不要一次性全关注。**

- **必须关注的是「校园综合服务」这一类**，尤其是「清华大学信息服务」——绑定之后通知能直接推到微信，这是最省事的一步。
- **其次按你需要补**：常去图书馆就补图书馆的号，关心住宿和报修就补后勤类的号，参加学生组织就补对应组织的号。
- **宣传类可以少关注**。信息密度和你的实际需求不一定匹配，关注太多只会让通知被淹没。
- **凡是涉及登录、绑定、缴费的公众号，一律先核对是不是官方认证的主体**，别在来路不明的「服务号」里填账号密码。

## 马上能做的：把入口存进手机

- [ ] **绑定「清华大学信息服务」**，确认通知能收到
- [ ] 把 **info / learn / student** 三个地址存成书签或桌面快捷方式
- [ ] 打开 **its** 一次，确认自己知道「系统出问题去哪查」
- [ ] 确认**学生邮箱和云盘能用**，各打开一次
- [ ] 校外要用的话，提前把 **WebVPN 的双因素认证**配好——**别等到要交材料的当天**
- [ ] 需要借场地的话，**先在 student 上看清时间窗**，再定活动日期

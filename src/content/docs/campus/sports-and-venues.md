和食堂、打印这些事一样，场馆与体测的信息也是**一年一变**。所以这篇**不写任何具体项目分值与达标线**——那些写在文章里，过一年就会把人带偏。**场馆名称、预约入口和赛事名称**这类信息，本文给的是 2026 年的口径，并标明年份。

这篇回答四个问题：**体育课和体测大体是怎么回事、场地通常怎么约、约不到怎么办、以及怎么让自己真的动起来。**

## 这篇文章不做什么

- **不写达标标准**。体测项目、评分口径、及格线与免测条件**全部以官方通知和任课教师说明为准**，这里一个数字都不写。
- **开放时段与放场规则**每年都可能调整，本文只在「2026 年的场馆与赛事」一节给当年的入口与场馆名称，**具体时间到场馆看公示**。
- **不给训练计划模板**。"每周跑多少公里"这种事取决于你的基础、旧伤和目标，没有通用答案。
- **不评价任何任课教师**，也不比较哪个项目"好过"。

:::caution
身体有特殊情况（旧伤、慢性病、术后恢复期等）的同学，**请尽早按流程向任课教师和院系说明**，走免修、缓测或替代安排的正式渠道。**不要自己硬撑，也不要用不实材料去申请**——后者属于违纪，代价远大于一次体测。
:::

## 2026 年的场馆与赛事：先知道有什么

下面这些名字是 2026 年的口径。**它们的作用是让你知道"有哪些选项"**，不是让你背下来——到了现场看公示牌比记这张表准。

**体育场馆**：北体育馆、西体育馆、综合体育馆、游泳馆、气膜馆，以及羽毛球场、乒乓球、篮球场、足球场、排球场、网球场、棒垒球场、手球场和室外健身区。大部分场馆、场地**定时开放**，开放时间去场馆门口看。

**部分场地走网上预约**：<https://www.sports.tsinghua.edu.cn/venue/#/home>（这个系统有**诚信记录**，需要网上缴费，爽约有代价）。

**文艺场馆**（同一张卡、同一个校内票务体系）：

| 场馆 | 座席 | 主要用途 |

| 新清华学堂 | **2011 座**，配专业舞台系统 | 交响音乐会、歌剧、芭蕾等大型演出 |
| 蒙民伟音乐厅 | **491 座** | 音乐会、戏剧、话剧等中型演出 |

### 你会遇到的体育赛事（不用基础也能参加）

- **新生赤足运动会**：大一同学专属的**第一项体育比赛**，赤足奔跑，也是认识同学、给班级拿荣誉的机会。
- **班级体育大联盟**：由「**紫荆之巅**」篮球赛、「**临门一脚**」足球赛、「**排山倒海**」排球赛组成，跨院系、跨年级、跨班级，**不需要经验和基础**，代表班级就能上场。
- **马约翰杯**：得名于马约翰先生，已经办了 70 多年，是贯穿全年的赛事体系。
- **特色长跑**：校庆月的**校园马拉松**（自 2015 年起，每年校庆日前两周的周六）、**冬季迷你马拉松**（自 2017 年起，每年 12 月初）、**毕业长跑**，以及一二·九长跑等。

:::caution[游泳测试：这是毕业要求，不是选修]
学校自 2017 年起恢复「**不会游泳不能毕业**」的老校规，游泳测试是本科生的毕业环节之一。**具体的测试时间、距离标准与免测流程以体育部门的当年通知为准**（本文不写达标数字）。不会游泳的同学，**大一就去学**，别拖到大四才发现它是硬门槛。
:::

## 体育课与体测的一般逻辑

先把三件事分清，能省掉很多焦虑：

1. **体育课的成绩构成通常是"出勤 + 课堂表现 + 技能/体能测试"的组合**。也就是说，**长期缺勤的损失往往比一次测试没发挥好更大**。
2. **体测通常与课程或学年挂钩**，但具体怎么挂、算不算成绩、什么时间测，**各院系和年份可能不同**。
3. **免修、缓测、替代项目都有正式流程**。这些流程存在，但**必须提前走**，通常不接受事后补办。

所以最省事的做法是：**开学第一节课就把考核方式、测试时间、请假与补测规则问清楚**，而不是期末才发现缺一次测试没法补。

:::tip[把"要交什么"记进日历]
体育课最容易被忽略的，是那些**只在某个固定时段发生一次**的事：某次技能测试、某次体能测试、课外锻炼的打卡截止。它们不像期末考试有明确的全校氛围提醒，很容易被错过。**第一节课就把这几个时间点记进手机日历。**
:::

## 场馆预约的一般流程

不同场馆的系统不一样，但流程大体是同一个形状：

| 步骤 | 这一步在做什么 | 容易踩的坑 |
| --- | --- | --- |
| **① 确认入口** | 找到该类场馆的官方预约入口 | 入口可能在校内体育相关站点或校内门户里，**别用来路不明的小程序** |
| **② 实名与资格** | 登录、绑定身份、确认自己是否有预订资格 | 资格可能分学生/教职工、校内/校外，**不是所有人都能约同一类场地** |
| **③ 按放场时间抢场** | 在规则允许的时间点提交预订 | 放场时间点很关键，**提前几分钟登录好** |
| **④ 确认与凭证** | 记下场地、时段、凭证或二维码 | 截图保存；**别只靠记忆** |
| **⑤ 到场与核验** | 按时到场、按规则核验身份 | 迟到可能被取消，**规则以场地方为准** |
| **⑥ 取消** | 去不了就按规则尽早取消 | **爽约通常有代价**（限制后续预约等），具体口径以官方说明为准 |

体育相关的官方入口之一是学校体育部门的站点（[场馆信息入口](https://www.sports.tsinghua.edu.cn/venue/)），**页面结构与入口随时可能调整，请以你实际打开看到的为准**。校内的场馆类链接也可以从[校内常用链接](/guides/links/)里找。

:::danger[两条不要做的事]
1. **不要转借、倒卖或代订场地**。这类行为通常违反场馆使用规则，被查到会影响你自己的使用资格。
2. **不要用脚本、代抢或多人账号刷场**。规则类的空子不属于"技巧"，属于违规；本站不写这类做法。
:::

## 约不到场地怎么办：按"目的"换方案

约不到场地的第一反应往往是"再抢一次"，但更有效的是**回到你真正想做的事**：

| 你的目的 | 约不到时的替代方案 |
| --- | --- |
| **想出汗、想有氧** | 跑步、快走、跳绳、楼梯、宿舍或楼里的自重训练——**门槛最低，也最不容易被取消** |
| **想练力量** | 自重训练、弹力带、校内健身类场地（规则以官方为准） |
| **想打球、想社交** | 加入院系队或社团的固定活动；很多队有固定时段，比散客抢场稳 |
| **想上体育课之外的项目** | 看体育类课程或学生组织的公开活动，**以当年开课与活动通知为准** |
| **只是想要固定运动习惯** | 别依赖场地。**依赖"时间点 + 同伴"更靠谱** |

:::tip[非高峰时段比抢场更值]
工作日的白天、周末的清晨、以及饭点前后，通常比晚间和周末下午好约得多。**如果你的课表允许，把运动安排在别人上课的时间**——这是最稳定的解法。
:::

## 安全与损伤：三条不能省

1. **热身不少于几分钟，正式运动前先让身体热起来**。绝大多数拉伤发生在"直接上强度"的头十分钟。
2. **加量要慢**。本周比上周多一点点就够；**一次练到极限的收益，抵不上伤停一个月**。
3. **旧伤和不适要主动说**。疼、肿、头晕、心慌，都是停止运动的信号，**不是"意志力不够"**。

**受伤之后**：先停止运动、保护受伤部位，按需就医；涉及课程考核的，**尽早按流程向任课教师说明并咨询缓测或替代安排**（具体流程以官方通知为准）。校内看病与报销的流程见[看病、报销与奖助学金](/campus/health-and-money/)。

:::caution[关于"带伤上场"]
用不实理由请假、找人代替体测、或者明知有伤还去拼成绩，都不值得。**成绩可以下次再测，伤可能陪你很久。**
:::

## 怎么把运动塞进课表

不靠意志力，靠结构。四个有效的做法：

1. **绑定固定时间点**。选一个每周不变、且不容易被别的事挤掉的时段（比如某天早课前，或者某天下午第一节课前）。
2. **和已有安排绑定**。把运动接在"已经必须出门"的行程后面——下课之后、取快递的路上、去食堂之前。**需要额外出门的计划最容易取消。**
3. **结伴**。约一个同学固定时间运动，**爽约的社会成本比爽自己的约高得多**。
4. **降低最小门槛**。"今天只做 15 分钟"也算完成。**能做下去的半小时，胜过坚持不了的三小时。**

:::note[运动与作息是一件事]
作息乱、睡不够的时候，训练表现和恢复都会变差，受伤风险也会升高。时间安排上的思路见[时间管理：为什么你的计划总是失败](/mindset/time-management/)。
:::

## 马上能做的：开学第一周清单

- [ ] 第一节课问清**考核构成、测试时间、请假与补测规则**，记进日历
- [ ] 确认自己的**体测与免测相关安排**（有特殊情况就更要早问）
- [ ] 打开官方入口，**确认自己有没有场地预约资格**，看清放场规则
- [ ] 准备基础装备：合脚的鞋、透气衣物、水杯、毛巾（**鞋最重要**）
- [ ] 想好一个**不依赖场地**的备选方案，写下来
- [ ] 约一个同伴，定一个固定时段

## 马上能做的：身体不适或受伤时清单

- [ ] **立刻停止运动**，不要"再试一次"
- [ ] 记录受伤时间、部位、动作，以及疼痛的变化
- [ ] 需要就就医；涉及考核的，**按流程向任课教师说明**
- [ ] 恢复期**从低强度开始**，不要按受伤前的强度直接回到训练
- [ ] 复诊或复查按医嘱进行，**不要自己判断"好了"**

## 哪些东西取决于你的院系、宿舍楼和年份

- **体育课的考核构成与达标口径**：不同项目、不同年份会变，**以当年通知为准**。
- **场馆预约资格与放场规则**：取决于场馆类别和你的身份类别。
- **宿舍楼附近有什么可用的运动空间**：取决于你住在哪一片，**问同楼的人最准**。
- **免修、缓测、替代安排的流程**：各院系和相关部门的口径可能不同，**必须走正式渠道确认**。

**C 楼一栋楼能办完新生 80% 的手续。** 这话不夸张：注册、住宿咨询、报修、缴费、心理与学业支持、超市、打印、理发、洗衣，都在这一栋楼或者它边上。所以先把 C 楼记熟，你的日常半径会小很多。

这篇只做一件事：**给点位和渠道**。哪一层有什么、哪几家超市、打印店在哪、报修和缴费去哪个平台。**至于打印具体怎么做才不出错**（交 PDF、嵌字体、先看预览页数），方法不在这一篇，见[快递、打印与跑腿](/campus/express-and-printing/)。

:::note[先看口径]
下面所有楼层、店名和平台地址都是 **2026 年** 的情况。楼内布局会调整，商户会换人。**这里的清单不替代现场公示**。
:::

## C 楼：先记一层一层有什么

学生服务中心（简称 C 楼）就在**紫荆宿舍区**，因为外形像一个字母 C 而得名。楼里入驻了学生学习与发展指导中心、学生心理发展指导中心、全球胜任力发展指导中心、学生课外活动指导中心、注册中心、学生社区管理服务中心等部门，还有学生公寓总服务台、校园超市、各类商户和学生活动空间。

**最该先记住的是 C 楼 109 室**：这里提供 24 小时「一站式」服务——住宿生活咨询、空调等设备报修、日常调宿申请、临时伤病房办理、借宿舍钥匙、楼内水电费充值。**总台 24 小时服务热线 010-62793003**。国际学生住宿业务咨询国际学生公寓总服务台 **010-62793006**（工作时间 7:00–22:00）。

**三层和四层是「办事 + 找人」的楼层**：遇到学业、心理、全球胜任力、课外活动、社区管理这几类问题，先来这里问，比自己在网上搜快。二、三层的活动空间和研讨教室需要按教室借用流程申请，入口和[吃饭、自习与出门](/campus/food-and-study/)里写的一样。

## 洗衣、理发、修车、电子维修与咖啡

这几类商户数量多、换得也快，所以**只写「集中在哪一片」**，不逐个列店。

- **洗衣店**：集中在**南区 7 号楼、C 楼负一层、观畴园地下、C 楼 013** 等位置。**冬天洗大件先看现场贴的收送时间**，别默认当天能取。
- **理发店**：**C 楼 1 层、C 楼负一层、独峰书院一楼、南区 7 号楼**一带。
- **修车铺**：分布在**照澜院、西南楼社区居委会南侧、桃李园西侧、紫荆园东侧、紫荆公寓 20 号楼旁、小桥西侧南区 5 号楼旁**等位置。**修车铺的位置比打印点更值得提前记一下**——车坏在半路时你不一定还有力气找。
- **电子维修店**：集中在**C 楼负一层、南区 7 号楼、观畴园地下一层、观畴文化长廊**一带。
- **咖啡店**：有**十余家**，多在**图书馆、教学楼和系馆附近**——比如李文正图书馆一层、建筑馆、李兆基科技大楼、医学楼、新清华学堂下沉广场等位置。**想找个地方坐着谈事或者等下一节课，往这些楼里走比往食堂走更稳。**
- **综合服务点**（早餐、菜鸟驿站、配钥匙、电子维修等）：**西区便民服务站**，以及**青楼社区服务站东侧**。
- **商户总分布与优惠活动**：看**商贸与食品安全管理中心的公众号**。**这一页只给分类，不评价任何一家店。**

:::tip
这一页把洗衣、理发、修车、维修、咖啡**按类归到片区**，就是因为你不需要背完整清单：**你需要的只是「这件事大概去哪一片办」**。到了那一片再看门牌，比记住具体店名可靠。
:::

## 报修、缴费与后勤服务平台

这是这一页里**最值得立刻存进手机**的部分。

**清华大学后勤服务平台**：`https://pt.tsinghua.edu.cn`。它能做的事包括部门电话查询、校内宾馆客房预订、车辆预订、校医院挂号、网上报修。**首次使用要先注册，并用学生证号验证**；注意**它与信息门户的账号密码并不互通**，别拿信息门户的密码去登。也可以从「**清华后勤**」公众号进入，在手机端操作。

**宿舍水电费缴纳与设施报修走「清华家园网」**——微信服务号，或 `https://myhome.tsinghua.edu.cn`。**国际学生公寓除外。**

**注册中心 24 小时自助服务厅在 C 楼 102 室**，可以办学期注册、火车票优惠卡充值、在学证明、成绩单与排名打印、学生卡挂失与补卡。**白天人多的时候，来这里自助办比排队窗口快。**

把这三个入口先在手机上打开一次、把账号注册好，**再在真正需要报修的那个晚上**去办，会顺手很多。

## 免费法律咨询

**这是免费的、面向学生的**，遇到合同、纠纷、人身损害这类问题可以先问。

法学院研究生团委与法学院学生法律援助协会面向学生提供**民事、刑事等法律问题的咨询**。时间固定在**教学周每周二、周四下午 13:00–17:00**，**以电话咨询为主，视情况可以预约线下**。咨询电话 **6277 3820、6277 3070**。

**法律与法务办公室**电话 **010-62780910**，工作日 8:00–12:00、13:00–17:00。

:::caution[两件事先分清]
**法律援助是学生组织提供的咨询服务，不等于代理**，也不承诺结果；**涉及正式程序、期限或者金额较大的事**，请走上面的法律与法务办公室，或者自己另找专业律师。另外，**咨询时不要把证件原件、账号密码交出去**。
:::

## 一个更省事的办法

把下面这几个入口存成手机书签或桌面快捷方式，再遇到事就不用现搜：

- `https://pt.tsinghua.edu.cn`——后勤服务平台（报修、查电话、订车订房、校医院挂号）
- `https://myhome.tsinghua.edu.cn`——宿舍水电费与设施报修（国际学生公寓除外）
- 「清华后勤」「清华家园网」两个公众号
- 商贸与食品安全管理中心的公众号——商户总分布与优惠活动

**报修和缴费这两件事，走平台比走人情快。** 平台上有记录，后面催进度时你有依据；口头说了不算。

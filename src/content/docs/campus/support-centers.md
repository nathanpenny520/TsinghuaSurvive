**这四个中心都是学校设的常设机构，面向学生开放，而且不用等到出事才去。**

它们是学校设的常设机构，不是给「已经出问题的人」准备的。选课卡住、睡不好、不知道毕业以后去哪、想练口语和写作——这四类事都有人管，也都能约。这一页先给一张总表，再逐个说清楚它们各自管什么、怎么约，最后把 13 个因材施教计划列成一张表。

## 学习发展中心：从「学不动」到「有方法」

**学生学习与发展指导中心**成立于 **2009 年**，在 **C 楼三层南侧**设有服务台（该中心在 C 楼二、三、四层都有空间，到了按门口指示走），邮箱 `learning@tsinghua.edu.cn`，公众号「乐学」。

它提供五类服务：

| 服务 | 具体是什么 |
| --- | --- |
| **学习资源提供** | 专题培训教材、练习、各科工作坊资料等纸质材料；以及学习方法、可迁移能力、时间规划方面的指导手册与效率手册 |
| **讲座与工作坊** | 通用类与专题类课程，**以班级为单位团体预约**；专题工作坊由 **20–30 名学生组成临时团队**，在专家指导下开展，主题含适应大学生活、英语学习方法、课程学习与备考技巧、时间管理 |
| **一对一咨询** | 由具备咨询资质的教师和高年级学生组成咨询师团队，特等奖学金获得者、优秀毕业生等志愿者参与；**可邮件或电话预约** |
| **基础课学习助力计划** | 由基础课教师、助教、辅导员和志愿者组成，含「**答疑坊**」学生志愿者团队、专题小组辅导、中文写作助理三部分 |
| **小伙伴计划** | 线上打卡 **+** 线下交流，一起早睡早起、读书、背单词、自习 |

**两条最实用的路子**：**基础课卡住**，直接去「答疑坊」这一块；**一个人学不下去**，去「小伙伴计划」找人一起。讲座和工作坊是团体预约的，**想参加就先问自己班里能不能组一支队**。

## 心理发展中心：不需要「病得很重」

**学生心理发展指导中心**成立于 **1988 年**，地址在 **C 楼 404**。预约电话 **010-62782007**，**在校学生专属 24 小时心理热线 010-62785252**，公共邮箱 `xinli@tsinghua.edu.cn`，公众号「清华小清心」。

中心**面向全校学生（含国际学生）**，提供**个体咨询与团体辅导**的预约。

**什么时候可以去？** 连续两周睡不好、吃不下、对什么都提不起兴趣——**就可以去，不需要「病得很重」。** 这是这一节最想让你记住的一句话：中心不是只接待严重情况的，**早去比晚去省事**。

**那条热线是 24 小时的**，不是只在工作时间有人接。如果不确定自己该不该预约，先打过去问一句也行。

## 全球胜任力中心：语言、留学与国际组织

**学生全球胜任力发展指导中心**在 **C 楼 226**，电话 **010-62780238**，邮箱 `thgc@tsinghua.edu.cn`，在线学习平台是 `https://olcgo-global.yuketang.cn/`。

它的**一对一咨询**分五个方向：**全球胜任力发展指导、国际组织人才发展、语言能力提高、出国留学规划、跨文化沟通辅导**。咨询师有 **30 余位，来自不同文化背景**。

除了一对一咨询，还有**国际课程、工作坊、在线学习平台、全球学程项目**等。

**想清楚「毕业以后想去国际组织」这件事的人，越早来越好**——语言和申请都是长周期的事，不是大三下学期临时抱佛脚能补上的。

## 课外活动也有一个中心（TSAC）

**学生课外活动指导中心（TSAC）**成立于 **2022 年 9 月**，挂靠**共青团清华大学委员会**。公众号「学生清华」。

它负责的事包括：**学生课外活动的服务与规范管理**；**学生活动空间（C 楼、南区、北院等）的建设与管理**；**活动室预约**；**物资与失物招领**；**「一站式」服务与智慧化建设**。它还运营「**1911 星球**」学生网络平台。

**办活动要找场地、借物资、丢了东西**，都是这里的业务范围。

## 职业发展中心：课程 + 咨询 + 教练

**学生职业发展指导中心**公众号是「清华职业辅导」。它的资源可以分成三块。

**第一块：课程。** 校内开设 **4 门职业发展课程**，例如：

| 课程 | 面向 |
| --- | --- |
| **大学生职业生涯规划与发展：学业与职业发展** | 大一至大三本科生 |
| **大学生职业生涯规划与发展：求职技能实训** | 大三、大四本科生 |

另有**职业能力提升训练营**与国家精品在线课程**《职业探索与选择》**。这些课程**学期初按需选课**——**错过选课周就要等下一学期**。

**第二块：一对一职业咨询。** 由 **30 余位校内咨询师 + 200 余位校友导师**组成，在**官网预约**，**用户名密码同 info 信息门户**。

**第三块：职业生涯教练计划（COACH 计划）。** 这个计划**常态化运营**，以**行业/企业教练团**为主体，带学员做**座谈、企业参访、技能培训与实习推选**。想接触具体行业里的人，看这一个。

中心还**直接指导 4 家校级社团**：学生职业发展协会、学生求职协会、学生基层公共部门发展研究会、学生全球治理与国际组织发展协会。

**顺序上建议这样用**：大一、大二先上课程把方向想清楚，需要具体信息时约一对一咨询，想进具体行业再看 COACH 计划。

## 因材施教计划：13 个方向，怎么选

除了上面这些中心，学校还有一批**因材施教计划**，各自面向不同方向。它们是**选拔制**，不是报名就能进。**各院系也有具专业特色的因材施教项目**，下面这张表只列校级常被提到的 13 个。

| 计划 | 在培养什么人 |
| --- | --- |
| **思源计划** | 全程匹配各类教育资源、为期三年的学生领导力通识教育，培养具有强烈社会责任感和服务精神的各行业领军人物 |
| **思源骨干计划** | 2007 年由校党委学生部和校团委设立，秉承「饮水思源，服务社会」精神，培养有社会责任感和服务精神的学生骨干 |
| **星火计划** | 整合校内外资源提供个性化、立体化支持，培养具有学术志趣、首创精神、跨学科视野的拔尖创新人才 |
| **启创计划** | 创业课程、项目拓展、创业实践、创业实训与学员考核五个模块，培养具社会责任感、颠覆性创新思维和商业意识的创新创业人才 |
| **薪火计划** | 培养青年志愿公益骨干，引领校园公益文化 |
| **沐风计划** | 长周期培养校园文艺文化活动的鉴赏、组织、统筹与创新能力 |
| **白杨计划** | 小班化授课辅导，以主持人培养为抓手，培养「清华风格」的校园学生主持人才 |
| **星空计划** | 完善学生社团骨干培养体系，通过导师指导、境内实习实践、大型活动锻炼等方式培养社团骨干 |
| **启明计划** | 培养创新型新媒体骨干人才，孵化新媒体平台与文创产品 |
| **林枫计划** | 通过校内外导师指导与海内外实习实践，培养信仰坚定的青年马克思主义者 |
| **烛光计划** | 提供公益支教实践平台，聚焦国家基础教育薄弱地区，培养新型公益支教人才 |
| **高飞计划** | 面向有志于前往国际组织实习任职的本研同学，通过知识学习、外语强化、实习申请辅导、海外走访实践培养全球胜任力 |
| **燎原计划** | 培养具有家国情怀、战略视野、专业能力与国防素质的国防事业领域青年领军人才 |

### 三条选择建议

1. **一次只挑一个对口的。** 这 13 个方向差别很大——学术、创业、公益、文艺、主持、社团、新媒体、国防。**同时参加两三个，通常哪个都做不好**，还会占掉你本来该用来上课和睡觉的时间。
2. **看是不是真的想做那件事。** 表里每一行写的都是「培养什么人」，不是「给你什么待遇」。**先问自己愿不愿意做那件具体的事**——愿不愿意去支教、愿不愿意带队做公益、愿不愿意练主持——再决定报不报。
3. **问清选拔届次与时间，以官方通知为准。** 这些计划的**名称、覆盖范围、选拔节奏每届都可能调整**。要报之前，去**学生部（处）、校团委、院系学生工作办公室的当年通知**里确认，或者直接问带你的辅导员。**别按这一页做决定。**

想同时了解社工岗位怎么选，见[社工体系：怎么选一个能干出结果的岗位](/campus/student-organizations/)——那一页里也提到了培养计划，两页对照看更完整。

## 法律咨询

**这是免费的，面向学生的。** 遇到合同、纠纷、人身损害这类问题可以先问。

**法学院研究生团委**与**法学院学生法律援助协会**面向学生提供**民事、刑事等法律问题的咨询**。时间固定在**教学周每周二、周四下午 13:00–17:00**，**以电话咨询为主**，电话 **6277 3820、6277 3070**。

**注意这是学生组织提供的咨询，不等于代理**，也不承诺结果；涉及正式程序、期限或金额较大的事，另找专业途径。C 楼与校内商户、后勤入口、法律与法务办公室的办事方式写在[C 楼与日常服务](/campus/daily-services/)，那一页有更完整的办事渠道清单。

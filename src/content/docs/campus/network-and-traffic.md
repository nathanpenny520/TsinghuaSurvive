网络问题有两个完全不同的类型，先分清再动手：

- **「连不上 / 认证失败」** —— 接入问题，看本文前半部分；
- **「能上网但下载慢、装包老失败」** —— 出口与源的问题，直接跳到[换镜像源](#换镜像源最省事的提速手段)。

:::caution[先关掉代理和加速器]
这是校内网络问题里最常见的原因之一：**挂着代理或加速器时，校内系统（信息门户、网络学堂、图书馆数据库）经常打不开**，
因为它们需要走校内网络出口。遇到「昨天还能用今天打不开」，第一件事是把代理关掉再试。
:::

## 接入：无线、有线与认证

学校的无线网用 802.1X 认证，**不需要每次打开浏览器登录**，但需要先在自服务系统里给 802.1X
单独设一个密码（很多人的第一次卡壳就在这一步）：

1. 用校园网账号登录自助服务系统 <https://usereg.tsinghua.edu.cn>；
2. 在里面找到 802.1X 相关的功能，**注册/修改 802.1X 密码**；
3. 在设备的无线设置里连接校园无线网，用户名填**校园网账号**，密码填**上一步设的 802.1X 密码**。

:::tip[为什么要单独设一个密码]
802.1X 密码和校园网账号密码是两套东西，**不要设成同一个**。
如果 802.1X 密码忘了或者被改过，表现就是「手机能连、电脑连不上」或者「一直提示密码错误」——回自服务系统重设即可。
:::

不同系统的配置细节（Windows / macOS / iOS / Android / Linux）以及 SSID 名称，
以**信息化用户服务平台上的说明**为准：<https://its.tsinghua.edu.cn/>。
不要照抄网上搜到的旧教程，界面早就变了。

**有线网**：宿舍与实验室的网口一般是插上就用，首次可能需要认证一次。宿舍端口的位置和可用性问宿舍楼管或院系。

## 在校外访问校内资源：WebVPN

放假回家、实习期间要查文献或进校内系统，用 [WebVPN](https://webvpn.tsinghua.edu.cn/)，
不要用第三方的「代理网站」——那些既不稳定，也意味着你要把账号交出去。

:::danger[不要把校园网账号给别人用]
账号外借既违反学校规定，也会让**你自己**承担别人操作的后果（流量、访问记录都算在你头上）。
需要用校外资源，走 WebVPN 或图书馆的校外访问入口。
:::

## 流量：为什么「刷视频很快，下论文很慢」

校园网对**境外流量**与校内流量是分开计量的：

- 访问校内、国内站点，通常不计入境外流量；
- 访问境外站点（Google、GitHub、arXiv、PyPI、YouTube 等）走国际出口，**有单独的配额与计费规则**；
- 所以「在校园网里下 PyPI 包」和「下国内镜像的同一个包」，体验和代价完全不同 —— 这也是下一节要说的。

具体额度、计费方式和超量后的处理，**以信息化用户服务平台和网络服务说明为准**。
本文不给数字：政策每年可能调整，写死一个数只会误导人。

一个被低估的做法：**把常用的开发工具源换到国内镜像**。省下的不只是时间，还有国际流量。

## 换镜像源：最省事的提速手段

原理很简单：这些命令只是把「去哪下载」从官方源改成国内的镜像站，**包的内容是一样的**。

### Python：pip

```bash
# 临时用一次
pip install -i https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple 包名

# 设为默认（推荐）
python -m pip install --upgrade pip
pip config set global.index-url https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple
```

### Node.js：npm

```bash
npm config set registry https://registry.npmmirror.com
# 想改回官方源
npm config set registry https://registry.npmjs.org
```

### 其他生态（conda / apt / Homebrew / Docker / Rust…）

不要记命令，直接看官方的换源说明页，每个生态都有一份、且持续更新：

**<https://mirrors.tuna.tsinghua.edu.cn/help/>**

:::caution[换源的两个坑]
1. **别把源删了重装**。改配置之前先记下原来的值（`pip config list`、`npm config get registry`），
   出问题能改回去。
2. **镜像同步有延迟**。刚发布的版本可能还没同步过来，装不上时先换回官方源试一次，
   确认是「包没同步」而不是你的环境坏了。
:::

## 连不上的排查顺序

按这个顺序走，能解决九成问题：

| 顺序 | 检查什么 | 常见结论 |
| --- | --- | --- |
| 1 | **代理/加速器是否开着** | 关掉再试。校内系统最容易被它挡住 |
| 2 | **账号与 802.1X 密码** | 提示密码错误就去 <https://usereg.tsinghua.edu.cn> 重设 |
| 3 | **换个设备/换个位置** | 手机能连、电脑不能连 → 是设备配置问题；都连不上 → 是账号或区域覆盖问题 |
| 4 | **忘记网络后重连** | 系统里存了旧密码时，表现就是「一直转圈」 |
| 5 | **访问的是不是校内系统** | 校外访问校内系统必须先连 WebVPN |
| 6 | **DNS 解析** | 校内 DNS 会缓存解析失败的结果，新绑定的域名可能要等一段时间才生效 |
| 7 | **还是不行** | 带着「什么设备、在哪、报什么错、什么时候开始」去找信息化用户服务平台，比说「上不了网」有效得多 |

:::tip[报修时说什么]
「什么时候开始、在哪个楼、什么设备、完整报错截图、已经试过哪些办法」——
这五件事说清楚，处理速度会快很多。只说「网断了」通常会被要求补充信息。
:::

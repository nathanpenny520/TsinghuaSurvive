"审美是感受"这句话没错，但**感受是可以被解释的**。同一张海报改一改，为什么就是更顺眼？答案通常落在四件事上：**层级、点线面、留白、对称**。

这一页讲的是判断标准——它同时适用于海报、推送、PPT、封面和展板。

:::tip[先给结论]
版式设计最核心的目的只有一个：**明确地突出版面的层级结构**，让版面"先看什么、再看什么"一目了然。

实现它的手段只有两条：**放大画面重点**、**降低次重点的字号大小或透明度**。
如果你做完一张图，自己都说不清第一眼看的是什么，那它不是"风格问题"，是没做版式。
:::

## 一、没有版式 vs 有版式

| | 表现 |
| --- | --- |
| **没有版式** | 画面呆板，一眼看过去不知道是先看字还是先看画；所有元素一样大、一样重 |
| **有版式** | 主体和主标题被突出，视线有明确落点；**对角线排版**这类结构还会给画面加张力 |

**判断方法**：把图缩小到手机缩略图大小，眯着眼看。如果还能一眼看出"这张图在说什么"，版式就是成立的。

## 二、点是引导，线有性格，面是第一视觉

画面上的所有元素，都可以按"占多大、起什么作用"归成三类。

### 点

点是最小的视觉单位，作用比它看起来大得多：

- **标注画面的重点**；
- **引导视线**——一排点会让眼睛顺着走；
- **关联与对比**——把相关的信息用点连起来；
- **连续的点构成线**（点动成线）；
- **增加画面的丰富度**——留白太多时，几个点就能"填"住而不显乱。

**实操**：把点放在角落、放在留白处，用来平衡画面；不要平均撒满，那会变成噪点。

### 线

线是形的轮廓、面的边缘，也是点的运行轨迹。**线产生的视觉感受比点更强烈，也更有性格**：

| 线的形态 | 给人的感受 | 适合用在 |
| --- | --- | --- |
| **横线** | 平衡、稳定 | 分割信息、承载标题 |
| **曲线** | 柔美、流动 | 文艺、生活、人文类主题 |
| **折线** | 科技、刚硬 | 科创、竞赛、数据类主题 |

### 面

**面是最显眼、最重要的第一视觉**——比如一张图片、一行很大的字。面的性格：

- **直线型的面**：稳定、简洁；
- **曲线型的面**：随意、舒适。

两个扩展概念：

- **正负形**：有颜色的地方是"正"，剩下的空间是"负"。**负形也是设计的一部分**——留白不是浪费。
- **装饰性的面**：与主题有关的人物、事物，可以作为一个面压在画面上做遮挡（见下一节的"双重曝光"）。

## 三、格式塔原理：大脑偏爱什么

格式塔讲的是"人眼如何自动组织画面"。对做图来说，最有用的是两条：

### 简洁律

**大脑偏爱简单、对称、稳定、规则的图形。**

由此得到两条几乎万能的技巧：

1. **给画面留出边距，让画面有呼吸的空间。** 元素贴边是新手最典型的破绽。
2. **对称构图 + 几何化。** 拿不准怎么排时，先对称、再把元素归纳成几何形状，八成不会难看。

### 连续性

**残缺的线条、形状、运动趋势，会被大脑自动补成连续流畅的物体。**

由此得到一个反直觉但有奇效的技巧：**适当残缺会增强画面的设计感**。常用的两种做法：

- **双重曝光**：把两个图像叠在一起，让它们互相"穿透"；
- **用几何元素遮挡**：用一个色块或形状盖住主体的一部分，画面立刻有了层次和艺术气息。

:::note[为什么这两条值得背下来]
因为它们把"我觉得这样好看"变成了**可以说明理由的判断**。评审时你说"这里留白不够、元素贴边了"，比说"我感觉不太行"有用得多；改稿时你也知道该改哪一处。
:::

## 四、审美靠输入，不靠天赋

**审美是感受，而感受来自看过的东西。** 想快速提升，输入比练习更缺：

- **多看海报**，尤其是**电影海报**——它们是全世界设计师里竞争最激烈的一类作品，构图、主次、字体的处理都极其成熟。
- **看经典设计**：把喜欢的存下来，攒一个自己的素材库。
- **带着问题看**：不要只存图，存的时候写一句"我喜欢它哪里"（是层级清楚？是留白舒服？是颜色克制？）。

### 三步练法

1. **看**：找同一主题的三张不同设计，选出你最喜欢的一张，说出**三个理由**。
2. **拆**：把那张图的主标题、副标题、主体、辅助信息分别用框圈出来，看它们的字号倍数关系和位置关系。
3. **改**：拿自己的作品，按拆出来的规律重排一遍，和原版对比。

:::tip[一个便宜的练习]
拿一篇你们组织的旧推送封面，只做一件事：**把不重要的字变小、变淡，把最重要的那行放大**。不改颜色、不换图。对比前后两版，你会立刻理解"层级"是什么。
:::

## 五、出稿前自检

- [ ] 眯眼看缩略图，能一眼说出"这张图在说什么"
- [ ] 画面里只有**一个**第一视觉（主体或主标题）
- [ ] 次重点的字号/透明度**真的**降下来了（不是只降了一点点）
- [ ] 四周**有留白**，没有文字或图形贴边
- [ ] 配色不超过三种主色，且符合主题性格（严肃 / 活泼）
- [ ] 装饰元素没有抢主体
- [ ] 缩小到手机尺寸，最小的字仍然看得清（海报上的小字在手机里通常等于不存在）
- [ ] 文字**没有错别字**（这一条在评审时比任何美感问题都致命）

## 六、常见坑

:::caution
- **每样东西都加粗放大。** 全都强调等于没有强调。
- **元素塞满整张图。** 不留白的画面读起来很累，且没有重点。
- **装饰抢主体。** 用了很漂亮的花纹，结果没人看见活动名称。
- **配色凭喜好。** 红配绿、高饱和撞色并不是"活泼"，是刺眼；不确定就用单色系 + 一个强调色。
- **字体用了四五种。** 一种标题字 + 一种正文字就够，最多再加一种点缀。
- **只在电脑上看。** 和推送一样，海报和封面绝大多数时候是在手机上被看到的。
- **为了"设计感"牺牲信息。** 忘记读者是来找时间地点和报名方式的。
:::

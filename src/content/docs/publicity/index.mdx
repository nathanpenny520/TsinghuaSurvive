**宣传不是"发通知"。** 发通知只要求信息发出去了；宣传要求看到的人**看懂、记住、并且愿意动一下**——报名、转发、来现场。

这一页解决三个问题：**宣传岗真正在做什么**、**五项手艺怎么分工**、**你该从哪一项开始学**。

:::tip[先给结论]
任何一次宣传的落点都是四句话：**内容突出、主次分明、版式美观、色彩和谐**。

前两句是"想清楚"，后两句是"做出来"。落到手上就是五个动作：**把话说清楚 → 把它排好看 → 需要图就做图 → 没图就去拍 → 动起来就剪视频。**
只做其中一个动作的人很多，能连着做完的人才稀缺。
:::

## 一、宣传岗的五项手艺

这五项不是并列的"技能包"，而是**一条流水线上的五道工序**。一场活动的宣传通常按这个顺序发生：

| 工序 | 你第一次真的会用到它，通常是…… | 这一篇讲什么 |
| --- | --- | --- |
| [推送制作与排版](/publicity/wechat-article/) | 部长说"这条推送你来出" | 秀米的排版逻辑、字号行距的成套规范、SVG 与长图兜底 |
| [平面设计](/publicity/graphic-design/) | 要做一张海报、封面、易拉宝 | 层级怎么定、点线面怎么用、为什么"好看"能被解释 |
| [活动摄影](/publicity/event-photography/) | 被派去拍一场活动，回来要交图 | 全流程 SOP、参数与焦段、横平竖直、合照专题 |
| [照片快速后期](/publicity/photo-postprocessing/) | 拍完当天就得返图 | 一套能"调一张、同步整组"的批量流程 |
| [活动视频](/publicity/video-basics/) | 要做一条活动回顾或实践记录 | 为什么前期比后期重要、素材怎么拍够、剪辑怎么起手 |

:::note[顺序不是随意的]
前一项是后一项的输入：**没有照片，后期无从谈起；没有排版规范，做好的图放进推送也会乱。** 所以如果只想先学一项，学[推送排版](/publicity/wechat-article/)——它是所有宣传物的最终容器。
:::

## 二、宣传的三种"形态"和两种"风格"

同样一件事，可以做成不同的东西。选之前先明确它是什么：

| 维度 | 常见取值 | 影响 |
| --- | --- | --- |
| **形式** | 推送、平面海报、短视频 | 决定流程长短：推送当天能出，视频通常要好几轮 |
| **风格** | 严肃细致 / 活泼有趣 | 决定字号、配色、字体与图的比例，而不是"随便选个模板" |
| **题材** | 上级指定任务 / 自己创意的小众选题 | 指定任务先保准确与合规，创意选题才轮到"出彩" |

**最常出的问题不是做得不好看，而是"形式选错了"**：一件需要交代清楚规则的事被做成了九宫格海报，一份只需要三行通知的事被做成了五分钟视频。先定形式，再谈美观。

## 三、这个板块怎么用

1. **救火式**（最常见）。今天就要交东西，直接跳到对应那一篇，只看「最小可用路径」和「出稿前自检」两节。
2. **备着**。花二十分钟把五篇的「先给结论」和「常见坑」过一遍，知道有哪些坑存在。等你真的被派活时，至少知道该回来看哪一篇。
3. **按一条主线学**。想认真做宣传岗：排版 → 摄影 → 后期 → 设计 → 视频。前四项一两周能到"能用"，视频值得慢慢磨。

:::tip[别一上来就学软件]
秀米、可画、Lightroom、剪映——软件的按钮会变，**判断"这版为什么比那版顺眼"的能力不会变**。这个板块每篇都在先讲判断，再讲软件。
:::

## 四、和社工岗位的关系

宣传是社工里**产出最直观**的一类岗位：你有署名或至少可追溯的作品，年底能说出"我运营了什么、做了几条、数据大概什么样"。

- 选岗位的逻辑见[社工体系：怎么选一个能干出结果的岗位](/campus/student-organizations/)；
- 宣传委员、宣传组、新媒体组这些岗位的"真实的一天"就是上面这条流水线；
- **作品集从大一开始攒**：把做过的推送、海报、活动照片按月存一个文件夹。到评奖学金、找实习时，这是极少数能直接拿出来看的东西。

## 五、本板块不写什么

- **不写任何账号与密码**，不贴内部系统截图，不写具体的发布审批流程（每个院系不一样，问带你的人）。
- **不写"怎么刷数据"**：阅读量、点赞量的技巧性操作，不属于宣传。
- **不评价具体的人、组织或作品**。这一页只讲判断标准。
- **不推荐付费软件**：有免费方案就先讲免费方案；需要商业软件时，先确认学校或院系有没有正版授权渠道。

:::note[本板块的时效约定]
这一板块写的是**方法和判断**，不依赖某一年的制度，因此不标注"核对日期"。
但其中涉及**校内资源**的部分（能借到什么设备、有没有正版软件授权、云盘的限制）会变——这类内容一律写"以你所在院系/学校的说明为准"，不做逐条承诺。
:::

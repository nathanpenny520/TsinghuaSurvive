活动照片是宣传物料里最容易将就、也最容易露怯的一环：推送、海报、新闻稿都要用它，而**一场活动最后真正能用的照片往往只有几张**。

这一页按"案例 → 流程 → 规范 → 专题 → 装备 → 速查"的顺序写，可以整篇读，也可以只在被派活的那天翻速查表。

:::tip[先给结论]
活动照片遵循一条优先级：**先保证可用，再追求好看。**

"可用"的门槛是三条硬线：**横平竖直、关键人物睁眼、曝光和肤色正常**。
另一方面，**拍摄时多拍无妨**——多拍才有选片余地，也才可能挑出真正好的那张。
:::

## 一、质量底线：能看、能用、不砸门面

面向宣传使用的照片，底线是"能看、能用、不砸门面"。判断标准很朴素：**这张图放在推送里，会不会让人一眼看出"没人管"？**

## 二、先学会分辨好坏：常见问题

这些是"不能上推送"的典型问题，认得出它们，你才知道现场该避开什么：

- **画面过暗、倾斜、没有主体、构图过满**——随手拍的四个典型特征，在推送里最显眼。
- **合影拍歪**：画面结构没有对齐（可以拿背景文字、地砖线、人物站位作参照）。
- **投影仪摩尔纹**：教室投影是横向刷新的光源，快门采样频率较高时会在画面里形成彩色条纹，需要规避。同时注意曝光正确、肤色正常——**黑要够黑，脸不能发黄没气色**。
- **未经整理的"黑照"**：高校官号偶尔放出没挑过的活动照，多半是拍摄者不够上心。

:::note[要求可以按重要性浮动]
如果活动本身不重要（比如只是凑数办的一场），照片要求可以相应放宽。**这不是标准松了，是把力气花在重要的活动上。**
:::

## 三、好照片长什么样

- **表情抓拍到位、构图得当、面光充足**（合影、指挥、颁奖这类瞬间）。
- **领导/嘉宾致辞**：提前准备，抓拍自然瞬间，而不是等对方看镜头。
- **人物抓拍**讲究灯光与构图，善用**背景虚化**去掉杂乱环境。
- **可用合影的标准**：横平竖直，关键人物全部睁眼；**重要活动要求全员睁眼**。
- **机位**：与嘉宾**平视或略低**的位置更显正式、有分量；必要时可以开闪光灯补面光（不开通常也不是大问题）。

## 四、全流程 SOP

### 4.1 拍摄前：沟通与准备

- **与主办方沟通**（或者你自己就是主办方）：确认活动时间安排、需要的照片类型（嘉宾特写、全场概览、物料合影等）以及有没有样例参考。**这一步可以线上远程完成。**
- **提前 10–20 分钟到场**，勘察场地，确定机位与站位。**越重要的活动到得越早**——有领导致辞的活动，开场几句话没拍到就麻烦了。
- **"重要程度"怎么衡量**：看两个指标——**照片最终所上媒体的级别**、**活动的主办层级**。

### 4.2 选座与站位

选座的核心目的是两件事：**方便进出**、**方便拍嘉宾讲话**。

- **优先选**：第一排边上、中间侧面、靠过道的座位，或最后一排靠边。
- **大教室坐前 3–5 排**。坐得太远，前面的嘉宾根本拍不到。

### 4.3 开场

- **开场前 1–2 分钟就位**，先拍**主持人特写**与**活动全景**。
- **合照时机要提前决策**：合照一般放在最后，但**多数活动越到后面人越少**——可以和主办方沟通，在开场后插入合照环节，或安排在第一位嘉宾讲完之后。重要活动也可以留在最后（由主持人收尾时组织）。

### 4.4 各环节拍什么

| 环节 | 拍什么 | 要点 |
| --- | --- | --- |
| 嘉宾讲话 | **半身像 + 全景**的组合 | 拍到可用的就回座，不要来回走动干扰活动 |
| 互动 / 提问 | 观众特写；嘉宾与观众**同框**的互动镜头 | 互动是活动质量最直观的证据 |
| 游戏 / 自由讨论 / 小组 | 观众特写，记录"他们在做什么" | 别只拍空场 |
| 物料 | 物料与活动的合影 | **最容易漏**，别忘 |
| 结尾 | 合照 | 见第八节 |

### 4.5 站位与焦段

**画框与站位共同决定成片**：站位决定透视关系，画框决定所需焦段。

| 拍摄对象 | 建议焦段 / 视角 | 要点 |
| --- | --- | --- |
| **半身特写** | 全幅 **50–85mm** | 避免 35mm 近距离"怼脸"（透视过强）；24–70 的 50–70mm 端即可，站位稍靠后 |
| **全景** | 广角至标准，**尽量退后** | 退后取温和透视，避免过广的夸张变形 |
| **合照** | 广角，**尽量退远** | 后移可以减小透视、提高成片率 |

### 4.6 结尾：合照与收尾

如果合照留到最后拍，**务必留住人**：

1. 提前请主持人配合，在结束时宣布"接下来拍合照，大家先不要走"；
2. 然后"**3、2、1**"按快门；
3. 或者主持人话音刚落，立刻到台前组织——**不要等嘉宾和观众开始离场**。

## 五、成片规范与参数

### 5.1 横版为主

推送排版以**横版**为宜（**3:2 或 4:3**）。竖版不利于推送排版；而**横版照片裁成竖图后，分辨率依然够手机和电脑观看**——所以先拍横版，需要竖版再裁。

### 5.2 快门速度

**不快不慢。** 活动场景动作幅度小：

- **1/100 已经足够**，提到 **1/200 完全够用**；
- 回看发现画面糊了，再适当提高；
- 实操上也可以**先稍微降低快门保证进光量，糊了再调高**。

### 5.3 光圈与景深

**"该清楚的地方必须清楚"**：后排屏幕上的文字、前排的人脸都要清楚。

- 合照要求**前后排人脸都清楚**，其中**前排嘉宾的脸最重要**；
- **技巧**：光学上"**前景深短于后景深**"，所以**焦点放在嘉宾身上或略靠后**，能获得更大的清晰范围。

### 5.4 画质不必追求极致

活动照片对画质和动态范围的要求并不高，没有必要上中画幅、一亿像素级的机身。

- **一个实用思路**：用高像素机身 + 中短焦段（50–70mm）近拍，后期裁切"偷焦段"——例如把 6100 万像素裁到 2000 万左右，相当于获得约 1.5 倍焦段系数，画质仍够推送与手机观看，**可以减少镜头配置**。
- **代价**：高像素会带来存储压力和后期压力。

:::tip[像素量参考]
活动照片基本都会放在推送/新闻稿里，对像素量要求不高（**合影除外**）——普通手机、2400 万像素、甚至 1100 万像素的相机都是足够的。
:::

### 5.5 手机拍摄

手机画质有限，但完全可行；**能借到相机时优先用相机**。

- **长焦是短板**：放大到 2 倍左右明显变糊。标准端（24–28mm）放大 **1.3–1.4 倍**（等效约 40–50mm）尚可，**尽量不要再放大**。
- **优先自动模式**：专业模式反而失去 AI 加成，画质未必更好。
- **摩尔纹**：多点几下屏幕，手机通常能自动消除；仍不行可以开专业模式、把快门降到 **1/50–1/100**。
- **眩光**：投影或窗外强光容易引起眩光、让画面发灰；**找角度规避**，实在规避不了就以能否接受为准。

### 5.6 曝光与色彩

**曝光务必准确**：前期把曝光做到位，后期尽量不再大改，效率更高。**色彩前期尽量标准**（肤色正常），实在不行再后期补救。

### 5.7 连拍

嘉宾讲话时表情多变（闭眼、嘟嘴、张口过大都不能用）。为保证快速拿到可用照片，**可以开连拍**：

- 每次连拍 **6–7 张足够**，一次或两次连拍基本能命中；
- **拍完立即回座**，减少对活动的干扰。

## 六、横平竖直：姿势与基本功

**前期做到位，后期就不需要校正。**

- **握持**：两臂夹紧、身体与手保持端正，正常握姿下画面就是水平的；**身体稍歪，画面就歪**。
- **竖拍**：右臂可以略放松，**左臂务必夹紧**。
- **跪姿（低机位）**：屁股坐在右脚脚跟上、膝盖点地，手臂撑在膝盖上——稳定，而且容易保持横平竖直。
- **手机同理。**

## 七、合照专题

### 7.1 能不接片就不接片

接片麻烦而且容易失败——要拍好几张才能拼出一张。**一张广角能装下的合照，就直接一张拍完。**

确需接片时：

- **尽量往后退**，提高接片成功率；
- **相机竖拍取景**，上下留出空余；
- **相邻两张重叠约 1/3**；
- 接片后**矫正透视**，尽量做到横平竖直。

:::caution[中心旋转接片的先天缺陷]
站在场地中心旋转接片，透视影响不可避免，**无法做到全程横平竖直**。除非你在场地一侧平移拍摄（从这头一路拍到那头）。
:::

### 7.2 防闭眼连拍法

口令流程：**"大家准备一下——3、2、1！"**，同时按下快门。

- 前几张常有人闭眼，**第 3、4 张通常较好**；
- **每次连拍 3–4 张**；可以连续两轮（**"3、2、1"连拍 4 张 × 2**），共 8 张保底。

### 7.3 闭眼与表情补救

实在有人闭眼或表情不佳：

- **手动拼合**（免费）：从多张连拍里各取可用部位，拼到同一张上；
- **商业 AI 人像修图工具**：可以替换闭眼或表情，属于付费方案，用到再了解。

## 八、装备与工作习惯

### 8.1 镜头方案

| 用途 | 建议镜头 |
| --- | --- |
| **合照** | 广角：16–35（或 16 定、15–30、14–24、12–24 等） |
| **全景 + 特写** | 标准变焦：24–105 或 24–70 |
| **裁切机身** | 可用 16–35 拍完再裁，够用 |

一个**广角 + 一个标准变焦**是学生活动摄影最常见的双镜方案，能覆盖绝大多数场景。

### 8.2 存储、交付与备份

- **照片再"烂"，只要你觉得可能有用，也要交给活动方**——万一对方觉得重要。
- **现场不要删照片。**
- **原片在返图后保留一段时间**（一两个月，或到学期结束再删），以备对方索取底片、补选照片，或照片出问题时留存底。
- **重要活动开双卡备份**（双卡槽备份选项）。
- **电量必须充足**：带备用电池，或用支持充电宝直充的相机。

### 8.3 照片直播

有的活动会使用付费的**照片直播服务**（实时上传、扫码看图）。两件事要注意：

- **直播需要设置封面**，封面主视觉向主办方索取；
- 默认转发会带上平台角标，看起来不够正式；**可以先转发到自己的文件传输助手，再从那里转发到活动大群**，角标就没了。

### 8.4 现场礼仪

- **非必要不开闪光灯**：闪光灯吸引注意、干扰活动。
- **着装低调**（例如全身深色系），降低自己的存在感。

## 九、后期与返图

**活动摄影时效性强，应当天或一两天内返图。** 后期工作量不算大，重点在于：

| 步骤 | 做什么 |
| --- | --- |
| **筛片** | 剔除不可用照片——**这是主要工作量** |
| **校色** | 校准明显不准的颜色，让人物肤色回到正常亮度与色偏（**不暖、不冷、不绿**）；特别留意灯光杂乱、廉价灯光导致的人脸发怪 |
| **调亮度** | 调整整体亮度，与环境匹配 |
| **校横平竖直** | **正式活动成片必须横平竖直，不能歪** |
| **屏幕内容** | 在保证人脸亮度正常的同时，投影/屏幕上的内容最好也能辨认（例如黑色文字可读） |

:::caution[前期必须保留细节]
屏幕内容要能看清，前提是**前期没有过曝**——宁可把人物压暗一两档，后期拉回后色彩依然正常；**前期已彻底过曝的部分无法补救**。
:::

**交付渠道**：成片整理时，数量不多可以不分文件夹，较多时按场次/内容分文件夹。校内交付一般用**清华云盘**；商业拍摄的行业惯例是百度网盘。

批量后期的具体操作见[照片快速后期：当天返图的批量流程](/publicity/photo-postprocessing/)。

## 十、如果想接商拍

上面这套流程**完全适用于商业活动拍摄**，可以作为兼职接单的起点。

- **报价参考**：一场活动 2–4 小时约 500 元，时薪尚可；
- **接单渠道需要自己积累**；
- **多拍多传**：商拍多出片，甲方更满意。

:::note[和校内活动的差别]
商拍对**交付时间和成片数量**的要求更硬，但对"记录活动"这件事的判断是一样的：先保证可用，再追求好看。
:::

## 十一、速查手册

### 拍摄前检查清单

| 类别 | 检查项 |
| --- | --- |
| 沟通 | 与主办方确认时间安排、所需照片类型、样例参考 |
| 器材 | 机身、镜头（广角 + 标准变焦）、备用电池 / 充电宝、存储卡余量 |
| 备份 | 重要活动开启双卡备份 |
| 到场 | 提前 10–20 分钟；活动越重要到得越早 |
| 座位 | 第一排边上 / 中间侧面 / 靠过道 / 末排；大教室坐前 3–5 排 |
| 开场 | 提前 1–2 分钟就位；主持特写 + 活动全景；**考虑是否安排合照环节** |
| 结尾 | 合照留人（请主持人配合）；"3、2、1"连拍 |

### 全流程速查表

| 阶段 | 关键动作 | 要点 |
| --- | --- | --- |
| **拍摄前** | 线上沟通、确认需求与样例；提前到场踩点 | 时间安排、照片类型；重要程度决定到场时间 |
| **开场** | 主持特写 + 活动全景 | 提前 1–2 分钟就位 |
| **合照** | 开场后或结尾组织 | 人多时提前拍；重要活动可留到最后 |
| **嘉宾讲话** | 半身像 + 全景 | 拍到可用即回座 |
| **互动 / 讨论** | 观众特写、嘉宾—观众同框 | 记录现场状态 |
| **物料** | 物料与活动的合影 | **勿遗漏** |
| **后期** | 筛片、校色、调亮度、校横平竖直 | 当天或一两天内返图 |
| **返图** | 清华云盘（校内）/ 百度网盘（商拍） | 按量决定是否分文件夹 |

## 十二、常见坑

:::caution
- **到得太晚。** 开场前 1–2 分钟才到，主持人特写和全景就没了。
- **只拍大头照。** 人物特写要带背景，否则照片说明不了"这是一场什么活动"。
- **合照拖到最后。** 人已经走了一半，只能凑一张缺人的合影。
- **不开连拍。** 嘉宾讲话十张里九张闭眼，回去没得挑。
- **现场删照片。** 你觉得不好看的，活动方可能正好要用。
- **拿竖版当主力。** 推送排版会很难受。
- **拍完就撒手。** 当天不返图，宣传物料就赶不上热度。
- **忘记物料合影。** 主办方最常回头找的就是这一张。
- **站位挡人。** 为了拍好照片在嘉宾面前走来走去，是比照片不好看更严重的问题。
:::

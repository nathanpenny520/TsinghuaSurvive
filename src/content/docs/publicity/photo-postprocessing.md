活动照片的后期**不是"精修"**，而是"在一两个小时内把两百张变成能发的三十张"。所以它拼的不是技术，是**流程**：能把一次调整复制到整组，就赢了。

这一页给的是一条可以照做的顺序——调好一张，同步整组，批量导出。

:::tip[先给结论]
只要记住两件事，返图速度会翻倍：

1. **拍摄时一定要拍 RAW**（或 RAW+JPG 双格式）。很多自动配色功能只对 RAW 生效，用 JPG 后期空间会大幅受限，等于把这条捷径堵死了。
2. **永远不要一张一张手调。** 调好一张 → 全选 → **同步** → 批量导出。
:::

## 一、第零点：一定要拍 RAW

这是整条流程的前提：

- **只有 RAW 文件在"配置文件"里才有"随样性颜色"这个选项**，JPG 直出照片没有；
- RAW 的可恢复空间（高光、阴影、白平衡）远大于 JPG；
- 相机设置里把输出格式设为 **RAW** 或 **RAW+JPG**。

:::caution[拍完才发现是 JPG 就晚了]
这是**唯一一个事后无法补救**的环节。带相机出门前，先确认格式设置——尤其是借来的相机。
:::

## 二、工具

用 **Lightroom**（桌面版）做批量后期。它的核心优势是"一张调好、整组同步"，正好对上活动照片的场景。

关于授权：**正版授权渠道以你所在院系/学校的当前说明为准**，先确认有没有可用的正版方案，不要用来路不明的版本处理需要交付的作品。

## 三、六步流程

### 第 1 步：导入与自动调色

1. 打开 Lightroom，在**「图库」**窗口导入活动照片；
2. 点击**「修改照片」**切换到调整界面；
3. 点击**「配置文件」** → 选择**「随样性颜色」**。

**点击之后，照片会自动调整好大致的颜色。** 这是整条流程里性价比最高的一次点击。

然后**看情况手动微调**：

| 调整项 | 一般做法 |
| --- | --- |
| 曝光 | **稍微加一点** |
| 高光 | **减一些**（减到 -100 都没事） |
| 阴影 | **提高一些**（让明暗信息分布更均匀） |
| 对比度 / 饱和度 | 想更好看就加**一点点** |

### 第 2 步：检查暗部与降噪

**放大查看暗部**，如果有明显的**彩噪**，就需要降噪。

- 勾选 **「去杂色」**（AI 降噪）；
- **这个功能耗时较久，一张照片可能要十多秒**——所以**只对噪点确实影响观感的照片做**，不要整组无脑勾。

### 第 3 步：几何校正（Upright）

找到**「变换」**里的 **Upright**，点击**「自动」**，它会自动把画面调成横平竖直。

:::tip[这一步能救回大量照片]
活动照片最常见的毛病就是"歪"。手动拉直一张要半分钟，自动校正一次一秒钟。**先让 Upright 跑一遍，再回头看不顺眼的个别照片。**
:::

### 第 4 步：批量同步到整组

1. 在底部的胶片栏**点选那张已经调好的照片**；
2. **Ctrl+A / Cmd+A 全选**；
3. 点击**「同步」**；
4. **勾选你要同步的项目**——注意**「细节」那一项可以不勾**，因为降噪很耗时间，可以只挑出那些噪点极度影响观感的照片单独降噪；
5. 点击**「同步」**，等它跑完。

:::caution[同步勾选是这套流程里最容易做错的一步]
勾多了（比如把降噪也同步），整组同步会变得很慢；勾少了（比如漏了 Upright），你会发现照片还是歪的。**第一次用的时候看清每一项再勾，之后按同一套勾法走。**
:::

### 第 5 步：导出

1. 回到**「图库」**界面，**全选**照片，点击**「导出」**；
2. 选好目标文件夹；
3. 勾选**「重命名为」**，在右侧选择重命名方式：**「自定名称 - 序列编号」**；
4. 在**「自定文本」**里输入**本次活动名称**；
5. **「图像格式」选 JPEG**，色彩空间用默认；
6. 勾选**「文件大小限制」**，设置为 **5000K（约 5MB）**。

**为什么限制在 5MB 左右**：

- 活动照片基本都用在推送里，**5MB 的图细节已经足够丰富**；
- 更小的文件在各类云盘里预览更稳，不会因为太大而打不开或预览出错；
- 原片仍然在你本地，需要时随时能再导。

### 第 6 步：上传云盘并交付

- 上传到**清华云盘**（校内活动的常用交付方式）；
- **文件夹命名为「日期_活动」**，日期写成类似 `260903` 这样的格式（两位年 + 月 + 日）；
- 把分享链接发给活动方。

:::tip[命名一定不要偷懒]
一个学期下来你会交付十几场活动。"新建文件夹 (3)" 这种命名，三个月后连你自己都分不清哪张图是哪场活动的。
**「日期_活动名」**是最省事也最不容易错的格式。
:::

## 四、出稿前自检

- [ ] 拍摄格式是 **RAW**（不是只拍了 JPG）
- [ ] 「随样性颜色」跑过，且手动微调过曝光/高光/阴影
- [ ] 放大查过暗部，**明显彩噪的照片单独降过噪**
- [ ] **Upright 自动校正跑过**，成片横平竖直
- [ ] 用**同步**处理整组，没有一张一张手调
- [ ] 导出为 **JPEG**，文件大小限制在 **5MB 左右**
- [ ] **重命名带活动名称 + 序列编号**
- [ ] 上传云盘，文件夹名是**「日期_活动」**
- [ ] 交付前**抽看开头、中间、结尾各几张**，确认没有漏掉坏图

## 五、常见坑

:::caution
- **拍 JPG。** 后面所有自动功能都打折，且高光阴影救不回来。
- **一张一张手调。** 两百张照片不可能靠手调做完，必须用同步。
- **同步时把降噪一起勾上。** 整组同步会慢到你以为软件卡死了。
- **导出 20MB 的原图。** 云盘预览慢，推送也用不上，白白浪费时间和流量。
- **导出文件名是相机默认的 `IMG_1234`。** 活动一多就再也找不回来。
- **不做横平竖直校正。** 这是正式成片的硬要求，且自动校正只要一秒。
- **导出后不看就交付。** 至少抽看首中尾，避免把坏图发出去。
- **忘记保留原片。** 活动方过一两周回头要底片、要补选照片是常事。
:::

大学里很多"莫名其妙就尴尬了"的时刻，不是因为你不够聪明，而是因为**没人教过这类事的默认规则**：什么时候该发邮件而不是微信、问问题该怎么开头、在群里说什么会被记住、第一次见面要注意什么。

这一页把这件事拆成可以照着做的动作。它的底稿来自一次迎新分享里的「沟通礼仪」部分，**核心只有一条：尊重**。

:::tip[先给结论]
**尊重 = 承认对方是独立的人：有时间、有情绪、有边界、有选择。**

判断一句话该不该说、一件事该不该做，用这四个词过一遍就够了——他的时间值不值钱？他的情绪现在是什么状态？我越界了吗？他有没有拒绝的余地？
:::

## 一、尊重的四个关键词与四个层次

**四个关键词**（用来检验具体行为）：

| 关键词 | 具体是什么意思 |
| --- | --- |
| **边界** | 不越界，不把别人的帮忙当成理所当然 |
| **清晰** | 说清我是谁、为什么找你、需要你做什么 |
| **换位** | 如果别人这样对我，我会舒服吗 |
| **选择** | 允许对方拒绝，不把"帮忙"当成义务 |

**四个层次**（缺哪一层都会出问题）：

1. **尊重自己**：悦纳自我，会拒绝，不讨好，有底线。
2. **尊重他人**：尊重他人的时间、隐私、情绪、差异。
3. **尊重情境**：分清场合、渠道和正式程度。同一件事在群里说和在私聊里说，效果完全不同。
4. **尊重规则**：组织、群聊、互联网、公共空间各有规则。

:::caution[尊重不是什么]
这句话值得单独记住：**尊重不是讨好所有人，不是不能有冲突，不是沉默忍让，不是模糊边界。**

尤其不是这两句：
- 「我这是为你好」——用善意包装的控制；
- 「我说话直，你多担待」——把自己的不客气变成别人的义务。

**可以观点争论，不要人身攻击；可以不同意，但要允许差异存在。** 这两条同时成立，才叫尊重。
:::

## 二、微信：五个层面

微信是校内最主要的沟通渠道，也是最容易出问题的地方。

### 加好友

- 加人时说清**你是谁、从哪来、为什么加**（同一门课？同一个组织？谁推荐的？）。
- 推名片给别人之前**先征求对方同意**。
- 群里的"扩列"式加好友要注意礼貌问题——对方不欠你一个好友位。

### 问问题

- **先问自己：这个问题该问谁？** 通知里写了的、群里发过的，先去搜，不要直接问人。
- **学会用微信搜索**：翻一下群记录和对方的朋友圈/聊天记录，很多问题已经答过了。
- **别只发"在吗"。** 把问题一次说清：你是谁、遇到什么、已经试过什么、需要什么。
- **收到答复要有回音。** 问题解决了说一句结果，这比一句"谢谢"有用得多。

### 发请求

- **分清场合**：紧急且短的事可以私聊；需要留痕、需要多人知道的事走邮件或群。
- **关键信息在对话中间再确认一次**（时间、地点、交付物）。口头或聊天里的约定，隔几天就容易变形。
- **长请求要分段**：一段一件事，别写成一大段让人无从下手。

### 收文件与其他

- 通知群里的文件**及时保存**（群文件会过期，也会被清）。
- 重要消息**开提醒**；群太多就**免打扰 + 折叠**，但别因此错过通知。
- 待处理的消息**标为未读**，处理完再取消——比在脑子里记更可靠。
- **别不打招呼就打语音或微信电话**。除非你们的关系到了那一步，否则先文字问一句"方便通话吗"。

## 三、邮件：四个要素

邮件是**留痕**的渠道，也是和老师、教务、校外机构打交道的正式方式。

| 要素 | 具体做法 |
| --- | --- |
| **分清对象** | 想清楚收件人、抄送人；该"回复全部"的时候别只回一个人 |
| **重点明确** | 有问候语和祝颂语；正文里的**【时间】【地点】【截止】**这类关键信息用加粗、标黄或【】标出来 |
| **内容清晰** | 三段话说完：我是谁 / 为什么写这封邮件 / 需要你做什么 |
| **落款专业** | 姓名、学院、邮箱、电话；中英文场合注意邮箱名与头像是否得体 |

:::tip[邮件最容易犯的错]
**只写了"我想问一下"，没写"我需要你做什么"。** 收件人读完不知道要采取什么行动，这封邮件就只能被搁置。
把"需要对方做的事"写成一句话放在显眼位置——这是邮件写作里性价比最高的一件事。

更细的邮件写法（写给老师、导师、辅导员的三类对象分工、提要求的节奏、追问的频率）见[怎么和老师、导师、辅导员沟通](/mindset/talking-to-advisors/)。
:::

## 四、见面与公共空间

### 第一次见面

- **地点**：谈正事约会议室/研讨室；食堂、操场这类地方适合聊天，不适合谈需要专注的事。
- **时间**：第一次见面和重要活动**不迟到**；会迟到就提前说，到场先道歉；要早退也提前告知。
- **着装**：得体、好看、舒适，契合场合。**"契合场合"比"好看"重要。**
- **卫生**：勤洗澡、勤换衣。这条不用多说，但它确实影响别人对你的第一印象。
- **对话**：**健谈 ≠ 聒噪**。多倾听、少打断，允许留白，不怕尴尬。

### 线上与线下的表达

这些是在公共空间说话的基本线，比想象中重要：

- **严禁使用脏话**，包括无意识的口癖。
- **准确、清晰，比速度重要**。急着抢答说错话，比慢一点说得对代价大。
- **可以开玩笑，但不能冒犯。**
- **可以有观点争论，不要愤怒破防。**
- **互联网不是法外之地。** 发出去的东西可以被截图、被保存、被翻出来。
- **尊重隐私**：不查户口，不随意评价他人。

## 五、关系里的分寸

这一节只讲边界，不讲"应该谈不谈恋爱"——那是你自己的选择。

- **先学会好好对待别人，再谈亲密关系。** 顺序反了，容易把对方当成解决自己孤独的工具。
- **谨慎进入权力不对等的关系**（比如存在评价、指导、管理关系时）。这件事的代价往往在关系结束之后才出现。
- **暗恋可以，别影响自己的状态；上头可以，别过头；喜欢可以，别穷追猛打。**
- **对方已明确拒绝、开始回避、感到压力或情绪不佳时，识趣后撤。** 追求不是骚扰，喜欢不是纠缠。
- **相处**：维持其他关系，恋爱不是全世界；正视双方需求；财务上避免不对等——付出与索取大致平衡。
- **冲突**：多对话、少冷战；对事不对人，不翻旧账，不威胁；允许情绪宣泄，但不要伤害自己或他人。
- **分手**：不纠缠、不诋毁、尊重选择。**关系的结束不等于关系的失败。** 消沉期就去找自己喜欢做的事。

:::note[友情同样有边界]
- 没有无条件、无原则的包容——**付出要有底线**。
- 爱"真实的人"，而不是"你期望中的人"。
- 求同存异，允许不同。
- 财务上：AA 是好习惯，主动及时结清；请人代买及时转账；被请记得请回来。
- 拒绝要清晰，也接受被拒绝；不越界、不控制、不背后议论。
- **关系是双向的，舒服比热闹重要。** 交朋友不是"占有"，而是并肩。
:::

## 六、这套东西为什么值得花时间

因为它决定的是**别人愿不愿意和你一起做事**——而这几乎决定了大学里所有需要协作的事情能走多远：小组作业、社工、科研组会、实习面试、推荐信。

它不玄。它就是一堆具体动作：一次说清来意、一封结构清楚的邮件、一次不迟到的见面、一句"这个问题已经解决了，谢谢"。

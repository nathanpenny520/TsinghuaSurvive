网上流传的"学长告诫"类长文，问题从来不是"全错"，而是**对错混在一起**：几条真的有用，几条只适用于他那个学校、那个年代，还有几条是教你怎么对付别人。这篇做的事就是**分类之后重写**——告诉你哪些可以拿走，哪些看完就忘，哪些本站明确不建议照做。

- **本文是改写与筛选，不是原文转载。** 正文按主题重新组织，删去了大量原文内容（删了什么见「[我丢掉了什么，为什么](#我丢掉了什么为什么)」一节）；**原文观点不代表本站立场**。

## 先看总表：一条一条怎么判

判断标准只有三条：**这条建议今天还能不能落地？它对不对？它适不适合你？** 三条都过关才放进正文。

### 值得听（正文会展开）

| 原文编号 | 内容 | 为什么留下 |

| 一 | 无论喜不喜欢，都要学习 | 长期不动脑的代价是真实的，和绩点无关 |
| 二 | 别急着变现，先投资自己 | 大学里最贵的是可以慢慢积累的那几年 |
| 三 | 别把宿舍当默认去处 | 环境比意志力可靠 |

### 可以跳过

指"不算错，但对你不一定有信息量"的条目——它们要么是价值判断，要么论证方式本身有问题。

| 原文编号 | 内容 | 跳过的理由 |
| --- | --- | --- |
| 四 | 观察老师、领导 | 论证方式本身有问题：它要求你去打听一个人的背景与私事，这个做法本站不推荐 |
| 七 | 网游风险自测清单 | 结论（远离成瘾性设计）对，但那张清单把性格当预测器，不是可靠判断 |
| 十 | 宿舍各时期论 | 宿舍关系因人而异，那套"阶段表"更像个人模型，参考价值有限 |
| 十九 | 要有正确的人生观 | 道理不错，但这一条没给出可执行的动作 |
| 二十六 | 有付出才有回报 | 正确的废话，读完不知道该做什么 |

### 已经过时

指原文里**绑定在特定年代和特定学校**的内容——不是观点错，是信息过期。

| 原文编号 | 内容 | 为什么过时 |
| --- | --- | --- |
| 十五 | 考研与"规划十二个五年计划" | 原文拿 2011 年前后的专硕比例说事，那一代数据早就不能用来判断今天 |
| 二十三（部分） | 关于"考研难度"的判断 | 原文顺带评价了不同层次学校的考试难度，这类判断和年份、地区强绑定 |
| 二十四（部分） | 作者自己的一份成绩统计 | 样本是自己的同学，且是很多年前的数据，只能当"道理"看，不能当"事实"引用 |

还有两类**没有列进总表**：一条是原文空缺（第十八条、第二十条），另一类涉及人身攻击和不当建议——见下一节。

## 学习是本职

哪怕这门课你不喜欢，**该有的思路要有，该记住的东西要记住**。理由和绩点无关：长期不动脑会以"注意力变差、记不住东西、做事丢三落四"的方式收利息，而且这个过程慢到你自己不会察觉。

- 不喜欢的课，目标从"学好"降级成"不掉队"：跟上进度、作业自己写、考前过一遍。
- 真正危险的不是某门课学得差，而是**一整个学期没有让脑子承过重**。
- 绩点只是这件事的副产品。算法见[绩点到底是怎么算的](/academics/gpa/)；如果具体表现是"课跟不上、作业不会做"，那属于学习方式没换过来，见[从高中到大学：学习方式要怎么换](/academics/learning-method-transition/)。

## 别急着变现：投资自己，而不是赚钱

大学里最容易犯的错，是把**唯一一段可以慢慢积累的时间**换成了即时收入。原文那句话很准确：现在该干的是**投资**，不是**赚钱**——功夫活的特点是短期内看不出效果，但一旦学会，别人很难追上你。

:::caution[一个前提]
家庭经济确实困难、需要自己挣生活费的，**不适用这条**。原文也留了这个口子：那种情况下挣钱是必须的，不是短视。这条针对的是"本来可以不急，却因为看着别人挣就急了"。
:::

- 判断标准：这件事**三年后还值不值钱**？只值当下的，优先级往后放。
- 更常见的变体不是打工，而是**用"忙"换掉"积累"**：接了很多零散活，每件都有产出，一学期下来没有一件是可展示的能力。相关：[时间与精力管理](/mindset/time-management/)。

## 别把宿舍当默认去处

这是原文里最容易引起争议、也最值得认真对待的一条。**它不是在说"不许回宿舍"**——困了不回宿舍才是蠢。它说的是：**别让宿舍成为你没事时的默认选项**。

宿舍的环境是按"休息和娱乐"设计的：床、屏幕、随时可以搭话的室友。在这个环境里，"躺一会儿"的成本几乎为零，"学两小时"的成本很高。长期待在里面，损失不是时间，而是**和外面世界接触的频率**。

**具体做法**：给自己一个默认场所（图书馆、空教室、实验室、自习室），约定"到点就去那里"，而不是"到宿舍再看看要不要出去"。相关：[自习与学习空间](/campus/food-and-study/)。

:::tip
先别急着自我评价，做一次诊断就行：**记录一周内晚上 7 点到 11 点你实际在哪、在干什么**。数据比感觉可靠。
:::

## 尽量去操场转转

原文这条讲得很直白：二十岁左右的身体像一棵树，现在长歪了，三十岁要还。**哪怕只是去操场跑一圈**，也比"等忙完这阵再锻炼"强。

锻炼最被低估的作用不是身体，而是它和作息、情绪、专注力**是同一个系统**：体能好的人熬得住长期任务，而长期任务才是大学真正的难点。场馆与开放时间见[体育场馆与锻炼](/campus/sports-and-venues/)。

## 读书，以及不要变成"传统文盲"

原文把文盲分成两种：不会用现代工具的（"现代文盲"），和不懂基本礼仪与场合感的（"传统文盲"）。今天真正稀缺的是第二种——**信息越碎，完整读一本书的能力越贵**。

- 原文的读书方法可以保留：**读书习惯因人而异，可以借鉴不要照搬**；思想类的书和情节类的书读法不同，前者要慢、要记、要跟自己的问题对照。
- 关于礼仪，保留它最有用的一层：**分清场合**。同一个玩笑在宿舍和在正式场合不是一回事；在需要认真的场合控制网络用语和口头禅，不是虚伪，是让人准确接收到你的意思。
- 这两件事都需要大块时间。如果你的阅读时间已经被切成碎片，先解决上一节的"默认场所"问题。

## 关于恋爱与担当

原文最有价值的一句是：**恋和爱不是一回事，爱是担当**。它的意思是，恋爱里真正决定关系质量的是**责任感**——站在对方立场上考虑，愿意承担后果，而不是靠表白和仪式。

- 看一个人是否靠得住，看的不是他说了什么，而是：**遇到麻烦时他做什么**、对承诺认不认真、会不会为了短期爽感牺牲对方的长期利益。
- 反过来对你也一样：**先把自己变成一个能承担后果的人**，再谈投入。
- 原文有一段把恋爱比喻成"父亲 / 儿子 / 老公三种身份"，本站没有采用——它把两个人都框进了很固定的角色，不适合作为通用建议。

:::note[不采用的部分]
原文这条里还夹了一段对媒体和影视作品的批评，以及"男生应该怎样、女生应该怎样"的表述，本站没有保留。原因见下一节。
:::

## 冲突面前保持冷静

原文这条的对象是**大的社会冲突与热点事件**，不是两个人吵架。它真正有用的部分是：**人在二十岁左右最容易被情绪调动**，而一旦站了队、传了话、动了手，代价往往由你一个人承担。

**原则**：不冲动表态，不盲目跟风，先看清再说话；事件没有直接涉及你的切身利益时，**退后一步观察**比冲在前面安全得多。

:::danger[边界]
这条**不包括**政见、组织和行动层面的任何指导，本站也不提供这类内容。这里只保留一句通用的自我保护建议：**别把自己的学业和前途押在别人的情绪上**，遇到说不清的事，先问"这件事和我有什么关系、我要承担什么后果"。
:::

## 真朋友，值得去他家里看看

原文说得很实在：一群人吃饭喝酒唱歌，是**同乐**；真正难的是**同担**。它给了一个判断方法——**在合适的时候去对方家里坐坐，见见他的父母**。你见过一个人的成长环境，才谈得上了解他。

**可以照做的部分**：一起回家吃顿饭、陪长辈聊聊天；记住对方家里的情况；逢年过节发个问候。这不是攻略，是**从同学推进到朋友**的正常路径。

:::caution[两条提醒]
1. **不要刻意经营**。原文后半段把它写成了操作步骤，那部分本站没有保留——被设计出来的"贴心"是能被看出来的。
2. **大三大四之后机会就没了**。原文有一句判断很准：工作以后立场各异、关系复杂，很难再交出这种朋友。所以这件事有时间窗口。
:::

## 行得正，就不怕和老师把话说开

原文这条讲的是"分内之事"：**把该做的事做漂亮，是你去争取应得东西的底气**。做好了分内之事，遇到问题才敢直接沟通，而不是躲着走。

- "行的正"不是理直气壮，是**你把作业、考试、规定环节都做到位了**，所以你有资格问"为什么是这个结果"。
- 遇到不理解的结果，**直接、客观、有条理地问**，比在心里积怨有用得多。沟通方式见[怎么和老师、导师、辅导员沟通](/mindset/talking-to-advisors/)。
- 也要接受另一面：有些事不归老师管，有些结果不取决于你的努力。这种情况下的正确动作是**问清楚原因、留好记录**，而不是硬扛或对抗。

## 关于实习

实习最直接的作用是**把课堂知识放到真实问题里检验**——原文的例子是"用你的专业知识去解释你身边正在发生的事"，这个思路今天依然成立，而且不需要等实习开始就能做。

- 应用型、授课型项目和商科方向，**实习是权重最高的经历之一**；偏研究的方向则科研更重要。
- 别让实习吃掉基本学业。**在不影响基本学业的前提下**安排，一次一段就够。
- 每段实习结束写一页纸：做了什么、学到什么、产出是什么。这份记录以后会直接变成简历和文书里的内容。

## 能直线就别走曲线

原文这条是整篇里最实用的判断之一：**很多"曲线"方案只是把目标推得更远**。绕弯的时候你觉得自己在靠近，实际上消耗的是意志和时间。

**判断办法**：

| 问自己 | 如果答案是…… |
| --- | --- |
| 这条路的目标，是不是我真正想要的那个结果？ | 不是 → 大概率是绕弯，重新选 |
| 这条绕法有没有前人走过、结果如何？ | 没有、也不知道 → 更要警惕，原文说的正是这种情况 |
| 正面走不通的那堵墙，突破口在哪？ | 找不到 → 先把问题拆小，而不是换一条更远的路 |

原文的态度很明确：除了极端个别的情况，**大部分事情都能找到那个"七寸"**，关键是分析得够不够细。

## 别涸泽而渔

原文这条很朴素：二十岁出头的恢复力是真实的，但**透支明天的精力，收益小、利息高**。用通宵换来的产出，往往要用后面几天补回来，而且不一定补得回来。

- 长期用睡眠换产出，等于在借高利贷。
- 如果某段时间必须冲刺（期末、截止日期），**提前留出恢复的时间**，别把恢复期也排满。
- 这条不只适用于精力：**任何需要长期投入的事情都不该透支**——包括身体、关系和信用。

## 不疯魔不成活，但不能全疯

原文这条来自梨园行话：要出成绩，得进入一种**忘我的专注状态**。这个观察是对的，但原文自己也给了一个必要的限制——**不是所有事都值得全情投入，你也不可能对每件事全情投入**。

- **全疯**留给一两件你真正想做出成果的事：你会主动去想它，做起来还游刃有余。
- **必须完成但不喜欢的事**（比如考试）用**半疯**：把环境简化，把最能吸引你的东西（游戏、短视频、小说、手机）移出视线，让自己处在一个"除了这件事没别的可做"的处境。
- **反作用要避免**：如果逼到开始厌恶这件事，方法就失败了。感到排斥的时候先退一步，而不是加大强度。
- 原文结尾用了一种很激烈的表达方式来强调"别一下课就回宿舍开电脑"。意思是对的，但**不要把它理解成自我惩罚**——专注是靠环境设计做出来的，不是靠骂自己。

## 把这一页变成四个动作

1. **今晚做一次诊断**：记录未来一周晚上 7 点到 11 点你实际在哪、在干什么。
2. **指定一个默认场所**，写下"到点就去那里"的具体时间和地点。
3. **挑一个手上正在做的事，检查它是不是绕弯**——用上面那张三问表过一遍。
4. **如果最近状态不好**，先看[失败之后怎么爬起来](/mindset/after-failure/)，那里处理的是"我搞砸了"这类具体情形，不是励志口号。

## 我丢掉了什么，为什么

这一节是本页最重要的部分之一：**你看不到的内容，和你能看到的内容一样需要交代。**

### 一、涉及人身攻击或不当建议的，一律不收

原文有两条的内容是**教你怎么压制别人**：一条讲"碰到小人不必讲对错，要让他知道你随时能攻击到他的要害"，另一条讲宿舍关系里"找一个朋友配合演戏、当众立威"。还有一条把学生会描述成"水太深"，并给出"如何讨好上级"的具体做法。

这些内容**本站不做任何形式的收录或转写**，包括"换个说法保留精神"。理由很简单：

- 它们教的是**操纵和威慑**，不是解决问题。读者照着做，风险全在自己身上。
- 它们默认了一个"处处是敌人"的校园图景，而绝大多数人遇到的其实只是**沟通不畅和边界不清**——后者有正当解法。
- 本站的定位是"能公开讲、被讲的人看到也不难堪"。这类内容不符合这个标准。

同样被去掉的还有：原文里对**某位具体老师**的评价（包括其家境、职位、挂科率、"资格是买来的"这类无法核实也不该复述的说法），以及引用他人**家庭情况、身体状况、私人选择**来论证观点的段落。

### 二、涉及具体个人与机构评价的，一律去掉

原文用大量篇幅评价具体的人、具体的学校和具体的机构。这些内容：

- **无法核实**，而且原本就是私人判断；
- **写死了一个人**，读者不认识当事人，无法判断语境；
- 换个年份、换个学校就不成立。

所以本页全程用"某门课""一位老师""某个项目"这样的表述。这不是为了显得客气，是因为**本站不评价具体个人**。

### 三、涉及时效的，标年份或者直接删

原文写于约 2022 年，里面有几类内容今天已经不能用了：

- **具体平台与行业现象**：原文提到的创业叙事、媒体案例、当时的热门行业判断，全部删除——那些东西的保质期比一篇文章短。
- **带有年份的制度性数字**：原文用 2011 年前后的考研结构变化来论证趋势判断，本站不保留具体数字，只保留"向前看几年"这个动作。
- **作者的私人统计**：原文提到一份自己做的、样本约三十人的成绩对比。它在原文里位置很重，但样本小、年份早，只能当道理看，不能当证据引用。
- **对特定类型学校难度的判断**：删除。这类判断和年份、地区、专业强绑定，写进来就会误导人。

本页凡涉及制度与规则的地方，统一写成"以官方通知为准"或链接到站内对应页面，不写具体数字。

### 四、和本站立场不同的，改写而不照搬

原文有若干段落的价值判断与本站不一致——例如把恋爱关系框成固定的性别角色、"读书"一节里对具体作家与思想体系的高下评论、以及把某些社会现象归因于单一原因的论述。

对这类内容，处理方式是**保留其中可操作的方法，丢掉价值判断**。改写的部分不需要读者替原作者或本站站队。

### 五、结构上的改动

- 原文的第一条到第二十八条是**平行罗列**，权重不分。本页改成"总表 + 按主题重写"，因为读者需要的是"我该听哪几条"，不是"一共有几条"。
- 原文缺第十八条、第二十条，本页不补、不猜。
- 原文的语气是"哥教你们"，本页保持建议性，不做人身评价、不用贬义词给读者贴标签。

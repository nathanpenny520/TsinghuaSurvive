文献管理工具的价值只有一句话：**让"引用"变成插入一个编号，而不是手打一串格式。**

手打参考文献的问题不在于累，而在于**你一定会错**：改一次顺序、删一篇、换一种格式要求，手打的编号就全乱了。而工具只需要你换一下输出样式。

## 为什么现在就该学

| 场景 | 具体会发生什么 |
| --- | --- |
| **课程论文与综述** | 要求附参考文献，格式有明确规定。手打容易错，而且改起来极其痛苦。 |
| **进实验室做科研** | 读文献是日常工作，几十上百篇 PDF 必须有地方放，否则半年后你连自己读过什么都想不起来。 |
| **毕设** | 参考文献数量多、格式要求严格，是文末最容易被扣分的地方。 |
| **投稿** | 不同期刊的参考文献格式不同，工具换一行就能重排。 |

:::note[越早开始积累越划算]
文献库是**有复利的**：大二存进去的五十篇，到大四写毕设时就是你的素材库。等到写论文那天才开始用工具，它只能帮你处理眼前这一篇。
:::

## 马上能做的

- [ ] 今天就装一个工具（见下一节的二选一），并把**浏览器插件**一起配好——直接从数据库页面一键存进库里，比手动录入省事得多。
- [ ] 导入 5 篇你已经读过的文献，**逐条核对元数据**（作者、年份、期刊名、页码），感受一下哪里最容易错。
- [ ] 定一条 PDF 命名规则（例如「年份-第一作者-关键词」），并统一放在一个目录里。
- [ ] 装一个国标相关的输出样式，试导出一条参考文献，**对照学校或期刊的要求检查一遍**。
- [ ] 在你的文档里插入一条引用并生成参考文献表，完整走通一次流程。
- [ ] 打开工具的同步功能，或者定一个**定期导出备份**的提醒——文献库丢一次，你会想砸电脑。

## 二选一：Zotero 还是 EndNote

**先看你的课题组用什么。** 如果导师和师兄师姐都用同一个，跟着用，能省掉大量沟通成本。**以组内的实际要求为准。**

如果没有约束，两者的大致分工是：

| | Zotero | EndNote |
| --- | --- | --- |
| **费用** | 免费、开源 | 商业软件，学校是否有授权、如何获取，以[信息化服务](https://its.tsinghua.edu.cn/)的说明为准（具体入口链接待补） |
| **上手难度** | 较低，界面简单 | 功能更多，需要花点时间熟悉 |
| **中文文献** | 能用，但元数据仍要人工核对 | 同样需要核对 |
| **写作插件** | 提供主流文字处理软件的插件 | 提供主流文字处理软件的插件 |
| **适合谁** | 本科生、刚开始做科研的人 | 课题组已有统一工作流、需要更多高级功能的人 |

:::caution[兼容性要自己实测]
工具与文字处理软件（尤其是国内常用的办公软件和在线文档）的插件兼容性会随版本变化。**在正式写论文之前，先用一篇练习文档走通"插入引用 → 生成参考文献 → 改样式"整个过程**，不要等到截止前一天才发现插件装不上。
:::

## 中文文献与 GB/T 7714 的现实做法

这是国内学生最容易踩坑的地方。**中文文献的元数据质量普遍不如英文文献**，导入后必须人工过一遍。

国内期刊、学位论文和很多课程论文要求使用国家标准 **GB/T 7714（参考文献著录规则）**。但要注意：

:::caution[格式要求以官方为准]
**GB/T 7714 具体用哪个版本、学校/院系/期刊有没有附加规定（例如是否要求文献类型标识、是否要求 DOI），一律以课程要求、学位论文规范或期刊投稿指南为准。** 本文不列举具体条目格式，因为写错一条就可能让你整份参考文献都不合格。
:::

现实中的做法：

1. **优先用数据库的题录导出功能。** 国内文献数据库的文献详情页一般都有导出入口，导出后再导入文献管理工具，比手动录入快且少错。
2. **导入后逐条核对四样东西**：作者姓名是否完整、期刊名是否写全、年份卷期页码是否正确、文献类型是否正确（期刊论文 / 学位论文 / 会议论文 / 标准）。
3. **中文作者姓名容易出错**，尤其是复姓、多音字和外文译名。核对时以论文原文页为准。
4. **工具生成的条目要抽查**。随机挑几条，对照官方格式要求逐字看一遍。**这一步能挡掉绝大多数低级错误。**
5. **不要凭印象改格式。** 觉得"这样看起来更好"就加个空格、改个标点，很可能正好违反了要求。

## 写论文时的引用流程

按这个顺序走，基本不会乱：

1. **边读边入库。** 读的时候就存进文献库，并加上标签或备注（这篇解决了什么、能不能用在我的哪一节）。**不要事后补录。**
2. **统一命名和归档。** PDF 文件名规则统一，按课题分文件夹，不要把所有 PDF 堆在一个目录里。
3. **写作时只插入引用，不手打编号。** 用工具插入，编号交给文档自己维护。
4. **定稿前再换样式。** 先写完内容，最后一步统一改成要求的格式。
5. **生成参考文献表并逐条核对**，特别是作者数量、页码和年份。
6. **交付前再通读一遍。** 重点看：正文里每个引用都在文末有对应条目（反之亦然）、没有重复条目、没有空条目。

:::tip[LaTeX 用户的对应做法]
如果你用 [LaTeX](/skills/latex-and-overleaf/)，流程是一样的：文献存在管理工具里，导出成 `.bib` 文件，正文里用引用命令，最后交给参考文献样式处理。**同样不要手打条目。**
:::

## 避免学术不端的引用习惯

**引用规范不是格式问题，是诚信问题。** 下面几条建议不是"技巧"，是底线：

1. **没读过的文献不要引。** 从别人的参考文献列表里抄一条自己没看过的，等于虚假引用。
2. **必须转引时，明确写"转引自"。** 能够找到原文的，一定要去查原文。
3. **直接引用要加引号并标注出处页码。** 不要用"改写几个词"的方式代替引用。
4. **图表、数据、代码来自别处都要注明来源。** 不只是文字才算引用。
5. **不要重复使用自己已发表的内容而不说明。** 自我抄袭同样属于学术不端。
6. **AI 工具生成的内容，按课程和期刊的规定处理。** 是否允许使用、是否必须声明，**以课程要求和投稿指南为准**，不要自己想当然。
7. **查重率低不等于没有不端行为。** 工具只能查文字重合度，判断责任的是人。

:::danger[三个真实的坑]
- **删掉文献库里的条目**，会导致正文里的引用变成乱码或错误编号。删之前先确认它在哪些文档里被引用过。
- **用别人的文献库或来源不明的数据文件**，可能已经把错误和虚假条目一起继承了。核对时以原文为准。
- **使用来源不明的破解软件**。软件来源不合法，风险也不止是版权问题。请使用正版或学校提供的授权版本。
:::

## 常见坑

:::caution
- **两个工具同时用。** 结果两边的库都不完整，写作时不知道该信哪一边。**只用一个。**
- **只存 PDF，不录元数据。** 一年后你有一堆不知道是什么的文件，等于没存。
- **不做备份。** 文献库通常存在本机，硬盘故障、系统重装都可能让它消失。定期导出备份，并留一份到[校内云盘](https://cloud.tsinghua.edu.cn/)。
- **同一个库里大量重复条目。** 每次导入前先查一下是否已经在库里。
- **在 Word 里手动改生成好的参考文献。** 下次刷新就全被覆盖，而且会错得莫名其妙。
- **把 PDF 和文献库放在两个地方。** 换电脑后条目在、附件不在，等于白存。
- **参考文献格式只对了一部分。** 中文条目、英文条目、学位论文和标准各有各的写法，要分别检查。
:::

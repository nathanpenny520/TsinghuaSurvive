刚拿到录取通知书的时候，信息量会非常大：一堆群、一堆文件、一堆"记得要带"。这篇只解决一件事——**别漏掉关键动作**。

## 出发前：证件比行李重要

<Aside type="danger" title="证件永远随身，不要托运">
录取通知书、身份证、户口迁移材料、银行卡、证件照——这些东西一旦跟着行李箱走丢，你到校第一周会寸步难行。**全部放随身包**，并且提前拍一份照片存云端。
</Aside>

出发前对照一遍：

- [ ] 录取通知书（原件，别只存电子版）
- [ ] 身份证 + 复印件若干
- [ ] 户口迁移相关材料（**是否需要迁户口请按通知书要求办**，不是所有人都要迁）
- [ ] 党团组织关系转接材料
- [ ] 一寸/两寸证件照（纸质 + 电子版，底色按学校要求）
- [ ] 录取通知书里提到的其他材料（体检表、资助材料等）
- [ ] 一张能用的银行卡 + 少量现金
- [ ] 常用药、充电器、转换插头

:::tip
**可以到校再买的**：被褥、脸盆、衣架、台灯、插线板、洗衣液。学校及周边都有卖，价格不比自己家贵多少，扛着它们坐高铁是纯亏。
:::

## 到校当天

<Steps>

1. **先去报到点**，按指示牌或志愿者的引导完成身份核验、领取材料袋。

2. **去宿舍楼办入住**，拿钥匙/门禁卡，检查一下床、柜子、插座、水龙头有没有问题——有问题当场报修，别拖到住进去才说。

3. **确认一卡通**（校园卡）是否已激活、怎么充值。吃饭、借书、门禁、洗澡基本都靠它。

4. **把宿舍网络和手机网络弄通**。这件事优先级极高，因为后面几乎所有流程都要在网上办。

5. **加对群**：班级群、院系群、宿舍楼群。信息基本都从群里走。

</Steps>

## 第一周：把"账号"这件事干掉

真正容易卡住人的不是行李，是**各种系统进不去**。按这个顺序办，一条链路走通：

<Steps>

1. **激活学校邮箱**。后面所有官方通知、注册验证都靠它，务必每天看一次（可以转发到常用邮箱）。
2. **登录信息门户**，把里面的通知翻一遍，特别是"新生"相关的。
3. **设置校园网**，确认宿舍和教学区都能上网。需要 VPN 的场景也顺手配好。
4. **进教务/选课系统**，看清楚本学期的选课时间和你的培养方案（怎么读见[培养方案与选课](/academics/course-selection/)）。
5. **办图书馆权限**，顺路把入馆测试/借书规则过一遍。
6. **医保、体检、疫苗**等按院系通知办，别自己猜。
7. **找到辅导员和班主任**，存下联系方式。这是你遇到任何"不知道该问谁"的问题时的第一站。

</Steps>

## 几个真实的坑

<Aside type="caution" title="这些事每年都有人栽">
- **建行/工行卡没激活**：奖助学金、报销都打到卡上，卡没激活就一直收不到，等到发现时已经过了一个学期。
- **邮箱不看**：很多截止通知只发邮箱，不发群。习惯性地把邮箱设成手机推送。
- **选课时间错过**：新生第一学期选课窗口和军训时间重叠，人在操场上，课没了。**提前在手机上设好提醒**。
- **把培养方案当废纸**：它是你四年能不能按时毕业的唯一依据，第一周就该读懂。
- **什么都自己扛**：不知道就问，问辅导员、问班导、问室友。大学里没有人会主动来告诉你该怎么办。
</Aside>

## 心态上的一句

第一周你会觉得周围人都比自己强、信息都比自己灵通——**这是错觉，因为每个人都在同一个状态里，只是没人说出来**。

按清单做事，把该办的办完，剩下的时间用来认识人。这比提前预习两门课重要得多。

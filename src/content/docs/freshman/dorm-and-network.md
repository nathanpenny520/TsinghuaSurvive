这三件事是"地基"：办不好，后面的选课、交作业、吃饭、洗澡都会卡住。**优先级高于收拾宿舍。**

## 一卡通：先把它搞清楚

校园卡通常一张卡管四件事：**食堂、门禁、洗浴、图书借阅**。到校第一周就该弄明白：

- **怎么充值**（线上还是线下、多久到账）
- **丢了怎么挂失**（这个一定要提前知道，丢了再查会很慌）
- **有没有电子卡**可以替代实体卡（手机掉了、卡消磁了都不至于寸步难行）

:::caution
**卡里别放太多钱**。丢卡后如果没及时挂失，余额可能被刷掉。够用两三周就行。
:::

## 校园网：一次配好，别每周折腾

- **先确认你的账号有没有激活**。很多"连不上网"其实是账号没开通，不是信号问题。
- **宿舍网口/无线**：宿舍通常有网口也有无线。要接路由器的话，注意**认证方式**——很多校园网需要在网页上登录，路由器要做相应设置才能共享。
- **教学区与宿舍可能是不同网络**。上课时发现连不上，先想想是不是需要重新认证。
- **校外访问校内系统**通常要走学校 VPN，**提前配好**，别等到要交材料那天才发现进不去。

:::tip
把**校园网自助服务页、VPN 配置说明、一卡通挂失入口**存成手机书签。这三个地址你会反复用到。
:::

## 宿舍关系：把丑话说在前面

宿舍矛盾几乎都源于同一件事：**作息和习惯差异没有提前约定**。等矛盾积累到爆发，就很难坐下来谈了。

建议**入住第一周**就把这几件事聊清楚：

| 要约定的事 | 为什么 |
| --- | --- |
| **最晚几点熄灯 / 关大灯** | 这一条能解决 80% 的宿舍摩擦 |
| **能不能在宿舍打电话、开外放** | 戴不戴耳机是小事，但影响别人是大事 |
| **空调温度** | 有人怕冷有人怕热，需要规则而不是每天吵 |
| **卫生怎么轮** | 不分工就等于没人做 |
| **借东西要不要打招呼** | 提前说清楚，反而更自在 |
| **带人回宿舍的规矩** | 最容易踩雷的地方 |

:::tip
**用"我需要"而不是"你别"来表达**。「我 11 点后需要安静」比「你别那么吵」有效得多。同一件事，说法不同结果差很远。
:::

**住不惯怎么办**：先尝试沟通，沟通无效再找辅导员。换宿舍通常需要理由和时间，**不要指望一开口就能换**。

## 用电与安全

- **大功率电器（电热锅、电暖器之类）基本都禁用**，而且宿舍电路承不住，跳闸是轻的。
- **插线板不要串接**，也别压在床垫下。这是真实的火灾原因。
- **充电宝不要放在被子里充**。
- **出门锁门**。宿舍楼人员流动比你想的复杂。

## 报修与杂事

- **坏了立刻报修**，别拖。尤其是漏水、跳闸、门窗锁不上这类会影响别人的问题。
- **洗衣、饮水、快递**的位置和收费方式，第一周就走一遍，之后不用再问人。
- **贵重物品**（电脑、相机、证件）不要放在明显位置。

## 一个被低估的建议

**把宿舍当成睡觉和休息的地方，而不是学习的地方。**

宿舍里有床、有室友、有手机，学习效率通常是图书馆的一半。**每天背着书包出门，去教学楼或图书馆，回来只睡觉**——这个习惯一旦在大一养成，四年都会受益。反过来，如果大一就在宿舍学，后面很难改。

具体去哪自习，见[吃饭、自习与出门](/campus/food-and-study/)。

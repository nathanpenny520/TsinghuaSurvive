## 怎么判断一份资料是哪一届的

四个地方按可靠性从高到低看：

1. **文件内容里的学期**。课件封面、讲义页脚、作业题头的「20XX 春 / 秋」，比文件名可信。
2. **文件名里的年份**。多数按**学年起始年**写，比如 `2020-线代-期末.pdf` 指的是 2020–2021 学年；但也有按毕业届或上传时间写的，撞上模糊的就当不确定。
3. **目录名上的年份**。目录名是整理者标的，反映的是「他把哪些东西归到一起」，不等于每一份都是那一年的。
4. **内容里的改版痕迹**。课程改名、合并、拆分、换教材之后，旧资料会整体失效——不是内容错，而是对象已经不是同一门课了。

:::caution[判断不出来的时候]
把它当**知识点参考**，不当**考纲**。具体做法：只从里面取那些今年讲义里仍然出现的知识点；复习范围以今年的教学大纲、讲义和任课教师口径为准。一份不知道哪一届的资料，唯一安全的用法就是「当习题做」。
:::

## 使用红线

和[外部资料库地图](/guides/archives/)里的规则是同一套，这里换到「资料类型」的视角再说一遍：

- **往年题不是考纲。** 看过往届题之后仍然要以今年的教学大纲为准，别把往届的重点当今年的重点。
- **答案只用来看思路，看完自己重写。** 复制粘贴和「参考后独立完成」是两件事，判定雷同并不需要一模一样。
- **课程内部材料不进公开库。** 老师发的课件、内部讲义、考试原卷、含他人信息的名单与成绩，都不该出现在公开仓库或网盘里。
- **尊重原库的许可与署名。** 多为 CC BY-SA / CC BY-NC-SA：可以转载改写，但要署名、非商业使用、以相同方式共享。
- **发现侵权内容走原库 Issue。** 本站只做索引，不代为删除任何第三方内容；被收录材料的作者可以要求下架。

界线本身写得比这里细，见[学术规范的边界](/academics/academic-integrity/)；每个资料库的强项、可达性和注意事项，见[外部资料库地图](/guides/archives/)。

## 这一页的数据是怎么来的

索引由 `scripts/build-course-index.mjs` 扫描四个公开资料库的目录结构生成，本站**不镜像、不托管任何课程文件**，链接直接指向原库。完整索引在[课程资料索引](/courses/)，各库的来头与克隆方式在[外部资料库地图](/guides/archives/)；只想找书就去看[课程参考书目](/courses/books/)。

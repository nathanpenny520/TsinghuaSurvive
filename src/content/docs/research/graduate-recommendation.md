保研（推研）是本站路线图里明确标为**不能猜**的三篇之一：写错的时间线会直接让人错过一年。

所以这篇的处理方式和别的文章不同——**先搭一个不会误导人的骨架，把必须核实的事实逐条列成清单**。等真正走过流程的人来填空，而不是由不了解当年政策的人替读者假设。

## 这篇文章不做什么

- **不写名额、比例、排名算法**。推研名额怎么分配、综合成绩怎么加权、排名按什么口径算，逐届逐院系都可能不同，写死一个数字只会误导人。
- **不写时间点和截止日期**。任何没有注明适用年份的时间安排都不写；有亲历者核实过的版本，请以"某年某院系"的形式写进来。
- **不写资格判定的硬指标**。绩点门槛、排名门槛、挂科与处分的影响，一律以官方文件和院系口径为准。
- **不写政策条款编号、不写具体办公室与联系方式**。需要链接的地方一律写「（链接待补）」，由填写者从官方渠道补齐。
- **不评价任何老师、不比较任何院系"好不好保"**。

## 流程概览：只写"有哪些环节"

保研通常围绕**两条可能并行的线**展开：一条是院系内部的推免资格与排序，一条是接收单位（本校或其他学校）的选拔。两条线的规则和负责方不同，**都要单独核实**。

| 阶段 | 这一步在做什么 | 你需要在这里确认的事 |
| --- | --- | --- |
| **① 判断资格** | 先确认自己是否具备申请推免的基本条件 | 资格条件由谁认定、在哪份文件里写明 |
| **② 校内排序/推荐** | 院系按自己的口径形成推荐名单与排序 | 排序口径、申诉渠道、名单如何公示 |
| **③ 对外申请与联系** | 向接收单位表达意向、投递材料、参加选拔 | 各单位的申请方式与材料要求各不相同 |
| **④ 考核环节** | 接收单位组织的笔试、面试、或综合考查 | 考核形式、考查范围、结果如何通知 |
| **⑤ 双向确认** | 你与接收单位之间完成录取意向的确认 | 确认的正式形式是什么、能否更改 |
| **⑥ 系统填报与手续** | 在正式系统里完成志愿与录取流程 | 系统开放与操作的官方说明在哪 |
| **⑦ 后续手续** | 录取之后的材料、档案与其他收尾事项 | 由哪个部门通知、什么时候办 |

**顺序可能不完全是这样**：③④⑤ 在不同单位之间的先后关系不一致；有的单位在很早就完成选拔。**这张表只用来定位"哪一步该问谁"，不是时间线。**

### 材料清单（只有类别，没有格式要求）

材料通常属于几类：**学业类**（成绩单、排名或学业情况证明）、**身份与学籍类**、**外语水平证明**、**科研与竞赛类**佐证材料、**陈述类**（个人陈述、研究计划、简历）、**推荐类**（推荐信或推荐意见）、以及各单位自己的**申请表单**。

:::tip[先建一个文件夹，再谈内容]
把这几类的空缺位置先建出来，能减少"以为还早、结果发现少一份盖章材料"的情况。**材料的最大风险不是写不好，而是发现得太晚。**
:::

## 官方文件已经写明的那部分（2023 年口径）

这一节不是亲历者经验，而是**从《清华大学本科生学习指南（2023）》第十三节「免试推研」摘编**的制度内容。它回答的是"规则文本里到底写了什么"，**不含名额、比例、排名算法和具体日期**——那些原文本来就没给。

:::note[事实来源与时效]
本节事实来自《清华大学本科生学习指南（2023）》第十三节「免试推研」（2023 年口径）与《清华大学学生手册（2024）》所收的《清华大学本科生学籍管理规定》《清华大学学位授予工作实施细则》。
**推免政策逐年调整**，每一届都会重新发布实施办法。这里写的是文件文本，**办事前务必以你毕业当年的学校与院系正式通知为准**。
:::

### 推研类别：按去向、按类型、按层次看

官方文件把免试推研拆成三个维度来描述。同一名同学在三个维度上各占一格：

| 维度 | 有哪几类 | 说明 |
| --- | --- | --- |
| **按去向** | **本校读研**、**校外读研** | 本校读研又分**本院系推免**与**本校跨院系交叉推免**；校外读研指免试推荐到外校或科研院所，跨校推免的原则是**自愿申请、双向选择** |
| **按类型** | **学术学位研究生**、**专业学位研究生** | 学术学位以学术研究为导向、偏重理论和研究；专业学位以专业实践为导向、重实践和应用 |
| **按层次** | **硕士研究生**、**博士研究生** | 推免既可以推硕士，也可以推博士，取决于接收单位当年的招生安排 |

文件同时写明：按照教育部规定，**各高等院校须有一定比例的推免生向外校推荐**。

专业学位在文件里列举的类别包括工程硕士、建筑学硕士、金融硕士、工商管理硕士、公共管理硕士、工程管理硕士、法律硕士、传播硕士、艺术硕士等。

### 专项计划

教育部设有若干专项计划，文件明确提到的有**少数民族高层次骨干人才计划**、**退役大学生士兵计划**、**研究生支教团计划**。各专项计划的推荐政策**以教育部当年公布的招生政策为准**。

### 基本条件（原文列了四条）

申请者一般应满足：

1. **预计于第二年 7 月本科毕业**；
2. **学业成绩和成绩排名符合院系制定的推荐办法和具体要求**；
3. **诚实守信，学风端正，品行优良，遵守法律法规和校规校纪，未因学业违纪受过处分**，如受其它处分已解除；
4. **本人承诺**：若被接收为推荐免试研究生，**在研究生入学之前不开具出国成绩单**。

:::caution[第 2 条不是"过线"就够]
原文只写到"符合院系制定的推荐办法和具体要求"，**没有给出任何绩点或排名门槛**。门槛写在**你所在院系当年的推荐办法**里，本文不猜。
:::

### 时间点：文件只给了一个

按照教育部统一要求，本科生申请推荐免试攻读研究生工作**一般安排在大四年级秋季学期 9 月份**。除这一句之外，文件没有给任何其他日期。**具体日程以当年通知为准。**

### 程序办法：文件列了九个环节

文件按顺序写明了九个环节：

| 序号 | 环节 |
| --- | --- |
| 1 | 学生个人申请 |
| 2 | 学生所属院系审核、确定学生推荐资格、推荐名额 |
| 3 | 招生院系审核、确定学生复试资格 |
| 4 | 学生参加招生院系复试考核 |
| 5 | 招生院系复试考核，确定拟录取初选名单 |
| 6 | 学校审查、确认拟录取初选名单 |
| 7 | 院系对拟录取初选名单进行公示 |
| 8 | 拟录取初选学生到**教育部推免服务系统**报名 |
| 9 | 资格复审与录取（第二年本科毕业之前） |

**这张表的价值是定位顺序**：资格由**学生所属院系**认定，复试资格与拟录取由**招生院系**决定，公示发生在**学校确认之后**，最后的系统报名是**教育部推免服务系统**。它仍然不是时间表。

### 文件依据

第十三节末尾列出的规章是《清华大学推荐 xxxx 届本科毕业生免试攻读博士 / 硕士学位研究生工作实施办法》——**注意届次是变量**，每届一份。另外，学籍与学位的通用规则见《清华大学本科生学籍管理规定》与《清华大学学位授予工作实施细则》。

## 需要核实的事实清单

下面每一条都要由亲历者填写，**每条请写明"适用年份 + 院系"**。查不到就保持 `- [ ]`，不要猜。

**已由 2023 年官方文件补上的条目已在下面标出**（`- [x]` 并在条末注明），其余继续留空。

- [x] **要填什么**：推免资格的基本条件（学业、纪律等方面分别要求什么）。**去哪查**：学校与院系当年正式发布的推免工作通知、院系教务的书面说明（链接待补）。**已由 2023 年官方文件补上**：文件的四条基本条件见上文「基本条件」；**院系层面的具体门槛仍需核实**。
- [ ] **要填什么**：资格由谁认定、什么时候认定、认定结果如何告知本人。**去哪查**：院系教务（链接待补）。
- [ ] **要填什么**：校内推荐名单的产生方式（按什么排序、由谁审议、是否公示）。**去哪查**：院系当年通知与公示渠道（链接待补）。
- [ ] **要填什么**：综合成绩的构成口径（哪些部分计入、大致如何加权）。**去哪查**：院系教务与培养方案（链接待补）。**注意**：这里填的是"口径是怎么定的"，不是让你复算或推广某个公式。
- [ ] **要填什么**：学业成绩之外还有哪些因素可能影响推荐结果（科研、竞赛、社会工作、面试表现等）。**去哪查**：院系通知与往年亲历者（链接待补）。
- [ ] **要填什么**：对外申请（含校外单位）的渠道与方式（各自官网、系统、邮件还是线下）。**去哪查**：各接收单位当年的招生通知（链接待补）。
- [ ] **要填什么**：考核环节的实际形式与考查范围（几轮、笔试还是面试、是否含英文环节）。**去哪查**：接收单位当年通知与亲历者（链接待补）。
- [ ] **要填什么**：结果以什么形式、由谁通知，多久能知道。**去哪查**：接收单位通知与亲历者（链接待补）。
- [ ] **要填什么**：双向确认的正式形式，以及确认之后能不能改。**去哪查**：接收单位与学校当年的正式文件（链接待补）。
- [x] **要填什么**：正式系统填报的操作流程与官方说明入口。**去哪查**：学校当年发布的系统填报说明（链接待补）。**已由 2023 年官方文件补上**：文件明确为「到**教育部推免服务系统**报名」；**该系统的具体操作以当年说明为准**。
- [ ] **要填什么**：各类材料的格式、份数、盖章与提交方式（线上还是纸质）。**去哪查**：接收单位当年的材料要求与院系教务（链接待补）。
- [ ] **要填什么**：外语水平要求的认可范围与有效期。**去哪查**：接收单位当年通知（链接待补）。
- [ ] **要填什么**：推荐信的提交方式（谁写、几封、是否要老师本人提交）。**去哪查**：接收单位要求（链接待补）。
- [ ] **要填什么**：录取之后的后续手续由哪个部门通知、大致有哪些。**去哪查**：院系教务与学校当年通知（链接待补）。
- [ ] **要填什么**：对结果有异议时的正式申诉渠道与时限。**去哪查**：学校与院系正式发布的申诉流程（链接待补）。
- [ ] **要填什么**：同一院系不同专业方向之间，规则是否有差异。**去哪查**：各方向负责人或院系教务（链接待补）。
- [ ] **要填什么**：如果同时面对多个机会，冲突时按什么规则处理。**去哪查**：学校当年文件与院系教务（链接待补）。
- [ ] **要填什么**：没走成保研的人通常有哪些后续选择（考研、就业、其他项目）。**去哪查**：辅导员、院系教务与亲历者（链接待补）。

1. **注明适用年份与院系**，没注明的条目读者无法判断是否还成立。
2. **区分"文件写的"和"我经历的"**：前者写文件和年份，后者写"某年某院系个人经历"。
3. **不确定就留着不填**。留空比写错安全得多——这也是这篇存在的意义。

| 渠道 | 能得到什么 | 注意事项 |
| --- | --- | --- |
| **官方文件与通知** | 资格条件、流程、时间的唯一权威口径 | 以当年正式发布为准；不要用往年的当今年用 |

## 常见误解

以下几条**不依赖任何当年的政策细节**，所以可以放心写：

1. **以为排名只看绩点。** 多数院系的排序口径包含绩点之外的部分；具体包含什么要以院系文件为准。更常见的错误是**只盯着绩点、忽略了规则里其他需要提前准备的部分**（比如某些经历或材料要提前才能有）。
2. **以为材料可以临时准备。** 成绩单、排名证明、推荐信这类东西都依赖**别人的时间**（部门出证明、老师写推荐）。临近才动手，风险不在你写得好不好，而在别人来不来得及。
3. **以为规则全校统一。** 同一所学校不同院系、甚至同一院系不同方向，规则和节奏都可能不同。看别人院系的攻略，只能当参考。
4. **以为拿到口头意向就等于结束。** 正式结果和口头意向是两回事，正式确认的**形式**必须从官方文件确认，不能靠转述。
5. **以为只有一条路。** 保研通常和考研、出国、就业的准备工作在时间上重叠。**把其他选项完全押后，是把风险集中到一个点上。**

- 走[贡献一篇经验帖](/contribute/)的流程，或者到仓库提 Issue 说明你想补哪几条。
- 涉及个人经历的部分请写清"这是某年某院系的个人经历"，**不要写成普遍规则**。
- 不要提交内部系统的数据、截图、他人名单或任何联系方式——见[免责声明与内容边界](/start/disclaimer/)。

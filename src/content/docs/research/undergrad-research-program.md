本科生科研项目是本站路线图里明确标为**不能猜**的内容之一：项目名称、面向对象、时间安排、经费与学分口径，**换个院系就可能完全不一样**，换个年份更可能整份文件都被替换。

所以这篇的处理方式和[保研（推研）全流程：待核实的骨架](/research/graduate-recommendation/)一致——**先搭一个不会误导人的骨架，把必须核实的事实逐条列成清单**，等真正报过、做过的人来填空。

## 这篇文章不做什么

- **不写任何具体项目名称与其适用对象**。学校层面和院系层面的项目设置会调整，写死一个名字只会让人找错地方。
- **不写时间点和截止日期**。任何没有注明适用年份的时间安排都不写；有亲历者核实过的版本，请以"某年某院系"的形式写进来。
- **不写经费额度、报销比例与学分认定口径**。这三个是最容易过期的数字。
- **不写资格判定的硬指标**。年级限制、成绩要求、是否需要先修课，一律以项目当年通知为准。
- **不写政策条款编号、不写具体办公室与联系方式**。需要链接的地方一律写「（链接待补）」。
- **不评价任何老师、不比较任何项目"值不值得报"**。

本文正文刻意不写时间安排。下面的清单与环节表里会出现"申报、立项、中期、结题"这类环节名，它们只用来标出**有哪些位置需要填**，不代表顺序之外还有任何实际时间信息。

## 已经能确认的部分：SRT 与挑战杯（2026 年口径）

这篇整体还是骨架，但有两类事情**可以写清楚**，因为它们不依赖你报哪个院系的项目：

### SRT：最容易上手的那条路

**SRT（学生研究训练，Students Research Training）**是本科生在教师指导下、以学生为主体开展的**课外教学研究活动**。它的定位不是"发论文"，而是：

- 接触更接近实际的科研环境，训练**查阅文献、制定方案、分析论证、设计或试验、分析与总结**这些能力；
- **完成 SRT 计划可以获得相应的学分和成绩**；
- 最早的收益是**尽早进入实验室和课题组**，了解学科发展动向与前沿课题。不少人是在 SRT 里找到自己的兴趣，后来把它接成了研究生阶段的方向。

**报名窗口**：清华大学信息门户 → **应用导航 → 学习 → SRT**。这条路径 2026 年有效，具体开放批次与资格仍以门户里当期的说明为准。

### 挑战杯与各类科技赛事

- **「挑战杯」学生课外学术科技作品竞赛始于 1983 年**，是清华历史最长、规模最大、学科最全、水平最高的综合性学生课外科技竞赛，宗旨是「**崇尚科学，追求真知，勇于创新，迎接挑战**」。
- 全校课外科技赛事以挑战杯为龙头，**每年由校科协与各院系科协组织 60 余项竞赛**。面向高年级的如机械创新设计大赛、「今经乐道」经济热点分析大赛、中国大学生工程实践与创新能力大赛；面向中低年级的专业类竞技赛如「自由能」杯化工车动力与控制大赛、结构设计大赛、硬件设计大赛；面向新生的兴趣赛如「芯动计划」科技冬令营、「碳中和+」创意创新大赛。
- 除此之外，学校层面还有以「**星火计划**」为代表的科研类因材施教计划（见[学校给你的支持](/campus/support-centers/)）。**哪个适合你，取决于你院系科协当年发什么**——同类赛事每年的名称与分组都可能变。

:::tip[先做一件事就够]
不用把上面这些背下来。**打开信息门户的 SRT 入口看一眼当期开放的项目，比读十篇攻略都直接。**
:::

### 补充：官方文件里还能确证的几条（SRT 与赛事）

上面那两节说的是"大概是什么"。下面这几条是《本科生学习指南》里写明的细节，**不涉及报名资格、经费金额与时间窗口**：

- **SRT 立项申请每年分两批**，分别在**秋季学期和春季学期的学期初**进行，具体留意教务通知。
- **大一至大三年级本科生均可申请立项**，也可以**报名参加已立项的项目**。
- **执行时间一般为半年至一年**，结题后学生可获得 **1–3 学分**，获批项目有一定经费支持。
- 学生课外学术科技赛事**有学校组织举办的，也有省市级、全国及国际赛事**；了解赛事组织情况及参与办法的渠道是**院系教学办、学生科协、任课教师以及相关网站**。

**来源**：《清华大学本科生学习指南》（2023）第八节「实践训练」8.2、8.3（2023 年口径）。规章依据为《清华大学大学生研究训练（SRT）计划管理办法》。

### 夏季学期：把实践环节单独排出来的那五周

清华从 **1985—1986 学年度**开始实行**三学期制**，即在秋季学期、春季学期之后增加一个**夏季学期**（也叫小学期）：

- **夏季学期一般为 5 周**，由学校和院系安排教学活动；**学生暑假 5–7 周**（寒假一般为 5 周）。**夏季学期和暑假的先后顺序由院系确定**——所以"你们院是先上课还是先放假"要问本院系。
- 夏季学期一般安排**与专业学习有关的实践训练环节**，基础文科和理科专业也可以安排**暑期课程**。
- 这些环节包括**基础技能训练、专题研究训练、专业实习实践**，文件举的例子是认识实习、生产实习、金工实习、电子工艺实习、课程设计、专题实验等。
- **夏季学期开设的课程，原则上每周计 1 学分。**

文件同时鼓励本科生**在不影响教学计划内学习的前提下**，利用暑假和寒假参加国内外社会实践活动、短期研修或交流项目。

### 创意创新创业教育：和 SRT 并列的几条通道

文件把"三创"教育单独列为一节。它的特点是：**项目多、各自归口不同**，所以"找谁报名"比"报什么"更容易搞错。

- **大学生创新创业训练计划（大创计划）**：面向**全体非毕业班本科生**开放，鼓励个人或团队在导师指导下自主完成创新训练、创业训练和创业实践。**项目由学生自主立项、自行寻找指导教师**，鼓励跨院系、跨学科组队；项目可以来源于 SRT 项目延伸、校内科技赛事、实验室研究课题等。执行期一年，一般分**秋季学期和春季学期两批**立项，**创新训练类项目由各依托院系组织申报**，**创业类项目由校团委创业中心、清华「iCenter」和清华「x-lab」分别组织**。
- **学生科技兴趣团队**：跨学科跨年级组建的科技创新团队，由**校团委**匹配活动室和指导教师团队、负责日常运营，企业提供资金、工程师指导、研发平台与实习机会。**每学期初面向全校同学零基础招新**，报名通知见「清华青年科创」微信号。
- **大学生学术研究推进计划**：面向全校本科生，学生根据自身兴趣**自主立项研究**，学校匹配项目经费、指导教师与学术交流平台。分**院系项目**与**个人项目**两类，支持周期一般以**自然年**为周期；**个人项目由申请人向院系提出申请，院系评审后按推荐顺序提交校团委**。
- **清华「iCenter」**：依托基础工业训练中心，是国内高校率先建成的校园创客空间，提供工业级加工设备与技术支持，开设人工智能创新创业能力提升证书项目及「创业导引」等课程，并支持中美青年创客大赛等赛事。
- **清华「创+」**：由学校发起、**校团委具体运营**的创新创业教育服务平台，为学生创业者对接高校、政府与企业资源。
- **清华「x-lab」**：**2013 年 4 月成立**，依托经济管理学院、由 14 个院系合作共建，接收学生、校友和老师的创意创新创业项目；**2013 年 12 月发起并主办首届清华大学「校长杯」创新挑战赛**。

:::caution[上面几条里出现的金额与比例都别照着用]
文件里还写了若干具体的经费额度和支持比例。**这些数字属于会逐年调整的项目经费口径，本文不转述**，请以你申请当年项目通知与项目管理办法为准。
:::

**来源**：《清华大学本科生学习指南》（2023）第八节 8.4（2023 年口径）。

### 社会实践：学校鼓励"至少参加一次"

- 学生社会实践是学生走进社会，认知世情、国情、社情、民情的重要途径。文件写明的规模是：**每年有近 1000 支支队、10000 人次学生**在寒暑假和学期中开展国内外学习调研、专题调查、服务建设、专业认知等多种类型的实践，**超过 90% 的学生在学期间至少参与一次社会实践**。
- 组织与支持体系由**校团委**负责：学校在支持、培训、总结等方面提供系统支撑，学生可以通过校团委获取实践指导，公众号为「清华大学社会实践（THUpractice）」。
- 围绕国家战略与时代热点，文件提到的实践项目包括「新时代实践梦想计划」「江村学者」「支部同行」「乡村振兴工作站」等；为提升全球胜任力，学校还设立了本科生海外实践支持计划、全球胜任力海外实践课程等。

**来源**：《清华大学本科生学习指南》（2023）第八节 8.5（2023 年口径）。

### 综合论文训练：什么时候开始、走哪几个环节

综合论文训练就是常说的**毕业设计（毕设）**：

- **时间**：一般安排在**第四学年第八学期**进行，**12–15 周**内完成。
- **性质**：它是检验专业学习成效、训练解决实际问题能力的**一门必修综合课程，10–15 学分**。
- **环节**：学校采用**过程管理与目标管理相结合**的模式，重点抓**开题、中期汇报、期终答辩**三个环节，并评选表彰优秀论文。
- **产出**：学生在教师指导下综合运用所学知识，完成一项课题研究或相应的综合训练任务，**独立完成并答辩通过一篇「学士学位论文」**，在文献阅读与调研、方案设计与实施、资料分析与处理、案例分析等方面得到系统训练。
- **海外综合论文训练**：自 **2017—2018 学年起**，教务处启动该项目，选派优秀本科生赴世界顶尖高校、顶尖专业或师从顶尖学者进行研究训练，具体留意教务通知。

**来源**：《清华大学本科生学习指南》（2023）第八节 8.6（2023 年口径）。规章依据为《清华大学本科生综合论文训练教学管理办法》。

:::note[这一节的年份口径]
上面四节的事实来自《清华大学本科生学习指南》（**2023 年口径**）。第八节末尾列出的规章是《清华大学大学生研究训练（SRT）计划管理办法》与《清华大学本科生综合论文训练教学管理办法》。**SRT 的批次安排、大创的立项节奏、综合论文训练的具体周次，都会由教务处与院系按学年重新通知**，用之前请对一下当年通知。

## 环节概览：只写"有哪些环节"

本科生科研项目通常围绕**一条主线**展开：申报 → 立项 → 执行 → 中期 → 结题。但**具体环节的多少、名称与先后关系，各项目不同**，有的项目没有中期检查，有的把申报和立项合成一步。

| 环节 | 这一步在做什么 | 你需要在这里确认的事 |
| --- | --- | --- |
| **① 了解有哪些项目** | 搞清学校层面、院系层面分别有什么可报 | 项目名称、面向对象、由谁组织 |
| **② 找方向与导师** | 确定要做什么、找愿意指导的老师 | 是否必须自己找导师、导师需要什么身份 |
| **③ 申报与提交** | 按项目要求填写申报材料并提交 | 提交渠道、材料格式、是否需要签字盖章 |
| **④ 立项评审** | 由评审方决定是否立项与资助方式 | 评审形式、看什么、结果怎么通知 |
| **⑤ 执行与指导** | 真正做研究的阶段，通常需要定期汇报 | 汇报节奏、与导师的沟通方式 |
| **⑥ 中期检查** | 有的项目要求提交进展材料 | 是否有这一环、要交什么 |
| **⑦ 结题与验收** | 提交结题材料、可能答辩 | 验收标准、材料清单、期限 |
| **⑧ 后续认定** | 学分、经费结算、成果归属等收尾 | 由哪个部门认定、什么时候办 |

**顺序可能不完全是这样**：有的项目允许先立项再补导师确认，有的项目把评审放在执行之后。**这张表只用来定位"哪一步该问谁"，不是时间线。**

### 材料清单（只有类别，没有格式要求）

申报与结题材料通常属于几类：**申报类**（申请表、项目简介、研究计划或方案）、**人员类**（参与者信息、导师意见或签字）、**进展类**（中期报告、汇报记录）、**结题类**（结题报告、成果佐证、答辩材料）、以及**经费类**（预算表、报销票据）。具体格式、份数与盖章要求**一律以当年通知为准**。

:::tip[先建一个文件夹，再谈内容]
把这几类的空缺位置先建出来，能减少"以为还早、结果发现少一份签字材料"的情况。**材料的最大风险不是写不好，而是发现得太晚**——尤其是需要老师或部门签字的那几份。
:::

## 需要核实的事实清单

下面每一条都要由亲历者填写，**每条请写明"适用年份 + 院系 + 项目名称"**。查不到就保持 `- [ ]`，不要猜。

- [ ] **要填什么**：学校层面与院系层面分别有哪些本科生科研项目（准确名称、面向哪个年级、由谁组织）。**去哪查**：学校与院系当年发布的本科生科研相关通知（链接待补）。
- [ ] **要填什么**：申报资格（年级、成绩、专业限制、是否要求先修课程）。**去哪查**：项目当年的申报通知（链接待补）。
- [ ] **要填什么**：申报的时间窗口与提交渠道（系统填报还是纸质表格、交给谁）。**去哪查**：项目当年通知与院系教务（链接待补）。
- [ ] **要填什么**：是否必须自己联系指导教师；导师的身份要求（职称、是否本校、能否跨院系）。**去哪查**：项目管理办法与院系教务（链接待补）。
- [ ] **要填什么**：导师需要出具什么材料（签字、意见、承诺书），以及老师通常需要多长时间处理。**去哪查**：申报材料要求与亲历者（链接待补）。
- [ ] **要填什么**：立项评审的形式（书面评审、答辩还是两者都有）与考查重点。**去哪查**：项目当年通知与亲历者（链接待补）。
- [ ] **要填什么**：立项结果以什么形式、由谁通知，多久能知道。**去哪查**：项目通知渠道与亲历者（链接待补）。
- [ ] **要填什么**：项目的执行周期、起止与结题期限，以及能否延期、延期怎么申请。**去哪查**：项目管理办法与院系教务（链接待补）。
- [ ] **要填什么**：是否有中期检查，需要提交什么，不交有什么后果。**去哪查**：项目当年的过程管理要求（链接待补）。
- [ ] **要填什么**：结题验收的要求（报告、成果、答辩）与通过标准。**去哪查**：项目结题通知（链接待补）。
- [ ] **要填什么**：中途退出、更换题目或更换导师的规则与后果。**去哪查**：项目管理办法与院系教务（链接待补）。
- [ ] **要填什么**：资助形式（是否给经费、是报销制还是额度制）、报销范围与报销流程。**去哪查**：项目经费管理办法（链接待补）。
- [ ] **要填什么**：能否认定学分、算哪一类学分、需要提交什么材料、什么时候认定。**去哪查**：培养方案与院系教务（链接待补）。
- [ ] **要填什么**：团队项目的规则（人数上限、分工怎么写、个人贡献如何认定）。**去哪查**：项目当年通知（链接待补）。
- [ ] **要填什么**：是否允许跨院系、跨专业参与或跨学科组队。**去哪查**：项目通知与院系教务（链接待补）。
- [ ] **要填什么**：项目成果的署名与知识产权归属规则（谁署名、按什么顺序、能否对外发表）。**去哪查**：项目管理办法与导师（链接待补）。
- [ ] **要填什么**：项目能否与毕业设计、课程项目、竞赛项目叠加或复用同一份工作。**去哪查**：院系教务与项目管理办法（链接待补）。
- [ ] **要填什么**：项目经历在保研、评奖等评价环节中如何被认定（是否计入、需要什么证明）。**去哪查**：院系当年的评价办法与教务（链接待补）。
- [ ] **要填什么**：遇到争议或问题时的咨询与申诉渠道（哪个部门负责、时限多久）。**去哪查**：项目管理办法与院系正式渠道（链接待补）。

:::caution[填写时的三条纪律]
1. **注明适用年份、院系与项目名称**，没注明的条目读者无法判断是否还成立。
2. **区分"文件写的"和"我经历的"**：前者写文件和年份，后者写"某年某院系个人经历"。
3. **不确定就留着不填**。留空比写错安全得多——这也是这篇存在的意义。
:::

## 怎么自己找信息

三类渠道的分工不一样，**只用一个一定会漏**：

| 渠道 | 能得到什么 | 注意事项 |
| --- | --- | --- |
| **官方文件与通知** | 项目名称、资格、时间、经费与学分的唯一权威口径 | 以当年正式发布为准；不要拿往年的当今年用 |
| **院系教务** | 本院系有哪些项目、材料细节、学分怎么认 | 泛泛的问题问不出结果，带着清单里的具体条目去问 |
| **人**（导师、学长学姐） | 真实的投入强度、评审氛围、踩过的坑 | 一个人的经历不等于普遍情况，至少问两三个人、且问清是哪一年 |

**公开资料**：校内信息门户与教学相关站点（如 [信息门户](https://info.tsinghua.edu.cn/)、[网络学堂](https://learn.tsinghua.edu.cn/)）是查正式通知的入口；学生自发维护的资料库可以帮你知道"有哪些选项"，但不能替代官方口径：

- [清华大学计算机系学生科协技能引导文档](https://docs.net9.org/)
- [软件学院 ReadMe 互助文档](https://ssast-readme.github.io/)
- [未央书院学习资料](https://weiyangxuexi.github.io/)
- [CS 自学指南](https://csdiy.wiki/)：不依赖校内项目的自学路线，适合先判断自己对什么方向有兴趣。

**站内相关**：怎么找导师、第一封邮件怎么写，见[怎么进实验室做科研](/research/finding-a-lab/)；项目管理与协作工具见[Git 与 GitLab](/skills/git-and-gitlab/)；文献怎么管理与引用见[文献管理工具](/skills/reference-manager/)；和老师沟通的方式见[怎么和老师、导师、辅导员沟通](/mindset/talking-to-advisors/)；绩点与各种资格的关系见[绩点到底是怎么算的](/academics/gpa/)。

:::note[问问题的顺序]
先看官方文件把范围缩小，再带着**具体到条目**的问题去问人："申报表要不要导师签字""中期要交几份材料"——比"本科生科研难不难"有用一百倍。
:::

## 常见误解

以下几条**不依赖任何当年的政策细节**，所以可以放心写：

1. **以为"要先做出成果才能申报"。** 这类项目的设计初衷恰恰是给你从零开始的机会。**门槛通常在申报环节，而不是在成果环节。**
2. **以为必须自己找好导师才能报。** 有的项目由学生自己联系导师，有的由院系匹配或指定，**顺序可能正好相反**。先去确认自己属于哪一种，别在第一步就卡住。
3. **以为报了就有经费和学分。** 经费形式（报销制还是额度制）与学分认定口径差异很大，甚至可能没有。**把它当成额外收益，而不是申报理由。**
4. **以为项目等于一篇论文。** 多数项目的产出是过程性材料、一段可写入材料的研究经历、以及"我喜不喜欢做研究"的答案。**把发论文当作唯一目标，失望概率很高。**
5. **以为别人的经验能直接照搬。** 同一所学校不同院系、甚至同一院系不同年份，项目设置与材料要求都可能不同。**看别人的攻略只能当线索，条件必须自己核实。**

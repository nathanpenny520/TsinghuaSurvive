:::danger[本文尚未核实，不得作为申请规划的依据]
这篇目前**只有结构，没有事实**。材料类别和环节名称是"通常需要准备什么"的框架；**具体要求、分数门槛、截止日期、项目与院系清单全部留空**，等着亲历者逐条填写并注明适用年份。

**不要用本文判断"我该考什么""什么时候考""材料够不够"**。出国申请最终只以**每个目标项目自己的官方页面**为准——不同国家、不同项目之间的差异比很多人想象的大。
:::

出国申请是本站路线图里明确标为**不能猜**的三篇之一。它和保研、考研不同的地方在于：**没有统一的"学校口径"可参考**，规则分散在几百个彼此独立的项目页面里。

所以这篇的任务不是替谁规划，而是**把"要核实哪些事"整理成一份不会漏项的清单**。

## 这篇文章现在是什么状态

- **状态**：未核实骨架（`status: draft`，没有核对日期）。
- **谁来填**：真正走过完整申请季的人（含至少一位**非本人专业方向**的填写者，因为学科差异很大）。
- **填什么**：下面「需要核实的事实清单」的每一条，并注明**适用年份 + 目标国家/项目类型**。
- **读者怎么用**：当成"我要去项目官网核对哪些字段"的自查表，**不要**当成时间规划。
- **特别提醒**：申请信息**过期的速度很快**。一条三年前的经验，可能连考试形式都已经变了。

## 这篇文章不做什么

- **不写任何截止日期、考试时间与准备周期**。没有注明适用年份的时间点一律不写。
- **不写分数门槛与录取标准**。语言考试、标化考试的分数要求，以及"多少分够用"，只在项目的官方要求页里。
- **不写项目清单与选校建议**。不推荐任何学校、项目、专业方向，也不比较"哪个好申"。
- **不写文书模板与"话术"**。可以讲结构与方法，但不提供可直接套用的范文，更不写任何为迎合评审的包装手法。
- **不写任何中介与培训机构**。本站不导流、不推荐付费服务，本文也不会出现这类名称。
- **不写具体办事窗口与联系方式**。需要链接的地方一律写「（链接待补）」。
- **不写他人案例**。别人的录取结果属于个人隐私，不作为论据。

:::caution[关于"经验帖"的一句话]
下面出现的环节名（如"语言考试""文书""推荐信"）只用来**标出需要填的位置**，既不代表固定顺序，也不代表任何时间安排。
:::

## 流程概览：只写"有哪些环节"

出国申请通常可以拆成**四条并行推进的线**，它们互不替代：

| 线 | 包含的环节 | 需要在这里确认的事 |
| --- | --- | --- |
| **① 目标定位** | 确定国家/地区、学位类型、专业方向 | 项目之间在学制、费用、培养方式上的区别 |
| **② 语言与标化** | 报名、考试、送分、成绩有效期 | 认可哪些考试、送分怎么操作、是否接受替代方案 |
| **③ 材料准备** | 成绩单、推荐信、文书、简历、作品或研究材料 | 每份材料的格式要求与提交方式 |
| **④ 申请与后续** | 网申提交、面试/补充材料、结果、确认入学、签证与行前 | 网申系统的字段含义、结果的正式形式、后续手续 |

**这四条线在时间上高度重叠**，但**本文不写它们各自的起止时间**——那属于必须核实的部分。

### 材料清单（只有类别，没有格式要求）

下面每一类的**份数、格式、是否需盖章、由谁提交、能不能修改**都必须回到项目官方页面核实：

- **学业类**：成绩单、在读或学位证明、课程与评分体系的说明。
- **语言与标化类**：语言成绩及送分方式；若项目要求，标化成绩及送分方式。
- **推荐类**：推荐信（谁写、怎么提交、是否要推荐人本人操作）。
- **陈述类**：个人陈述 / 目的陈述、简历、研究计划或写作样本。
- **作品或研究材料**：作品集、论文、代码仓库等方向性材料。
- **表单与费用**：网申表格、申请费及可能的减免途径。
- **后续材料**：录取后的资金证明、签证材料、体检或注册材料。

:::tip[材料的三条通用纪律]
1. **先读项目官方页面，再读任何经验帖**——后者只用来解释前者看不懂的地方。
2. **把"依赖别人"的事排在前面**：成绩单、推荐信都要别人配合，它们才是关键路径。
3. **每个项目单独建一份要求表**。最容易犯的错，是把 A 项目的要求套到 B 项目上。
:::

## 需要核实的事实清单

每一条请写明**适用年份 + 目标国家或项目类型**。查不到就保持 `- [ ]`，不要猜。

- [ ] **要填什么**：目标项目的学位类型与学制（授课型/研究型、几年制）在实际就读体验上有什么差别。**去哪查**：项目官方页面（链接待补）。
- [ ] **要填什么**：语言考试的认可范围、成绩有效期与送分方式。**去哪查**：项目官方要求页 + 考试主办方的官方说明（链接待补）。
- [ ] **要填什么**：该项目是否要求标化考试，以及近年是否发生过要求变化。**去哪查**：项目官方要求页（链接待补）。
- [ ] **要填什么**：成绩单的办理流程（谁出、要不要盖章、要不要密封、电子版怎么发）。**去哪查**：学校教务相关流程说明（链接待补）。
- [ ] **要填什么**：评分体系如何换算或说明（是否需要附换算说明、由谁出具）。**去哪查**：项目官方要求页 + 学校相关部门（链接待补）。
- [ ] **要填什么**：推荐信的数量、提交方式，以及推荐人是否需要本人操作系统。**去哪查**：项目官方要求页（链接待补）。
- [ ] **要填什么**：文书的具体题目与篇幅要求，以及各项目之间的差异。**去哪查**：项目官方要求页与网申系统内说明（链接待补）。
- [ ] **要填什么**：网申系统的填写要点与容易填错的字段。**去哪查**：系统内的官方帮助页（链接待补）。
- [ ] **要填什么**：面试环节是否存在、形式是什么、考查什么。**去哪查**：项目官方说明与亲历者（链接待补）。
- [ ] **要填什么**：结果的正式通知形式，以及确认入学的正式流程（能否反悔、有无押金）。**去哪查**：项目官方说明（链接待补）。
- [ ] **要填什么**：申请费水平与可用的减免途径。**去哪查**：项目官方说明（链接待补）。
- [ ] **要填什么**：资金证明的要求与办理方式。**去哪查**：项目官方说明与签证要求页（链接待补）。
- [ ] **要填什么**：签证与行前的正式流程，以及哪些材料需要提前准备。**去哪查**：官方签证说明与学校相关通知（链接待补）。
- [ ] **要填什么**：学历/学位相关的官方认证或验证渠道怎么用。**去哪查**：[中国高等教育学生信息网](https://www.chsi.com.cn/) 的官方说明。
- [ ] **要填什么**：不同国家/地区在申请材料上的主要差异（例如是否需要研究计划、是否有统一申请系统）。**去哪查**：各项目官方页面（链接待补）。
- [ ] **要填什么**：如果同时拿到多个结果，确认入学的规则与时限是什么。**去哪查**：项目官方说明（链接待补）。
- [ ] **要填什么**：奖学金或资助渠道的申请方式（是否随申请一并提交、是否需要单独申请）。**去哪查**：项目与资助方官方页面（链接待补）。
- [ ] **要填什么**：如果申请不顺利，通常有哪些后续选项（延迟申请、换项目类型、先工作或先读本校）。**去哪查**：院系老师、学校就业与升学相关公开信息（链接待补）。

:::caution[填写时的三条纪律]
1. **每条注明年份和适用项目类型**，不要把某国某项目的要求写成普遍规则。
2. **优先填"会变"的条目**：考试要求、截止日期、材料形式。这些最容易过期。
3. **不确定就留空**。留空比写错安全——写错会直接让人错过申请。
:::

## 怎么自己找信息

| 渠道 | 能得到什么 | 注意事项 |
| --- | --- | --- |
| **项目官方页面** | 要求、材料、截止日期、流程的**唯一权威口径** | 逐个项目单独看；不要用一个项目的要求推断另一个 |
| **学校与院系的公开信息** | 成绩单办理、在学证明、交流项目等校内流程 | 以当年官方说明为准；流程会变 |
| **人**（学长学姐、导师、同方向的同学） | 真实的准备节奏、文书写作思路、面试体验 | 个人经验不可推广；至少问两三个不同背景的人 |
| **公开资料** | 了解"有哪些选项"、通用技能与工具 | 只当参考，不能替代官方要求 |

**校内入口**：查正式通知与办事流程可以从[信息门户](https://info.tsinghua.edu.cn/)入手；课程与教学材料在[网络学堂](https://learn.tsinghua.edu.cn/)；数据库、文献与检索培训见[图书馆](https://lib.tsinghua.edu.cn/)；升学与就业相关信息见[学校就业信息网](https://career.tsinghua.edu.cn/)；校外访问校内资源的方式见 [WebVPN](https://webvpn.tsinghua.edu.cn/)；账号与网络相关问题见[信息化相关站点](https://its.tsinghua.edu.cn/)。

**工具类公开资料**：文献条目与引用可以用 [Zotero](https://www.zotero.org/) 统一管理，排版与 LaTeX 入门可以看 [Overleaf 的公开学习文档](https://www.overleaf.com/learn)；引用规范见[作业、引用与 AI：学术规范的边界](/academics/academic-integrity/)。

**学生自发维护的资料库**（与学校官方无关，可能过期）：

- [清华大学计算机系学生科协技能引导文档](https://docs.net9.org/)
- [软件学院 ReadMe 互助文档](https://ssast-readme.github.io/)

## 常见误解

以下几条**不依赖任何当年的具体政策**：

1. **以为成绩和考试分数就是全部。** 申请材料之间是**互相解释**的关系：分数说明你的能力，文书和推荐信说明你为什么做这件事。只堆分数、把材料写成流水账，是更常见的问题。
2. **以为材料可以临时准备。** 成绩单要别人出，推荐信要别人写，语言成绩要提前考出来并送分。**这些事的时间不由你决定**，越晚开始可选项越少。
3. **以为要求各国各项目差不多。** 不同国家、不同项目在学制、材料、是否需要研究计划上差别很大；把一套材料原样投所有项目，通常会被看出来。
4. **以为推荐信只要"找个厉害的人签字"。** 推荐信的价值来自**推荐人了解你并能写出具体事情**。找一个不了解你的知名推荐人，往往不如一位带过你项目的老师。
5. **以为申请是一次性动作。** 它是一串需要提前很久铺路的准备工作：语言考试、研究经历、材料积累。**决定成败的部分大多发生在提交之前很久。**

## 申请怎么准备：一份可操作的时间轴与材料清单

**先分清两条路**：**学校派出的交换、联合培养、校际项目**走的是另一套流程——校内选拔、国际处或院系通知、学分与学籍安排，见[校际交流与联合培养](/research/international-programs/)。**本节讲的是另一件事：你自己申请出国读研究生**（通常是"大三开始准备、大四上学期提交、毕业后秋季入学"这条路）。两者共用语言成绩和推荐人，但流程、时间点和决策方都不一样，不要混着规划。

:::note[本节的事实来源与时效]
本节要点改写自《清华大学飞跃手册》（THU Feiyue Team，CC BY-NC 4.0，<https://feiyue.online/>）。**本节是改写，不是原文转载**。凡涉及时间点与先后顺序的表述来自该手册的时间线与准备工作两章，**准备篇幅与时长的说法来自准备工作这一章**。时效上要打个折：该手册仓库里正文（`docs/`）的最后一次内容提交在 2025 年 3 月（站点最近一次构建是 2026 年 8 月，但那次只是依赖升级），**各章更新并不同步**，签证、费用与材料清单这类章节可能更早。**这些内容会随时间变化**，本节只保留方法与节奏，**不保留任何分数门槛、具体金额和截止日期**。

上面的「待核实骨架」和本节是两种东西：**骨架负责列"要核实什么"，本节负责讲"事情之间是什么关系"**。两者的最终依据都是**目标项目的官方页面**。
:::

### 一条主线：从大一到大四，每个阶段该做什么

下表以**本科四年制、申请秋季入学**（Fall）为默认情形，写的是每个阶段"该动哪件事"。**它不承诺任何具体日期**，因为不同国家、不同项目的开放与截止时间差别很大；每个阶段的具体时点，以目标项目的官方页面为准。

| 阶段 | 该动的事 | 这一步的真正目的 |
| --- | --- | --- |
| **大三以前** | 维持成绩；积累科研与实习；想清楚大概方向（学位类型、国家/地区） | 这些是**唯一没法临时补**的部分，只能靠时间堆 |
| **大三上** | 开始准备并"试水"语言考试；如果打算做暑期科研，**这时候手上就要有一个可用的语言成绩**；有意向地进入课题组、开始积累关系 | 语言成绩卡着暑研，暑研卡着海外推荐信，**这是链条的起点** |
| **大三下（年初到四月）** | 联系暑期科研、申请暑期学校或校级交换 | 这一步依赖上一阶段的关系和成绩，**不是临时投简历** |
| **大三下与暑假** | 继续科研或实习、继续维持成绩；语言成绩如果还不理想就补考；有需要时开始了解并联系目标导师（套磁） | 把"经历"变成"可写进材料的具体成果" |
| **大四上** | 选校定位；开始写 CV 与个人陈述类文书；**联系推荐人**；办需要提前很久的文件类手续 | 这是**并行最密集的一段**：文书、推荐信、手续互相不等 |
| **大四上末到寒假** | 提交网申。**部分项目截止得比其他项目早得多** | 别用一个项目的时间推断另一个 |
| **大四下（年初到三月）** | 面试 | 拿到面试邀请就等于进了下一轮 |
| **大四下（四月到五月）** | 比较并确定去向；办签证；安排出行与住宿 | **签证是这一段的关键路径**，因为它依赖录取文件 |
| **毕业后秋季** | 入学 | — |

:::caution[两条容易被忽略的时点]
1. **手册给的总原则是：着手准备最好不晚于入学前 18 个月，一定不要晚于入学前 12 个月。** 晚于这个量级，有些标化考试和文件手续会来不及。按秋季入学倒推，就是大三上／大三下之前要动起来。
2. **地区差异很大**：有些地区的申请时间明显晚于其他地区（例如德国冬季学期入学的申请季节就靠后，还会涉及一套单独的学历审核流程）。**具体时点以目标项目官网为准**，不要拿一个地区的节奏去套另一个。
:::

另外，部分地区的部分项目有**提前批**（比常规批次更早开放、更早出结果）。这是"机会"也是"压力"：如果你大三下才决定出国，可能已经错过一批。**决定得越早，可选的路越多。**

### GPA 与标化：它们在申请里的位置

手册把常说的申请背景概括成"三维"：**语言 + 标化（GRE/GMAT）+ GPA**。理解这三样在评价体系里的位置，比追求某个具体数字重要。

- **GPA**：它证明你**能不能持续把一件事做好**，是唯一覆盖整个本科阶段的指标。而且它是**从大一开始就在积累**的，没有"临时补"的可能。至于"多少算够"，任何统一说法都会过期——**看目标项目官网**，或者问你这个方向的学长学姐和老师（相关的换算与口径问题见[绩点到底是怎么算的](/academics/gpa/)）。
- **语言成绩**：通常是**门槛型**而非竞争型指标——先要过项目的线，过了之后作用递减。**需要单独留意的是口语**：手册提到部分学校对口语单项另有要求，或者达不到就不给助教岗位。如果你是博士申请者或希望做助教，这一项要单独确认。
- **GRE / GMAT**：近年的趋势是**越来越多项目把它列为可选**，也常见没有这项成绩而被录取的情况。这恰恰意味着两件事：**先确认目标项目要不要**（别花半年考一个用不上的试）；如果要，它仍然是一项加分项。
- **先后顺序上有一个技巧**：如果两样都要考，**先准备 GRE 的语文部分**（它的词汇量要求最高），再回头准备语言考试会轻松一些。

:::tip[准备节奏（只讲节奏，不讲分数线）]
- **语言考试**：推荐的节奏是**大二下开始复习、大三考出来**。这样申请时成绩还在有效期内，而且能在暑期科研之前拿到成绩。考位紧张的城市尤其要提前约。
- **有效期**：语言成绩和 GRE 的有效期不同（通常语言成绩短、GRE 长）。**按"申请提交那一刻仍然有效"倒推考试时间**，别考太早。
- **别把考试留到大四上**。大四上要同时处理文书、推荐信和手续，那时候再考语言，等于把所有事压在同一周。
- **考完就送分**：送分是独立动作，要花时间，不是提交申请后自动完成。
:::

### 经历：科研、实习、交换各自管什么

| 经历 | 主要对谁有用 | 怎么积累 |
| --- | --- | --- |
| **科研** | 博士与学术型硕士（例如部分 MPhil 项目）；授课型硕士要求较低 | 通过院系官网找到方向的老师，**发邮件表达兴趣**、约面谈；或由带过你的老师引荐校外／海外机会。**进组越早，能产出的东西越多** |
| **实习** | 应用型、授课型硕士；**商科类项目权重最高** | 在**不影响基本学业的前提下**安排；每段结束后写清"做了什么、学到什么、产出是什么"，这份记录以后直接变成 CV 和文书内容 |
| **交换** | 所有方向都用得上，但它**首先是经历，不是背书** | 校内项目见[校际交流与联合培养](/research/international-programs/)；自己申请的暑期科研见[海外科研实习](/research/overseas-research-internship/) |

关于"什么经历更值钱"，手册给了一个**粗略的优先级**（学科不同、年份不同都会有变化，只当方向感）：**有产出的科研 > 没有产出的长期科研 > 短期科研**；**海外经历**的额外价值在于它往往能换回一封**海外推荐信**。

:::caution[别把这张排序当标准]
真实评价里，**一段能讲清楚的经历**常常胜过一段名头更大但你说不出自己做了什么经历。任何"排序"都只是聚合印象，不要用它否定自己手上已有的东西。
:::

### 推荐信：找谁写、什么时候开口、怎么让它有内容

推荐信是申请材料里**程序上唯一不经你手的部分**——它从第三方视角说明你的能力，别人承认你"好"，比你自己说更有效。也正因为如此，**它最容易变成流水线产物**，而流水线推荐信在评审眼里是一样的。

**找谁写：**

1. 优先找**和你有实质交集**的人：科研导师、课程老师、实习主管。
2. **优先找了解你的人**，而不是头衔最高的人。一位带过你项目的老师，通常比一位只记得你名字的知名学者有用。
3. 建议**同时联系 3 到 5 位**，防止有人临时反悔或提交不出来，导致数量不够。
4. **开口时就确认强度**。可以直接问："您能给我写一封支持力度比较强的推荐信吗？"——**含糊的推荐信比没有推荐信更糟**。
5. 有的申请系统会让推荐人再做一组"你有多推荐这位学生"的选择题。如果推荐人习惯性选中间选项，会拉低效果，可以礼貌提醒一句。

**什么时候开口**：**大四上选校定下来之后、越早越好**，在你要提交的第一个截止日期之前留出充足余量。临近截止还没提交的，要礼貌地发邮件提醒。

**怎么让它有内容**：**给推荐人材料**。联系时附上成绩单和 CV，并说明你申请的方向和理由。如果推荐人和你并不熟，这一步尤其必要——否则他只能写出"该生上课认真"这种没有信息量的话。

**推荐信通常包含三层**：

| 部分 | 写什么 | 你应该提供什么素材 |
| --- | --- | --- |
| 关系 | 推荐人怎么认识你、认识多久 | 你们相处的具体场景和时间 |
| 具体内容 | 你参与过什么、扮演什么角色、做出什么贡献 | 你做过的事、遇到的困难、怎么解决的 |
| 结论 | 为什么推荐你、你适合什么项目 | 你的目标方向和理由 |

**不同推荐人的侧重不同**：和你一起做过科研的老师，重点是**工作状态与合作体验**；只上过课的老师，重点是**学习态度与课堂互动**；带你最久的导师，则可以写多段经历、给一些"你是一个怎样的人"的判断。

:::tip[收尾也是关系的一部分]
确定去向之后，**告诉每一位推荐人你最后去了哪、并表示感谢**。这不只是礼貌——他们很可能是你以后还要请教的人。
:::

### 选校定位：分层，然后收集信息

选校要同时回答两个问题：**这个项目会不会录取我**，和**如果录了我去不去**。大部分人只想第一个，结果拿到一堆自己不想去的录取。

**分层策略**（手册的划分，三个等级各选若干，具体数量没有标准答案）：

| 等级 | 含义 | 注意 |
| --- | --- | --- |
| **彩票** | 你的水平低于该项目往年的平均录取情况，竞争非常激烈 | 还是会有人中，不要因为"不可能"就完全不投 |
| **主申 / 冲刺** | 和该项目往年平均录取水平接近，方向也匹配 | 这是你申请列表的主体 |
| **保底** | 你的背景明显高于该项目往年平均录取水平 | **不要选得太低**，被"overqualified"拒掉是真实存在的 |

**除录取难度之外还要看的因素**：

- **项目导向**：就业导向（大量实习、职业服务、位于产业城市）还是学术导向（理论课硬、科研机会多、转博情况好）。**打算读博却申了一堆就业导向的硕士，是最常见的南辕北辙。**
- **院系与导师**：博士申请尤其要看这个方向有没有人、导师在做什么。
- **开销**：学费加生活费，地区差异极大。这是很现实的筛选条件，不该到最后才想。
- **学校声誉**：打算回国和打算留在当地，看重的因素不一样。
- **生活环境与安全**：读博士这种长项目尤其值得考虑。

**信息从哪里来**：

- **项目官网是第一顺位**，任何其他来源都只用来解释官网里看不懂的地方。
- **往届案例与聚合信息**：看和你背景相近的人去了哪、什么时候出的结果。
- **学长学姐、老师和同方向的同学**：能问到官网不写的东西，但**至少问两三个背景不同的人**。
- **申请社区与论坛**：能拿到时间线和就读体验，但**信息噪声大、展示偏差明显**，只当线索。

**两个操作建议**：如果因素太多理不清，**先挑出你在意的两三个因素做粗筛**，几轮下来自然收敛；以及**每个项目单独建一份要求表**，最容易犯的错是把 A 项目的要求套到 B 项目上。

### 套磁：什么情况下有意义

"套磁"指**主动给教授发邮件建立联系**。它**不是所有人都要做**：

- **对博士和研究型项目有意义**，尤其是导师在招生上有实际话语权的情况（"强 faculty 制"）。
- **对授课型硕士通常意义不大**——这类项目由招生委员会统一决定，教授不负责你的培养。

**目的**：确认这位老师今年是否招生；让对方在收到你的材料之前就对你有印象；顺便了解他的招生意向。

**邮件写什么**（正文不用长）：

1. 你是谁，写这封邮件的目的是什么（一两句）。
2. 你对哪个研究话题感兴趣（一两句）。
3. **你和这位老师的工作"匹配"在哪里**（这一段是重点，多写几句）。
4. 邀请对方在方便的时候聊一次（一两句）。

写匹配点有两种风格：**偏保守**——说明他的研究启发了你什么、你认同他哪个判断；**偏主动**——指出他的某项工作可以怎么继续做下去，甚至你已经做了一个小 demo。两种都可以，**前提是你真的读过他的东西**。

:::tip[实操细节]
- **用学校邮箱发送**。教授每天收到大量邮件，用教育邮箱能降低被当成垃圾邮件的概率。
- **没有即时回复很正常**。老师忙，而且他对你不了解，需要先做点功课。等较长时间仍无回复，可以重新整理后**再发一次**。
- **提交申请之后仍可以继续联系**：告诉对方"我在材料里提到了你的研究方向"。评审面对一堆陌生材料时，一个熟悉的名字确实会带来一点优势。
:::

### 文书：每一份在回答什么问题

文书是**命题作文**，项目会给出要求。每一份的定位不同，混着写是常见的失败原因：

| 文书 | 回答的问题 | 常犯的错 |
| --- | --- | --- |
| **CV** | 你是谁、做过什么 | 与网申里填的信息不一致；只列职责不写结果 |
| **PS** | 是什么塑造了今天的你 | 写成了抒情散文，读完看不出你的能力 |
| **SOP** | 你想做什么、为什么是这个项目 | 把 CV 翻译成段落，没有"为什么" |
| **RP** | 你打算研究什么问题、怎么做 | 选题过大、方法说不清 |
| **Diversity Statement** | 你的背景能带来什么不同视角 | 把不属于该类别的身份也硬写进去 |
| **Writing Sample** | 你的学术写作水平 | 交一篇和申请方向无关的课程论文 |

**几个具体要点**：

- **CV**：浓缩在一到两页；教育背景里可以列几门有代表性的课程和成绩；工作或研究经历**用带结果的方式写**。不同国家对 CV 的期望不同（例如有的国家要求从小学写起的完整学历），**看项目要求**。
- **SOP 和 PS 有时不区分**。如果项目只给一个位置、名字混着写，**更建议按 SOP 的思路写**——也就是把"目的"讲清楚。
- **SOP 可以顺着 CV 的思路展开**，但要写 CV 里没有的东西：你**怎么**开始对一个问题感兴趣的、在经历里**具体做了什么**、**从中学到什么**、对目标项目和具体导师**为什么匹配**、毕业后的打算。
- **PS** 的落脚点是把**你的经历与性格**和**你的研究兴趣**连起来——让读者读完自然得出结论："这个人对研究有兴趣，也有潜力"。
- **RP、Diversity Statement、Writing Sample** 是**部分项目要求或可选**的材料，手册在写作方法上仍在征集经验。**先看项目要不要，再决定花多少时间。**

:::caution[写法上的两点提醒]
1. **不必刻意追求"文学性"**。手册里几位作者和老师的看法倾向一致：一篇结构清晰、学术亮点突出的文章，通常比一篇辞藻华丽但信息稀薄的文章更有效。当然，风格偏好因项目和读者而异，**这只是倾向，不是规则**。
2. **改是必须的**。文书要反复修改，但**不要为了"好看"写出你解释不了的内容**——面试会问到你写的东西。
:::

### 网申与面试

**网申是纯执行环节，错在细节上。** 开始之前先做三件事：

1. **把每个项目的提交时间汇总到一张表里**，并且**至少在入学前一年**就完成这件事——有项目的截止日期比你以为的早得多。
2. **别默认学校邮箱能收到验证邮件**。很多平台的通知邮件进不来，注册时可以用其他邮箱。
3. **准备一份"填写内容存档"**：第一次填完后把内容复制出来，后面的项目直接复用；也可以开浏览器的自动填充。

**提交前逐项检查**：

- [ ] **时间的自洽**：所有出现的日期彼此不矛盾（例如毕业时间与毕业证时间）。
- [ ] **文件的格式**：上传后能正常预览吗？预览效果是评审会看到的样子吗？
- [ ] **人名与机构名**：导师姓名、学校与院系的正式名称（含大小写和特殊符号）。
- [ ] **与 CV 一致**：网申里填的内容和 CV 里写的不能互相打架。

**提交之后**还可以做两件事：**继续和你提到过的老师保持联系**；以及**开始准备面试**。

**面试**因专业而异，甚至同一个项目换个面试官风格就完全不同。可以提前准备的通用部分：

- 一份**几分钟的自我介绍**，把亮点说清楚。
- 如果这个方向流行学术型面试，准备一份**讲自己研究经历的幻灯片**；知道面试官是谁的话，先了解他的研究方向。
- 如果你的背景有**重大缺陷**（比如核心课挂过），准备一个诚实、简洁的解释。
- 准备**你要问的问题**：资助形式、指导风格、课题组构成——这些你在选 offer 时一定会用到。
- **博士面试的常见问题**："如果我们给你 offer，你会来吗？"回答得含糊确实会增加被放进候补或拒绝的风险；但也**不必为了拿 offer 而含糊其辞**，他们已经想录你才会这么问。
- **形式上也值得准备**：穿什么、怎么打招呼、视频通话的背景，都会形成第一印象。

### 录取之后：从 offer 到出发的先后顺序

这一节只讲**要提前多久办、先后顺序是什么**，不写任何具体政策条文。具体手续一律以官方说明为准。

**第一步：先把 funding 看清楚。** 资助不只有"给多少"这一个维度，常见形式包括：

| 形式 | 大致含义 | 要看清楚什么 |
| --- | --- | --- |
| Fellowship | 通常不需要工作 | 覆盖几年、是否含保险 |
| Assistantship（TA / RA） | 需要用助教或助研工作换取 | 每周投入多少、是否影响你自己的进度 |
| Stipend | 生活补助 | 是否够当地生活、是否随年份调整 |
| 外部资助（如国家公派类项目） | 由外部机构提供 | 申请时间与你自己的申请季是否冲突 |

**不要只比总额**，要比**构成、年限和条件**：一个"总额高但要干很多助教"的方案，和一个"总额低但前两年不用干活"的方案，实际体验完全不同。**博士项目尤其要在接 offer 前问清楚**，因为它决定你未来几年的科研生活状态。

**第二步：比较并确定去向。**

- **回到申请前的排序**：如果你按分层选校做的列表，其实已经排过一次序了。
- **但想法会变**：申请季长达数月，你会拿到新信息，也会被新因素干扰（资助额度、导师去向、个人原因）。这时候**按个人志趣、发展计划和经济条件重新过一遍**，是正常且必要的。
- **决定权在你自己手里**。可以向师长、同学、家人征求意见，但最终是你去读。
- **如果一个 offer 都没有**：这不是世界的尽头。接受现实、快速调整，然后做下一步计划（补齐短板、换一批项目、考虑先工作或先读本校，等等）。见[失败之后怎么爬起来](/mindset/after-failure/)。

**第三步：把出发前的动作倒排。** 顺序是**先确定去向 → 再办签证 → 同时安排出行与住宿**，因为签证需要录取文件，而住宿谈判需要你确定城市和到达时间。

- **签证：留给它最多的时间。** 有两点是通用的：**一是它依赖录取方先出具文件**（学校处理这些文件的效率差别很大，别以为拿到 offer 就自动有了）；**二是不同国家、不同签证类型的流程差别极大**，有的需要提前数月启动一个单独的学历审核流程，有的需要面签和额外材料。**具体材料、预约方式与时限，以官方签证说明为准**——本节不写任何条文。
- **住宿：早考虑、早商量、早看房。** 位置远比"房子好不好看"重要，安全性、通勤方式、生活便利程度都要先想清楚；房租之外还会有水电网气、垃圾、停车、保险等费用，签合同前要看清**哪些包含、哪些不包含**。
- **一条硬提醒**：合同一旦签了，**因为个人原因不入住或提前退宿通常不能取消，只能转租**。所以签之前一定要确认。
- **谨防诈骗**：不要因为对方是"学长""熟人"就放松警惕。个别地区只支持线下看房，可以请当地的人帮忙看，或者入境后先住临时住处再找长租。

:::caution[行前部分最需要注意时效]
签证、租房和资助这三块的手续与费用**变化最快**，手册里相关内容的时间也比申请部分更早。**上面的顺序和"要提前多久"的思路可以照用，但任何具体数字、材料和政策都不要从这一页引用**——去官方网站看当年的说明。
:::

### 还能去哪查

:::caution[用飞跃数据库的正确方式]
[飞跃数据库](https://database.feiyue.online/) 是学生提交的**个人申请案例库**（GPA、背景、录取结果，按方向与项目组织）。它的用处是**看聚合口径**——比如某个方向的人大致来自什么背景、申请的时间线长什么样。

**不要做这两件事**：**不要把某个人的个案当成"门槛"**（一个人的录取结果说明不了任何标准，样本偏差极大）；**不要搬运里面的个人信息**。想判断自己的位置，看的是分布，不是某一个点。
:::

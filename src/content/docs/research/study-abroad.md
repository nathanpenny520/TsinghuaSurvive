:::danger[本文尚未核实，不得作为申请规划的依据]
这篇目前**只有结构，没有事实**。材料类别和环节名称是"通常需要准备什么"的框架；**具体要求、分数门槛、截止日期、项目与院系清单全部留空**，等着亲历者逐条填写并注明适用年份。

**不要用本文判断"我该考什么""什么时候考""材料够不够"**。出国申请最终只以**每个目标项目自己的官方页面**为准——不同国家、不同项目之间的差异比很多人想象的大。
:::

出国申请是本站路线图里明确标为**不能猜**的三篇之一。它和保研、考研不同的地方在于：**没有统一的"学校口径"可参考**，规则分散在几百个彼此独立的项目页面里。

所以这篇的任务不是替谁规划，而是**把"要核实哪些事"整理成一份不会漏项的清单**。

## 这篇文章现在是什么状态

- **状态**：未核实骨架（`status: draft`，没有核对日期）。
- **谁来填**：真正走过完整申请季的人（含至少一位**非本人专业方向**的填写者，因为学科差异很大）。
- **填什么**：下面「需要核实的事实清单」的每一条，并注明**适用年份 + 目标国家/项目类型**。
- **读者怎么用**：当成"我要去项目官网核对哪些字段"的自查表，**不要**当成时间规划。
- **特别提醒**：申请信息**过期的速度很快**。一条三年前的经验，可能连考试形式都已经变了。

## 这篇文章不做什么

- **不写任何截止日期、考试时间与准备周期**。没有注明适用年份的时间点一律不写。
- **不写分数门槛与录取标准**。语言考试、标化考试的分数要求，以及"多少分够用"，只在项目的官方要求页里。
- **不写项目清单与选校建议**。不推荐任何学校、项目、专业方向，也不比较"哪个好申"。
- **不写文书模板与"话术"**。可以讲结构与方法，但不提供可直接套用的范文，更不写任何为迎合评审的包装手法。
- **不写任何中介与培训机构**。本站不导流、不推荐付费服务，本文也不会出现这类名称。
- **不写具体办事窗口与联系方式**。需要链接的地方一律写「（链接待补）」。
- **不写他人案例**。别人的录取结果属于个人隐私，不作为论据。

:::caution[关于"经验帖"的一句话]
下面出现的环节名（如"语言考试""文书""推荐信"）只用来**标出需要填的位置**，既不代表固定顺序，也不代表任何时间安排。
:::

## 流程概览：只写"有哪些环节"

出国申请通常可以拆成**四条并行推进的线**，它们互不替代：

| 线 | 包含的环节 | 需要在这里确认的事 |
| --- | --- | --- |
| **① 目标定位** | 确定国家/地区、学位类型、专业方向 | 项目之间在学制、费用、培养方式上的区别 |
| **② 语言与标化** | 报名、考试、送分、成绩有效期 | 认可哪些考试、送分怎么操作、是否接受替代方案 |
| **③ 材料准备** | 成绩单、推荐信、文书、简历、作品或研究材料 | 每份材料的格式要求与提交方式 |
| **④ 申请与后续** | 网申提交、面试/补充材料、结果、确认入学、签证与行前 | 网申系统的字段含义、结果的正式形式、后续手续 |

**这四条线在时间上高度重叠**，但**本文不写它们各自的起止时间**——那属于必须核实的部分。

### 材料清单（只有类别，没有格式要求）

下面每一类的**份数、格式、是否需盖章、由谁提交、能不能修改**都必须回到项目官方页面核实：

- **学业类**：成绩单、在读或学位证明、课程与评分体系的说明。
- **语言与标化类**：语言成绩及送分方式；若项目要求，标化成绩及送分方式。
- **推荐类**：推荐信（谁写、怎么提交、是否要推荐人本人操作）。
- **陈述类**：个人陈述 / 目的陈述、简历、研究计划或写作样本。
- **作品或研究材料**：作品集、论文、代码仓库等方向性材料。
- **表单与费用**：网申表格、申请费及可能的减免途径。
- **后续材料**：录取后的资金证明、签证材料、体检或注册材料。

:::tip[材料的三条通用纪律]
1. **先读项目官方页面，再读任何经验帖**——后者只用来解释前者看不懂的地方。
2. **把"依赖别人"的事排在前面**：成绩单、推荐信都要别人配合，它们才是关键路径。
3. **每个项目单独建一份要求表**。最容易犯的错，是把 A 项目的要求套到 B 项目上。
:::

## 需要核实的事实清单

每一条请写明**适用年份 + 目标国家或项目类型**。查不到就保持 `- [ ]`，不要猜。

- [ ] **要填什么**：目标项目的学位类型与学制（授课型/研究型、几年制）在实际就读体验上有什么差别。**去哪查**：项目官方页面（链接待补）。
- [ ] **要填什么**：语言考试的认可范围、成绩有效期与送分方式。**去哪查**：项目官方要求页 + 考试主办方的官方说明（链接待补）。
- [ ] **要填什么**：该项目是否要求标化考试，以及近年是否发生过要求变化。**去哪查**：项目官方要求页（链接待补）。
- [ ] **要填什么**：成绩单的办理流程（谁出、要不要盖章、要不要密封、电子版怎么发）。**去哪查**：学校教务相关流程说明（链接待补）。
- [ ] **要填什么**：评分体系如何换算或说明（是否需要附换算说明、由谁出具）。**去哪查**：项目官方要求页 + 学校相关部门（链接待补）。
- [ ] **要填什么**：推荐信的数量、提交方式，以及推荐人是否需要本人操作系统。**去哪查**：项目官方要求页（链接待补）。
- [ ] **要填什么**：文书的具体题目与篇幅要求，以及各项目之间的差异。**去哪查**：项目官方要求页与网申系统内说明（链接待补）。
- [ ] **要填什么**：网申系统的填写要点与容易填错的字段。**去哪查**：系统内的官方帮助页（链接待补）。
- [ ] **要填什么**：面试环节是否存在、形式是什么、考查什么。**去哪查**：项目官方说明与亲历者（链接待补）。
- [ ] **要填什么**：结果的正式通知形式，以及确认入学的正式流程（能否反悔、有无押金）。**去哪查**：项目官方说明（链接待补）。
- [ ] **要填什么**：申请费水平与可用的减免途径。**去哪查**：项目官方说明（链接待补）。
- [ ] **要填什么**：资金证明的要求与办理方式。**去哪查**：项目官方说明与签证要求页（链接待补）。
- [ ] **要填什么**：签证与行前的正式流程，以及哪些材料需要提前准备。**去哪查**：官方签证说明与学校相关通知（链接待补）。
- [ ] **要填什么**：学历/学位相关的官方认证或验证渠道怎么用。**去哪查**：[中国高等教育学生信息网](https://www.chsi.com.cn/) 的官方说明。
- [ ] **要填什么**：不同国家/地区在申请材料上的主要差异（例如是否需要研究计划、是否有统一申请系统）。**去哪查**：各项目官方页面（链接待补）。
- [ ] **要填什么**：如果同时拿到多个结果，确认入学的规则与时限是什么。**去哪查**：项目官方说明（链接待补）。
- [ ] **要填什么**：奖学金或资助渠道的申请方式（是否随申请一并提交、是否需要单独申请）。**去哪查**：项目与资助方官方页面（链接待补）。
- [ ] **要填什么**：如果申请不顺利，通常有哪些后续选项（延迟申请、换项目类型、先工作或先读本校）。**去哪查**：院系老师、学校就业与升学相关公开信息（链接待补）。

:::caution[填写时的三条纪律]
1. **每条注明年份和适用项目类型**，不要把某国某项目的要求写成普遍规则。
2. **优先填"会变"的条目**：考试要求、截止日期、材料形式。这些最容易过期。
3. **不确定就留空**。留空比写错安全——写错会直接让人错过申请。
:::

## 怎么自己找信息

| 渠道 | 能得到什么 | 注意事项 |
| --- | --- | --- |
| **项目官方页面** | 要求、材料、截止日期、流程的**唯一权威口径** | 逐个项目单独看；不要用一个项目的要求推断另一个 |
| **学校与院系的公开信息** | 成绩单办理、在学证明、交流项目等校内流程 | 以当年官方说明为准；流程会变 |
| **人**（学长学姐、导师、同方向的同学） | 真实的准备节奏、文书写作思路、面试体验 | 个人经验不可推广；至少问两三个不同背景的人 |
| **公开资料** | 了解"有哪些选项"、通用技能与工具 | 只当参考，不能替代官方要求 |

**校内入口**：查正式通知与办事流程可以从[信息门户](https://info.tsinghua.edu.cn/)入手；课程与教学材料在[网络学堂](https://learn.tsinghua.edu.cn/)；数据库、文献与检索培训见[图书馆](https://lib.tsinghua.edu.cn/)；升学与就业相关信息见[学校就业信息网](https://career.tsinghua.edu.cn/)；校外访问校内资源的方式见 [WebVPN](https://webvpn.tsinghua.edu.cn/)；账号与网络相关问题见[信息化相关站点](https://its.tsinghua.edu.cn/)。

**工具类公开资料**：文献条目与引用可以用 [Zotero](https://www.zotero.org/) 统一管理，排版与 LaTeX 入门可以看 [Overleaf 的公开学习文档](https://www.overleaf.com/learn)；引用规范见[作业、引用与 AI：学术规范的边界](/academics/academic-integrity/)。

**学生自发维护的资料库**（与学校官方无关，可能过期）：

- [清华大学计算机系学生科协技能引导文档](https://docs.net9.org/)
- [软件学院 ReadMe 互助文档](https://ssast-readme.github.io/)
- [CS 自学指南](https://csdiy.wiki/)
- [清华大学飞跃数据库](https://database.feiyue.online/)：学生整理的申请**案例库**，按方向、项目与年份组织。看别人"什么背景、申了什么、结果如何"，比读任何攻略都直观；但**案例是个体经验，不能替代当年的项目要求**

**站内相关**：[怎么进实验室做科研](/research/finding-a-lab/)（研究经历与推荐信怎么积累）、[海外科研实习：怎么去、做什么、推荐信从哪来](/research/overseas-research-internship/)（本科阶段进海外课题组那一步的准备逻辑、推荐信与签证时间倒排）、[绩点到底是怎么算的](/academics/gpa/)、[怎么和老师、导师、辅导员沟通](/mindset/talking-to-advisors/)。看到一条经验，先问三个问题：**这是哪一年的？说的是哪个国家/哪类项目？写的人和我背景像吗？** 三个都答不上来，这条信息只能当线索。

## 常见误解

以下几条**不依赖任何当年的具体政策**：

1. **以为成绩和考试分数就是全部。** 申请材料之间是**互相解释**的关系：分数说明你的能力，文书和推荐信说明你为什么做这件事。只堆分数、把材料写成流水账，是更常见的问题。
2. **以为材料可以临时准备。** 成绩单要别人出，推荐信要别人写，语言成绩要提前考出来并送分。**这些事的时间不由你决定**，越晚开始可选项越少。
3. **以为要求各国各项目差不多。** 不同国家、不同项目在学制、材料、是否需要研究计划上差别很大；把一套材料原样投所有项目，通常会被看出来。
4. **以为推荐信只要"找个厉害的人签字"。** 推荐信的价值来自**推荐人了解你并能写出具体事情**。找一个不了解你的知名推荐人，往往不如一位带过你项目的老师。
5. **以为申请是一次性动作。** 它是一串需要提前很久铺路的准备工作：语言考试、研究经历、材料积累。**决定成败的部分大多发生在提交之前很久。**

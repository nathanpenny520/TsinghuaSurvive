第一次在群里看到「贵系」「叉院」「北馆」「新清」「猫超」连在一起，你大概会以为自己进错了群。这些词没人教你，但**听懂了，你就知道别人在说什么、该往哪走**。

这一页把常用简称、俗称和俚语整理成表。

:::caution[时效：这些词来自 2022 年]
本页内容整理自 **2022 年**由学生共享的一份词典（《一字班梗词典》摘编）。**其中与人和机构有关的称呼可能已经过时**——院系会改名、书院会增设、店铺会换、楼会翻新。

**与「人」有关的称呼，本页一律不收录**，原因见文章最后一节。
:::

## 先给结论

- **简称分四类**：学校、院系、楼与地点、课程与事务。**认不出某句话时，先判断它属于哪一类**；
- **同一栋楼可能有两个名字**，一个正式、一个俗称（比如「李文正馆」和「北馆」），听到哪个都不奇怪；
- **本站不写任何针对具体个人的外号或昵称**，不管是在任领导、老师还是同学；
- **这份表不是权威名单**。它是「帮助你不掉线」的工具，不是官方术语表。有疑问就问身边的同学，比查表快。

## 一、学校与隔壁

| 简称 | 全称 | 什么时候会听到 |
| --- | --- | --- |
| **T大 / 你清 / 华大 / THU** | 清华大学 | 校内的自指，尤其是自嘲或玩梗的时候；THU 是英文缩写，正式场合也用 |
| **P大 / 我北 / 隔壁 / PKU** | 北京大学 | 说「隔壁」时，默认对方知道指北大；两校的对比是校内常见话题 |

:::note[「隔壁」这个词要看语境]
在清华说「隔壁」，**绝大多数情况指北大**，因为两校就在一条街上。但在别的场合也可能指隔壁的院系或隔壁的楼。**用的时候加上下文，免得误会。**
:::

## 二、院系：外号比正名更常听到

院系的俗称多半来自老名字、班号或某个著名的大作业，**所以听起来跟正名完全没关系**。

| 简称 | 全称 | 说明 |
| --- | --- | --- |
| **贵系** | 计算机科学与技术系 | 校内最常听到的院系俗称之一 |
| **雷系** | 自动化系 | 因大作业「雷课堂」而得名 |
| **无系** | 电子系 | 沿用其旧称，「无」也是电子系的班号 |
| **叉院 / 茶园** | 交叉信息研究院 | 「叉」来自「交叉」；姚班、智班、量信班都是叉院的班级 |
| **浅蓝书院** | 未央书院 | 因院徽得名 |
| **深蓝书院** | 行健书院 | 因院徽得名 |
| **六边形书院** | 探微书院 | 因院徽得名 |

:::tip[为什么书院有「颜色」外号]
未央、行健、探微都是书院，各自有院徽，**颜色来自院徽的配色**。所以「深蓝」「浅蓝」不是评价，只是在描述徽章长什么样。
:::

## 三、楼与地点：一半是简称，一半是俗称

这一类最容易吃亏——**别人说「去北馆」，你在地图上搜不到「北馆」**。

### 图书馆

| 简称 | 全称 | 什么时候会听到 |
| --- | --- | --- |
| **北馆** | 李文正馆（图书馆三期工程） | 说「去北馆自习」时指的是这个 |
| **西馆** | 逸夫馆（图书馆二期工程） | |
| **老馆** | 图书馆一期工程 | **摘编时的状态是「目前关闭」**，去之前先确认 |
| **文图** | 凯风人文社科图书馆 | 人文社科类的书主要在这里 |
| **法图** | 法律图书馆 | |

### 教学楼、宿舍与操场

| 简称 | 全称 | 什么时候会听到 |
| --- | --- | --- |
| **X教** | 第 X 教室楼 | 清华有一教至六教，比如「六教」就是第六教室楼。课表上写「三教 3200」这类 |
| **技科楼** | 逸夫技术科学楼 | 常用教室 3216、3311、3417 **需要绕行**，第一次去留出时间 |
| **李兆基** | 李兆基科技大楼 | 规模较大、容易迷路；校园卡和网络服务大厅都在这里 |
| **蒙楼** | 可能是蒙民伟音乐厅、蒙民伟楼（艺教中心）或蒙民伟科技楼 | **听到这个词要追问一句**，它至少对应三个地方 |
| **新清** | 新清华学堂 | 大型活动和演出在这里 |
| **紫操** | 紫荆操场 | 同类说法还有**东操、西操** |
| **W楼** | 紫荆公寓北侧的一排宿舍楼 | 因形状像字母 W 得名 |
| **邺架轩** | 北馆地下的书店 | 可用于自习，**开放至深夜** |
| **猫超 / C超** | 天猫超市 | 在 C 楼地下 |
| **C楼** | 紫荆学生活动中心 | 因整体形状像字母 C 得名，是学生宿舍区各种商店和服务点的集中地 |

:::caution[「蒙楼」是个反例，值得记一下]
**这个词本身就是歧义的。** 摘编里说它「可能指」三个地方。遇到这种简称，**最省事的做法是直接问「哪个蒙楼」**，别赌。
:::

## 四、课程与事务

| 简称 | 全称 | 什么时候会听到 |
| --- | --- | --- |
| **DDL** | deadline，作业或任务的截止时间 | 日常口语里基本只用缩写：「这个 DDL 是周五」 |

:::caution[理论上最常听到的那几个词，这里没有]
「写沟」「思政」「通识」「SRT」这类课程与事务简称，**在本页的素材（2022 年学生共享词典）里并没有出现**，所以本站不写——**不凭印象补定义**，因为「写沟」到底指哪门课的哪个部分，不同院系的说法并不一致。

它们的准确含义，**以你所在院系的培养方案和当学期选课通知为准**：[培养方案与选课](/academics/course-selection/)、[各类课程怎么选](/academics/course-types/)。
:::

## 五、校园俚语

摘编里明确可以归入「俚语」的只有一条：

| 词 | 含义 |
| --- | --- |
| **精清** | 「精神上的清华人」，指对清华有强烈认同感、但不一定在清华的人 |
| **精北** | 同理，「精神上的北大人」 |

:::note[这两个词是玩梗，不是贬义]
「精清」「精北」是学生之间的玩笑说法，**没有任何评价色彩**，用在同学之间是自嘲或调侃。正式场合不要用。
:::

## 为什么不收个人外号

摘编的原文里确实有几条**在任校领导的昵称**。本页**一条都没有收录**，原因有三个：

1. **过时太快**。这类昵称跟着具体的人走，人一换，词就失效，而读者会拿着一个失效的词去理解现实；
2. **本站不指名评价任何人**。这是全站的写作红线——不评价老师、不评价同学、不评价领导。昵称常常带着姿态，哪怕原意是善意，写进一份会被新生当参考资料读的清单里，就变成了站队；
3. **它对你有害无益**。知道某个领导的外号，不会让你少跑一趟腿、少填一张表。**真正有用的是「这件事该找哪个部门、打哪个电话」**——那种信息在本站其它页面里，而且是标了来源的。

所以本站的取舍是：**机构、地点、课程、事务的简称收；人的外号不收。**

## 这里有什么、没有什么

本站只有三类内容，刻意保持简单：

| 类型 | 在哪 | 用途 |
| --- | --- | --- |
| **经验帖** | 「新生入学 / 学业 / 科研与深造 / 校园生活 / 心态与避坑」 | 具体问题怎么写、怎么选、怎么避坑 |
| **工具页** | 「实用工具」下的[校内常用链接](/guides/links/)和[资料下载](/guides/resources/) | 直达入口，不用再翻聊天记录找网址 |
| **说明页** | 你现在看的这篇，以及[免责声明](/start/disclaimer/) | 约定边界，避免误用 |

**没有的东西**：没有评论区，没有账号系统，不收集你的任何信息。想反馈就通过页脚的 GitHub 入口，或者直接联系写这篇的人。

## 页面上的几个标记

- **需校内网**：这个入口要在校园网（或学校 VPN）里才能打开。
- **待核对**：网址或资料链接还没人亲自点开确认过。看到它请多留个心眼，别直接转发给别人。
- **待补充**：我们知道需要这份资料，但还没整理好。
- **内容可能已过期**：页面顶部的横幅。学校规则改了，而我们还没来得及更新。

:::caution
只要页面上出现了上面任何一种标记，就说明这块内容还没到"可以闭眼相信"的程度。涉及报名、截止、考核的事情，**一律去官方系统再确认一遍**。
:::

## 搜索

右上角的搜索框是全站可用的，支持中文。因为中文没有词形变化，搜索时建议用**两三个字的关键词**而不是整句话：

- 搜「绩点」「培养方案」「保研」「选课」比搜「我想知道绩点怎么算」命中率高得多。
- 也可以按住 <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>K</kbd> 直接唤出。

## 内容的时效性

经验类内容的保质期比想象中短。我们的做法是：

1. 每篇都在页脚显示**最近更新时间**（取自 Git 提交记录）。
2. 制度性内容一旦确认过期，会在页面顶部加横幅说明，而不是直接删掉。
3. 每篇正文里会写「**以官方为准**」的那类细节，请当它是提醒，不是客套话。

## 发现错误怎么办

非常欢迎。三种方式，从轻到重：

- 在页面底部点「编辑此页」，直接改完提 PR——**最快**。
- 到 [GitHub Issues](https://github.com/nathanpenny520/TsinghuaSurvive/issues/new) 描述问题，我们来改。
- 认识作者的话，直接微信拍他一下。

具体流程见[怎么贡献一篇经验帖](/contribute/)。

学术规范这件事，绝大多数人不是想违规，而是**不知道界线画在哪**：和同学讨论到什么程度算合作？改写了别人的句子要不要标来源？用 AI 改语法算不算作弊？

先给三条结论：

1. **别人的东西，用了就标**。直接引用要标，改写要标，翻译也要标。
2. **你的作业要能由你独立复现**。代码能解释、数据能追溯、思路能讲清——这是所有规范的共同底线。
3. **AI 可以是工具，不能是作者**。查资料、解释概念、改语法通常没问题；把它生成的内容当成自己的成果提交，就是另一回事。

## 这篇文章不做什么

- **不引用具体条文编号**。学校的学生纪律处分管理规定对课程作业抄袭、篡改实验数据等情形有明确处分条款，**具体条文以学校正式发布为准**，本文不复述原文、不标注编号。
- **不给查重系统的名称和阈值**。不同工具、不同课程的口径都不一样，写死数字只会误导人。
- **不教任何规避方法**。本文只讲界线在哪，不讲怎么绕过去。
- **不代替课程要求**。课程之间差异极大，任课教师和院系说的永远优先于本文。

:::caution
本文写的是通用原则。**具体的引用格式、合作尺度、AI 使用规定，以任课教师和院系的当学期要求为准**；涉及处分与申诉的部分，以学校正式发布的文件为准。
:::

## 引用与抄袭的分界线

判断标准其实只有一句话：**读者能不能看出这部分是谁的成果。**

| 你做的事 | 要不要标注 | 说明 |
| --- | --- | --- |
| 直接引用原文（含公式、定义） | **必须** | 引号或引用块 + 出处，缺一不可 |
| 改写别人的论述 | **必须** | 换词不换意，仍然是使用他人成果 |
| 翻译外文材料 | **必须** | 翻译不产生你的原创性 |
| 使用他人的数据、图表 | **必须** | 只写"数据来源：网络"不算标注 |
| 使用他人的代码片段 | **必须** | 注明出处，并遵守原项目的许可证要求 |
| 沿用他人论文的整体结构或论证框架 | **建议标注** | 结构照搬同样可能被认定为不当使用 |
| 自己独立完成的分析与写作 | 不需要 | 这才是你真正的成果 |
| 与同学讨论后自己写出的内容 | 通常不需要 | 合作作业另有规定，见下一节 |

:::caution
**"我改写了""我翻译成中文了""我在网上找的"都不是免责理由。** 反过来，标注来源不会让你的成果变少——规范引用恰恰说明你读过东西。
:::

### 数据与代码的归属

- **数据**：来源、采集时间、处理方式要写清楚。用公开数据集要标注；如果数据来自实验室或课题组，**能不能用、能用到什么程度，要先问数据的所有者**。
- **代码**：参考开源项目要遵守它的许可证（有的要求署名，有的要求以相同许可开源）。把别人的仓库当成自己的作业提交，改写多少都算使用他人成果。
- **未公开的材料**：他人的未发表论文、未提交的作业、老师的课件与题目，未经允许不要复制、不要传播，也不要用作自己作业的素材。

### 合作作业与独立完成的边界

**通常允许**：

- 讨论题意，确认彼此对课程要求的理解；
- 一起推导思路、互相讲清某个概念；
- 讨论调试方法，说"我卡在哪一类问题上"；
- 讨论结束后，各自独立写出自己的解答。

**通常越界**：

- 对着别人的答案抄写，或把解答拍照发出去；
- 共享代码文件、共用一份报告文本；
- "你写前三题我写后三题"再拼起来（除非课程明确允许分工）；
- 替别人写，或请别人替自己写。

:::tip
一个自检标准：**如果老师让你当场讲一遍这份作业的每个部分，你能讲清楚吗？** 讲不清的部分，通常也正是说不清来源的部分。
:::

## 三类场景：能做 / 不能做

### 实验报告

| 能做 | 不能做 |
| --- | --- |
| 如实记录原始数据，保留记录本和原始文件 | 修改、挑选、编造数据点让曲线"更好看" |
| 讨论实验原理、误差来源、操作技巧 | 抄别人的数据、结论或整段分析 |
| 引用文献里的公式并标注来源 | 把文献数据写成自己测出来的 |
| 明确写出"本组合作完成"的部分 | 把组内他人独立完成的部分写成自己做的 |

:::danger
**伪造和篡改数据是学术规范里最严重的一类问题**，学校的学生纪律处分管理规定对这类情形有明确条款。实验失败不是问题——把失败过程和原因写清楚，通常比一份"完美数据"更被认可；编数据才是不可逆的错误。
:::

### 代码作业

| 能做 | 不能做 |
| --- | --- |
| 查文档、查教材、看公开的技术文章 | 把别人的完整实现改改变量名后提交 |
| 与同学讨论算法思路和调试方法 | 共享代码文件、互相拷贝 |
| 使用课程允许的库和框架 | 使用课程未允许的现成实现 |
| 借助工具解释报错、理解语法 | 把生成工具产出的整段代码当作自主完成提交 |
| 在注释里注明参考来源 | 删掉原作者的版权声明当成自己的代码 |

### 论文与课程论文

| 能做 | 不能做 |
| --- | --- |
| 用文献管理工具整理参考文献 | 在参考文献里堆没读过的文献凑数 |
| 引用、改写、翻译他人论述并规范标注 | 多篇文献拼贴而不标注（怎么改词都算） |
| 用工具做语法润色、调整表达 | 让工具产出论点与论证主体，自己只做粘贴 |
| 向老师或助教确认引用格式要求 | 同一篇论文交两门课（除非课程明确允许） |
| 提前规划写作时间，留出修改轮次 | 临时拼凑、复制网络上的段落 |

常用工具：文献条目和引用格式可以用 [Zotero](https://www.zotero.org/) 这类文献管理软件统一维护；排版工具（如 LaTeX）的入门可以看 [Overleaf 的公开学习文档](https://www.overleaf.com/learn)；学校[图书馆](https://lib.tsinghua.edu.cn/)提供哪些数据库和使用培训，以图书馆页面的说明为准。

## 查重工具只是辅助

**重复率低不等于没有抄袭。** 反过来也成立：重复率高也不必然是抄袭——规范引用、题目原文、术语固定表述都会造成重复。

低重复率为什么不能证明清白：

- **改写和翻译**能显著降低字面重复率，但仍然是使用他人成果；
- **未收录的来源**（未发表的报告、外文材料、他人未提交的作业）本来就不在比对范围里；
- **代写和拼凑**可能逐句都是新写的，但整体不是你的工作；
- **思路和结构**的照搬，多数工具识别不出来。

:::caution
不要把"降重"当成写作目标。为了压低重复率而生硬替换词语、打乱语序，既不改善内容，还可能让表述变得不准确。**先把来源标清楚，再谈重复率。**
:::

## AI 工具的使用边界

总原则：**AI 可以参与过程，不能替代你对内容的责任。** 提交的东西，你要能解释、能负责。

**通常可以（仍需先确认课程规定）**：

- 查资料线索、解释概念、梳理知识框架；
- 改语法、润色表达、翻译后自己逐句核对；
- 生成样板代码、给出报错排查方向；
- 检查格式、核对引用条目是否完整。

**通常不可以**：

- **直接提交生成内容**：把工具写出的段落、论文、报告当作自己的成果；
- **代写**：让工具产出论点与论证主体，自己只做粘贴；
- **伪造材料**：用工具生成"实验结果"、编造参考文献；
- **把未公开的他人材料喂给模型**：未发表论文、老师的题目与课件、同学的作业，以及任何含个人信息的内容；
- **无视课程明确的禁止性要求**：课程说了不许用，用了就是违规。

:::caution[规定不一致时怎么办]
不同课程、不同院系对 AI 的要求差别很大：有的完全禁止，有的允许但要声明用途，有的只允许语言润色。

**当课程要求、院系规定和你的理解不一致时，以任课教师和院系的要求为准。** 不确定就直接问老师或助教——**提前问是"确认规则"，事后说就是"事后解释"，性质完全不同。**
:::

:::tip[如果要用，就声明]
课程允许使用 AI 时，在作业里写清楚**用在哪一步、用来做什么**（例如"英文摘要经工具润色后由本人核对"）。一句话的说明，能省掉后面绝大多数麻烦。
:::

## 万一已经越界了

最好的策略是**尽早主动沟通**，而不是等被发现。

1. **停止继续**。不要为了圆一个错再改数据、再补材料，那会把一个问题变成两个。
2. **保留原貌**。不要删除原始记录和过程文件——它们恰恰是你说明情况时最有用的东西。
3. **主动说明**。向任课教师或院系教务说明时间、范围和原因，不要托人转述，也不要拖到成绩公布之后。
4. **准备补救**。可以争取重做、补交、按规范重新标注来源；具体怎么处理由任课教师和院系决定。
5. **有异议就走正式渠道**。对处理结果有异议时，按学校正式发布的申诉流程提出，**受理渠道和时限以官方通知为准**（本文不列具体窗口和电话）。

:::note
主动沟通不保证没有后果，但拖着不说通常会让你的可选项变少。这条不是"话术"，而是从处理流程本身推出来的：越早说明，可补救的空间越大。
:::

## 提交前的自查清单

- [ ] 所有直接引用的原文都加了引号或引用块，并写明出处。
- [ ] 所有改写、翻译、借用框架的部分都标注了来源。
- [ ] 数据、图表、代码片段注明了出处，使用他人代码时遵守了原项目许可证。
- [ ] 实验数据是原始记录的真实结果，没有挑选、修改或编造。
- [ ] 合作作业里，属于他人的部分已明确说明，不是"分工拼装"。
- [ ] 参考文献列表里的每一条我都真的读过并核对过。
- [ ] 如果用了 AI 工具，用途已在作业中声明，且符合课程要求。
- [ ] 没有把未公开的他人材料（论文、题目、课件、他人作业）交给任何工具。
- [ ] 我能不看稿，口头讲清这份作业每个部分是怎么来的。
- [ ] 我确认过这门课对引用格式、合作方式、AI 使用的具体要求。

十条里有一条打不上钩，就先别提交，去问清楚。

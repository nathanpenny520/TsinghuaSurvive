大部分人考砸不是因为没复习，而是因为**用错了复习方式**。而退课和重修之所以容易出问题，是因为**它们都有时间窗口，错过了就没有补救机会**。

## 第一步：先搞清这门课怎么给分

拿到成绩构成之后，复习策略基本就定了：

| 成绩构成 | 复习策略 | 风险 |
| --- | --- | --- |
| **期末一考定音**（>70%） | 提前 3 周进入复习，真题优先 | 一次失误无法挽回 |
| **平时 + 期末各半** | 平时作业一次不落，期末按部就班 | 平时偷懒会累积成硬伤 |
| **大作业 / 论文为主** | 尽早开工，留出修改时间 | 拖延到期末会和别的课撞车 |
| **小组项目** | 明确分工，把分工写下来 | 搭便车会让你一个人扛 |

:::tip
**第一节课一定要听评分规则**，并且当场记下来。很多课第一节课就讲完了成绩构成，之后再也不提，而这是整个学期最关键的信息之一。
:::

## 复习：真题 > 笔记 > 教材

按投入产出比排序：

1. **往年题**。这是最有效的材料，能直接告诉你考什么、怎么考。问学长学姐要，或者看课程群里的资料。
2. **老师划的重点**。最后一节课不要缺席，信息密度极高。
3. **自己整理的笔记**。**整理笔记的过程就是复习**，不要只借别人的笔记看。
4. **教材**。用来补概念漏洞，不适合从头通读。

:::caution[小组作业的坑]
**把分工写下来并留痕**（群里发一遍）。不是为了撕破脸，而是最后评分出现争议时，你有东西可依。每年都有人因为口头分工最后自己扛了全部工作。
:::

## 退课：看清两个问题再决定

退课不是一个"要不要"的问题，是两个事实问题：

1. **退课后成绩单上会留下什么？** 有些情况是无声消失，有些会留痕。
2. **退课会不会影响培养方案的进度？** 比如它是后续课程的先修课，退了可能连锁影响。

:::danger
**退课截止时间是最容易错过的时间节点。** 它通常比期中还早，而且过了就没有例外。**开学第一周就把本学期所有截止日期记在日历里**，设提醒。
:::

**什么情况下应该退**：

- 你确定这门课会显著拖累绩点，且有替代课程可以补上学分；
- 课业量远超预期，正在挤压其他更重要的课；
- 与专业方向不符，且不是必修。

**什么情况下不该退**：仅仅因为"感觉难"或者"老师讲得不好"。先弄清楚考核方式，很可能并没有你想象的那么难。

## 重修：先算清代价

知道有人会为了刷绩点重修低分课程。**在动手之前必须确认三件事**：

- **政策允许吗**？（有些课程不允许重修，有些有次数限制）
- **成绩怎么记**？（是取最高分，还是两次都显示，还是取平均）
- **时间成本值不值**？（重修要占用下一学期的课时和考试周）

:::caution
**"有人这么干成功了"不是依据。** 政策每年会变，不同院系也不一样。一定要自己去教务系统或问教务老师确认你那一届的规则。
:::

## 缓考、缺考与成绩申诉

- **缓考**：身体或家庭突发原因导致无法参加考试，需要**提前**按流程申请并提供证明。考完再补申请通常不行。
- **缺考**：无故缺考通常按不及格处理，后果比挂科更重。
- **成绩申诉**：发现成绩明显异常（漏登、算错、主观题分数明显不符）时，**越早提出越好**。先找任课老师，再走教务流程。**保留好你的作业和试卷依据。**

## 官方口径：成绩怎么记、考不成怎么办

上面几节讲的是判断方法，这一节换成**制度原文的口径**，用来回答"我这门课最后会怎么记在成绩单上"。

来源：《清华大学学生手册（2024）》之《清华大学课程成绩管理办法》《清华大学本科生学籍管理规定》《清华大学选课管理办法》《清华大学本科体育课程的有关规定及要求》《清华大学本科生公共外语课程设置及修读管理办法》；《清华大学本科生学习指南（2023）》第七章 课程考核。**规则会随年份调整**，办事前请以注册中心、教务处和你所在院系的当年通知为准。

### 第一步：搞清考核方式与成绩记法

考核分**考试**与**考查**两种：考试包括闭卷、开卷、口试等；考查包括大作业、课程论文、研究报告、成果展示或答辩等。**考核方式由开课院系和课程负责人确定，写在课程教学大纲里**；全校性选修课、以实验为主的课程和实践类课程一般采用考查方式。

成绩怎么记，看下面这张表：

| 记法 | 含义 | 哪些情况用 | 学分与 GPA |
| --- | --- | --- | --- |
| **A+、A、A-、B+、B、B-、C+、C、C-、D+、D** | 等级制中的合格档 | 学校从 2015 年入学的学生开始，以等级制评定和记载成绩；考试课程成绩一般以等级制形式记载 | 取得学分，**参与**平均学分绩点计算 |
| **F** | Fail，不及格 | 考核不合格；违反考核纪律导致该课程考核成绩无效；选课后在规定期间内未办理退课手续又不参加课程学习或考核 | 不能取得学分；绩点记为 0 |
| **百分制** | 百分制成绩 | 2015 年之前入学的学生采用百分制；2015 至 2018 年入学的学生，学校**同时出具**每门课等级制成绩的对等百分成绩 | 见当年成绩单说明 |
| **P / F** | Pass / Fail，通过 / 不通过 | 考查课程一般以 P、F 形式记载；本科生每学期还可选择**一门任选课**以 P、F 记载 | P 取得学分，但**以 P、F 形式记载的课程不参与 GPA 计算** |
| **I** | Incomplete，未完成 | 课程考核期间因病等特殊情况不能参加考核，提出申请并经教学主管部门批准后备案记载 | 不参与 GPA 计算；在规定期间内完成考核后登载成绩并**取消原 I 记录** |
| **W** | Withdrew，退课 | 在"退课阶段"办理的退课。补退选期间的退课**不记载**，其后"退课期间"办理的才记载 | 不参与 GPA 计算 |
| **EX** | Exempted，免修 | 通过免修考核后按免修记载 | 取得学分，但**不参与 GPA 计算** |

:::caution[待核对：P/F 的办理时间点]
《本科生学习指南（2023）》第七章写的是"由学生本人于课程修读学期**第六周**在网上进行选择"；注册中心公布的选课规则表述为**网选结束后不可更改**。两处口径的年份不同，**你这一届按哪个时间点办，请在当学期选课系统与注册中心通知里确认**，不要按本文的年份推断。
:::

### 第二步：考不成、考不好，分别怎么处理

| 事项 | 触发条件 | 怎么申请 | 成绩 / 学籍上会怎样 |
| --- | --- | --- | --- |
| **缓考** | 因病或其他个人特殊原因不能参加课程考核 | 应当在**课程考核前**向所属院系提出**书面**缓考申请并提交《课程缓考申请表》；因病需同时提交校医院或二级甲等以上医院诊断证明 | 成绩单上该课程记为 **I**；可在缓考课程开设学期重修该课程，考核合格后**取消原 I 记录** |
| **重修** | 课程考核不合格；选课办法另说明**缓考的课程**也可重修选课。已考核合格的课程**不得**申请重修 | 在选课期间按重修选课办理。《本科体育课程的有关规定及要求》另规定：体育课不及格、或已办理退课/缓考手续的，须在**学年度对应学期**重（补）修，在预选或正选期间选**课序号 88**的体育课，再在分项选课期间上网选有余量的项目 | **重修成绩按学期记载**；在规定的学习年限内**重修次数不限**；**重修的课程不得申请免修** |
| **考试时间冲突** | 两门及以上考试时间冲突 | 在**规定时间内**到所属院系教学业务办公室登记，由教务人员协调考试先后顺序 | 冲突课程采取"考完一门紧接着安排第二门"；公共课与专业课冲突先考公共课，外院系与本院系课程冲突先考外院系课程，重修课与本学期课程冲突先考重修课；其他情况由注册中心协调 |
| **免修** | 除思想政治理论课、体育课、实验课、实践类课程、军事理论与技能训练、课程设计和综合论文训练以外的部分课程可申请。从中国人民解放军（含中国人民武装警察部队）退役后入学或复学的学生，可申请免修**体育课、军事理论与技能训练**，直接获得相应学分 | 本人在拟申请免修课程**开课 2 周内**向开课院系提出书面申请，提交《本科生免修课程申请审批表》。是否接受申请、以及免修考核的方式、内容、评价标准，由**任课教师**决定 | 通过考核的按 **EX** 记载、取得学分、**不参与平均学分绩点计算**；未通过的应当正常修课。在校期间**一门课程只允许申请免修一次** |
| **自修** | **平均学分绩点在 3.3 以上**可以申请自修部分课程；另外，所选课程上课时间存在**局部冲突**时，征得任课教师同意后可自修其中一门课程冲突部分的内容 | 自修课程应当经**任课教师同意、所在院系教学负责人批准** | 须按时完成课程要求并**参加课程考核**，考核合格取得学分。课程范围限制与免修相同：思想政治理论课、体育课、实验课、实践类课程、军事理论与技能训练、课程设计和综合论文训练**不列入**申请自修范围 |
| **成绩复议** | 对课程成绩有异议 | 在**成绩复议期内**向**开课院系教学业务办公室**提交《成绩复议申请表》（教学门户"办事流程与表格 / 学生相关 / 成绩、缓考"下载）。复议期一般为**下学期开学第一周**，逾期不予受理 | 由开课院系指派专人组成审核小组复议；确需更改的，由任课教师填写成绩更改申请表、经院系教学主管领导核准签字盖章后，在**开学第二周（含）前**报注册中心 |

:::caution[成绩复议：别越过渠道直接找老师]
学校明确**禁止学生以种种理由、各种方式直接要求任课教师更改成绩**；对严重干扰任课教师正常工作和生活、造成不良影响的，学校依规进行严肃处理。有异议就走**开课院系教学业务办公室**这条正式渠道。本文只讲渠道，不列具体窗口日期。
:::

:::caution[待核对：体育课与外语课的免修例外]
- **体育课程不允许免修**，也不允许自修；因身体情况（主要是内脏器官等慢性疾病或术后恢复期）不能参加正常体育活动的，学校另设**体疗课程**，申请与审批手续在每学期开学第一周内办理，成绩单独登录（按原文，总评成绩上限为 B）。本文不复述具体系数与流程表。
- **公共外语**方面，英语综合能力课组设有免修条件（与入学分级考试级别、院系全英文专业课等有关），**免修由语言中心审核**。具体条件表和办理流程请查《本科生公共外语课程设置及修读管理办法》当年的原文。
:::

## 考试周的时间管理

考试周最怕的不是难，是**几门考试挤在一起**。

- **提前两周画出考试时间表**，标出每门的间隔天数。
- **给间隔短的科目提前准备**，别指望考完上一门再突击下一门。
- **接受"不可能每门都复习到位"**，按学分和难度分配时间，而不是平均用力。
- **睡眠优先于最后两小时的突击**。缺觉进考场，损失远大于多背两个知识点。

## 关于挂科

如果已经挂科了：

1. **先确认补考/重修的具体安排**，不要靠打听。
2. **算清楚它对保研、评奖、毕业的实际影响**。有些情况下影响有限，不要自己吓自己。
3. **该修的课认真修**。重修一次通过，比反复纠结划算得多。

心态上的事，见[大一最容易踩的几个坑](/mindset/first-year-pitfalls/)里的最后一节。

[培养方案与选课](/academics/course-selection/) 给的是判断顺序，[各类课程怎么选](/academics/course-types/) 给的是分类逻辑。
但真到选课前一周，你面对的是**五到八门候选课在脑子里互相打架**：哪两门的期末会撞在一起、哪门课的先修你还没修、加起来每周要花多少小时。

这一页把那件事变成一张表。填完你会得到一份**风险清单**，而不是一个分数。

<SelectionWorkbench />

## 这个工具做什么、不做什么

| 它做 | 它不做 |
| --- | --- |
| 把你填的每周投入加起来，和**你自己填的**承受基线比 | 不告诉你「一学期最多修几学分」——没有这个通用数字 |
| 按固定规则找出先修缺口、期末撞车、一锤定音的课 | 不评价任何老师，不预置任何课程的数据 |
| 把你的判断落成一份可以打印、可以导出的表 | 不替你做决定——最后一步永远是你自己的 |

:::caution[最重要的一条]
工具里**没有一个是学校的数字**。学分上限、退课截止时间、课程考核比例、先修关系，这些每届、每院系、每门课都不同，本站一律不预设、不猜。
你在上面填的所有内容都是**你自己的估计**；制度的答案只有两个地方有：培养方案和开课院系的通知。
:::

## 规则原文

提示是按下面这几条算的，你可以自己核对。它们都只用你填的信息，没有一条依赖外部数据。

| 提示 | 触发的条件 | 为什么值得看 |
| --- | --- | --- |
| **先修链** | 某门课填了先修课，但「先修已修」没勾 | 先修没修就去上，最常见的结果是前六周都在补前置知识 |
| **期末撞车** | 满足①「投入曲线」是后重，或②勾了期末考试/课程论文且**不是**前重型 —— 这样的课达到 3 门及以上 | 两门课总投入一样时，扛不扛得住取决于它们会不会压在同一周 |
| **开学撞车** | 3 门及以上是「前重」型 | 开学第一个月还叠加了选课、退课、社团招新和适应成本 |
| **一锤定音** | 勾了期末考试或课程论文，但**没有**勾到「平时作业、期中考试、大作业或项目、实验报告、小组展示」里的任何一项 | 没有平时分托底的课，一次失手的代价大得多 |
| **还没调研** | 一门课的成绩构成一个都没勾 | 「不知道它怎么给分」本身就是选课前最该消掉的不确定性 |
| **给分逻辑** | 某门课的「给分逻辑」选了低或不知道 | 问「成绩怎么构成的」比打听「给分好不好」有用，后者换老师就失效 |
| **排超了** | 你填的承受基线**大于 0**，且每周投入合计大于它 | 基线是你自己估的，不准也没关系——它至少说明这张表比上学期更满了 |
| **备选** | 候选课全是必修 | 选不上、试听不合适、和必修冲突，这三件事每学期都会发生在某个人身上 |

关于「一锤定音」为什么不算上「出勤与课堂参与」：出勤和课堂参与确实能拿分，但它挡不住期末考试失手——成绩的重心仍然压在那一次考试上。所以这条规则问的不是「有没有拿分的环节」，而是**「有没有一个能缓冲期末失手的环节」**。

另外，只要表里有课程，最后总会附一条固定的「**下一步**」——把必修锁死、去开课院系核实先修、再用[二十分钟摸清一门课](/academics/course-selection/#二十分钟摸清一门课)那套问题去问一两个上过课的人，然后回来改这里的判断。它不是规则，是这张表唯一的出口。

## 为什么要「投入曲线」这一栏

这是这个工具里唯一一个不那么直觉的字段，值得单独说。

两门课总投入完全一样，一门每周稳定 3 小时，另一门前两周轻松、期末两周集中 40 小时——**它们对你的风险完全不同**。后者会和你的其他期末任务正面撞车，而前者只是让学期均匀地忙一点。

所以判断一门课该看的不是「难不难」，而是**它的重量落在学期的哪一段**。把每门课的曲线标出来，撞车就变成了看得见的东西。

## 怎么用它才不浪费

1. **选课前一周填**，不要更早——太早你手上的信息还是传闻。
2. 先只填必修和已经很确定的课，看看提示里出现什么。
3. 对着提示去消不确定性：先修那门去开课院系确认，成绩构成去课程大纲查——[二十分钟摸清一门课](/academics/course-selection/#二十分钟摸清一门课)。
4. 回来把查到的结果填进去，提示会跟着变。
5. **打印一份或导出 JSON**。上完一学期再回看，你会知道自己当初哪一栏估得最离谱——这比任何别人的评价都准。

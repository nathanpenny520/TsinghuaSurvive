1. **未请假或请假未获批准，连续 2 周未参加教学计划规定的活动，予以退学处理。**

## 一、请假制度：怎么请、谁批、不请会怎样

学生应当参加学校教育教学计划规定的各项活动。**因故不能参加，应当事先请假并获得批准。** 未经批准而缺席的，学校视情节轻重给予批评教育或纪律处分。

| 事项 | 规定 |
| --- | --- |
| 谁提出 | 学生**本人**提出书面申请 |
| 请假少于 3 日 | 由**班主任**批准 |
| 请假 3 日以上 | 由**院系教学负责人**批准 |
| 事假上限 | 一般**不得超过 2 周** |
| 病假材料 | 因病请假应当提交校医院或二级甲等以上医院的诊断证明 |
| 销假与续假 | 请假期满应当及时向班主任或院系教学负责人销假；需要续假的，办续假手续（与请假手续相同） |

:::danger[不请假的阶梯后果]
除上述退学红线外，《实施细则》第三十条按学时给出了处分的阶梯（**2024 年手册口径**）：未经批准不参加教育教学计划规定活动，一学期内累计达 **16 学时**给予警告处分，达 **24 学时**给予严重警告处分，达 **32 学时**给予记过处分，达 **40 学时**给予留校察看处分。按周计算的实践环节每天按 6 学时计算。

未经批准**连续离校**另有阶梯（第三十一条）：连续离校 **4 天**警告、**6 天**严重警告、**8 天**记过、**10 天**留校察看；其中连续离校达两周的，同时按学籍管理规定处理。
:::

## 二、考场纪律：进考场前后各要注意什么

《学生考场纪律》管的是**考场内的行为要求**，从进场到交卷都有明确规定。

| 阶段 | 规定 |
| --- | --- |
| 进场时间 | 应**提前 5 分钟**进入考场；**考试开始 15 分钟后不准进入考场，逾时以旷考论**；试题发出 **15 分钟后**方可交卷离场 |
| 证件 | 应试学生应携带并**主动出示学生证等校内有效证件**；在教室考试的，把证件摆在桌面显著位置备查。非应试学生不得进入考场 |
| 物品 | 闭卷考试时，书包、书籍、笔记、纸张等考试用具以外的物品一律按监考教师要求集中放置，**不得留在课桌、座位、身上**；除课程考试要求且经监考教师允许外，**手机、电脑等电子通讯和存储设备一律集中放置** |
| 独立完成 | 未经允许不得互借文具、计算器等；不得交头接耳、互打暗号或手势；不得左顾右盼、旁窥他人试卷，或默许他人旁窥自己试卷 |
| 中途与交卷 | 考试中途不得擅自离开考场（提前交卷、急需上厕所须征得监考教师同意）；考试结束信号发出后立即停止答题，按指定方式交卷并保持安静，**交卷后不得私自修改答卷** |
| 试卷 | 试卷、答卷不得私自带出考场 |

突发情况也有出口：突发疾病不能坚持考试的，在征得监考教师同意后应立即赴医院急诊，**事后凭当日医疗证明到院系教学主管部门补办缓考手续**。无故不参加考试或参加考试不交卷的，以旷考论，课程成绩记零分或 F 等级。

### 什么算违纪、什么算作弊

| 层级 | 典型情形 | 对应处分 |
| --- | --- | --- |
| 影响考场秩序 | 未按指定位置就座且不听从监考指令；携带规定以外的物品入场且至发卷时仍未按要求放到指定位置；其他故意影响考场秩序的情形 | 警告以上、留校察看以下 |
| 违反考试纪律但尚未构成作弊 | 交头接耳；互打暗号或手势；旁窥他人试卷或默许他人旁窥；将试卷、答卷、草稿纸等考试用纸私自带出考场；未经监考同意中途擅自离开考场；考试开始信号前答题或结束信号后继续答题；交卷后私自修改答卷；非当场考生进入考场扰乱秩序 | 严重警告以上、留校察看以下 |
| 考试作弊 | 未经考前允许，考试开始后课桌、座位、身体等处有书籍、笔记、纸条或文字等与考试内容相关资料，或携带存储有相关资料的电子设备；考试过程中利用上厕所等机会在考场外偷看资料或带资料返回考场；擅自使用电子设备检索资料；抄袭相关资料 | **记过以上** |
| 考试作弊（更重） | 违法违规获得试卷、答卷或故意隐匿、毁弃他人试卷、答卷；使用通讯设备或其他器材传接试题答案或相关资料；抄袭他人答案或协助他人抄袭；胁迫他人为自己抄袭提供方便 | **留校察看以上** |
| 考试作弊（最重） | 参与组织实施三人以上作弊；代替他人或让他人代替自己参加考试；再次考试作弊 | **开除学籍** |

:::danger[本文刻意不写什么]
这一页只写「**什么不能做**」。**不写任何作弊手法、不写怎么规避检查、不写监考的空子在哪**——那些内容不属于经验分享，属于教人违纪。另外，在法律规定的国家考试中有违反考试纪律行为的，从重或加重处分。
:::

### 被发现之后会经历什么（考场层面）

学生涉嫌违反考场纪律，**监考教师应当及时予以纠正并如实记录**；涉嫌考试作弊的，还要留证作弊材料、工具等。涉嫌违纪的事实按规定程序被认定后，学校再依据纪律处分规定给予相应处分。另外，违反课程考核纪律的，**该课程考核成绩无效（记 0 分或者 F 等级）**——处分程序和成绩处理是两条线，会同时发生。

## 三、处分档次与它们对你的实际影响

### 五档处分

纪律处分的种类分为：**警告、严重警告、记过、留校察看、开除学籍**。

除考场与作业相关条款外，《实施细则》还对其他行为划出了大量档次（如打架斗殴、偷窃、宿舍违规、网络违规、扰乱管理秩序等）。本页不逐条复述，**与学业最直接相关的是这三块**：违反课程学习纪律（课程作业抄袭严重、实验报告抄袭严重或篡改实验数据、期中期末课程论文抄袭严重、课程学习中其他严重弄虚作假）给予警告以上、留校察看以下处分；学术不端经学校学术委员会认定给予记过以上处分，其中学位论文、公开发表的研究成果中有抄袭篡改伪造情形的给予留校察看以上，情节严重的、以及代写或买卖学位论文的**给予开除学籍**。

### 处分的影响

| 处分 | 影响（处分解除前） |
| --- | --- |
| 警告 | 取消奖学金、荣誉称号等的申请资格 |
| 严重警告 | 取消奖学金、荣誉称号等的申请资格；**不得担任学生干部、学生社团会长等**；研究生同时取消一个学期的「三助」岗位申请资格 |
| 记过 / 留校察看 | 取消**奖学金、助学金、荣誉称号**等的申请资格；不得担任学生干部、学生社团会长等；研究生在处分期内同时取消「三助」岗位申请资格 |

三条更硬的后果：

1. **因学业违纪受过处分的学生不具有推荐免试攻读研究生资格。**
2. **留校察看处分不予撤销**；因学术不端或违反学习纪律给予的记过处分**原则上不予撤销**；不予撤销的记过处分、留校察看处分相关材料**归入有关档案**。
3. 受处分学生的处分期计算有两条不计入的规则：学校决定暂缓执行原处分决定的期间不计入处分期；受处分期间因故休学的，休学期间不计入处分期。

### 处分怎么解除

- **记过以下处分**：在处分期满或者受处分学生毕业时予以解除。
- **留校察看**：察看期满前一个月内或察看期满后，由本人申请、院系党政联席会议讨论提出建议、学校主管机构提出处理意见并报校务会议批准，且察看期满无新的违规行为的，按期满当日解除。
- **提前解除**：处分期内有突出表现的，可以申请提前解除（记过以下报校领导办公会批准，留校察看报校务会议批准）。
- **撤销处分**：受记过以下处分且处分期原则上已满、真诚悔改并有良好表现的，可以在毕业前或申请退学离校前三个月内书面申请撤销；但主观恶意较大或影响恶劣的原则上不予撤销，因学术不端或违反学习纪律被给予的记过处分原则上不予撤销。
- **毕业年级**：毕业离校前被发现有违法违纪行为的，有关部门应当中止其离校程序，处分决定作出后恢复；其中记过以下处分于离校手续完成时自动解除。

## 四、处分要走哪些程序：你有的权利

处分不是「一句话定下来的」，它有明确的步骤和你要知道的节点：

| 环节 | 时限与要点 |
| --- | --- |
| 立案 | 院系初步核实，**五个工作日内**决定是否立项并报学校主管机构备案 |
| 调查取证 | 一般由院系负责；第一次谈话时应当告知学生享有**委托代理人**、在法律允许范围内**自行收集证据**等权利；谈话笔录要经你现场核对，可更正补充，逐页签名 |
| 拟处分告知书 | 作出之日起**十个工作日内**送达学生本人（有监护人的同时送达监护人），载明事实证据、拟处分种类依据期限、陈述申辩途径与期限 |
| 陈述申辩 | 对告知书有异议的，送达之日起**五个工作日内**可提出书面或**口头**陈述、申辩请求；请求口头的，学校主管机构在请求提出之日起**五个工作日内**安排并作笔录 |
| 听证 | **拟被给予开除学籍处分的学生**有权申请听证，应在收到拟处分告知书后**十日内**书面提出；逾期未提出或无正当理由未出席视为放弃，且不得再次申请 |
| 决定 | 警告、严重警告、记过经**校领导办公会**讨论后作出；留校察看、开除学籍经校领导办公会讨论后报**校务会议**研究决定；拟开除学籍的还须经学校法律事务机构合法性审查 |
| 送达与公布 | 处分决定书在作出之日起**十日内**送达本人（及监护人）；处分决定的相关内容可以在学校指定公告栏或网页公布，但**不得涉及被处分学生的个人信息** |

## 五、不服处分怎么申诉

**受理机构**：学校**学生申诉处理委员会**（下设办公室负责日常事务）。可申诉的事项包括：取消入学资格、取消学籍、退学、不颁发学历证书、不颁发学位证书的处理，以及警告、严重警告、记过、留校察看、开除学籍处分。

| 环节 | 规定 |
| --- | --- |
| 时限 | 处理或处分决定的生效文书**送达之日起十日内**提出书面申诉；因正当理由未能在期限内提出的，可于正当理由结束之日起**十日内**提出 |
| 交材料 | 在学校工作时间内向委员会办公室提交；因教学安排等正当理由不能当面提交的可以邮寄（提出日期以交寄日期为准） |
| 材料内容 | 申诉申请书（申诉事项、请求和理由，本人联系方式、校内留置送达地址、校外挂号邮寄送达地址及一名有效代收人，本人签名）+ 相关证据材料 + 处理或处分决定书复印件；由监护人作法定代理人或委托代理人参加的，还要提供监护关系证明或授权委托书 |
| 能否补改 | 提交之日起**两个工作日内**可以调整材料，本人逐页签字后送交 |
| 受理审核 | 办公室审核后，**三个工作日内**书面告知是否受理；不予受理的书面说明理由 |
| 复查结论 | 接到书面申诉之日起**十五日内**作出；情况复杂经主任批准可延长**十五日** |
| 结论类型 | 同意原决定；或认为事实认定不清、发现新的重要证据、依据错误、程序有错误且可能有实质性影响，**建议原处理或处分机构重新研究决定** |
| 重新研究 | 原机构在**三十个工作日内**重新研究并作出复查决定 |
| 执行 | **申诉期间原处理或处分决定原则上不停止执行**；委员会认为必要的，可以建议学校暂缓执行 |
| 次数 | 对同一处理或处分决定，向委员会提出的申诉**仅限一次**；作出复查结论前可以书面撤回 |
| 校外途径 | 还可以按有关规定**向北京市教育委员会**提出书面申诉 |

几种**不予受理**的情形要知道：超过规定申诉期限的；申诉主体或事项不符合规定的；对同一决定的申诉次数不符合规定的；申诉事项系因学生本人或其监护人**主动申请**而形成学校处理决定的；学生已就申诉事项向法院提起行政诉讼且已被受理的。

委员会的构成与表决：由学校相关负责人、职务委员（相关职能部门负责人、学校法律事务机构负责人）和代表委员（教师代表、学生代表）组成；会议原则上不公开，按构成抽取出席委员，出席人数七人以上且三类委员分别两人以上方可开会；采取**无记名投票**表决，不得弃权，决定事项须到会委员（主任除外）半数以上同意，票数相同时由主任投票形成最终决定。委员与处理过程有利害关系的应当回避。

:::caution[申诉不是「再说一遍」]
申诉要提交**证据材料**和具体的**申诉事项、请求和理由**。如果你只是重复「我没错」，那和提交一份能指出事实认定、依据或程序问题的材料，效果完全不同。所以从**第一次被谈话开始**就要留存：谈话笔录你核对过没有、有没有签、你手上有哪些材料。这些是你后面唯一的抓手。
:::

## 六、服务消过：一次改错的机会

服务消过是给**初次违纪、情节较轻**的学生的一条改正路径。

| 条件 | 规定 |
| --- | --- |
| 适用对象 | 具有清华大学学籍的在校学生，**初次**违反校规校纪，应给予**警告或严重警告**处分，且经过教育**主动承认错误** |
| 不能申请 | **危害公共安全、违反考场纪律、学术不端行为**，以及主观恶性较大的违纪行为 |
| 申请时限 | 接到**拟处分决定书**之日起**十个工作日内**；经申诉后处分结论发生变化的，在接到复查决定书之日起十个工作日内；因不可抗力逾期的，于事由终了后十个工作日内提出 |
| 效力 | 经批准后，违纪处分决定**暂不作出或暂缓生效**，并由学校主管部门公开通报（含违纪事实与应给予的处分决定） |
| 服务量 | 应给予警告处分的参加社区服务**二十小时**；应给予严重警告处分的参加**四十小时**。服务分日实施，每日一般不超过四小时，原则上须于通报后**两个月内**执行完毕 |
| 结束评议 | 完成服务后学习有关规章制度、完成书面总结并由监督部门或院系签署鉴定意见；学校主管部门组织评议会与学生答辩。认定表现良好且已深刻认识错误的，**不对其给予处分或处分决定自始不生效**；否则作出处分决定或自始恢复处分决定效力 |

注意上面「不能申请」那一行：**违反考场纪律不能服务消过**。也就是说考试相关的违纪没有这条出口，别把它当成退路。

## 七、顺手记住：证件别转借

《学生证、学生校徽管理办法》里和纪律直接相关的两条：学生证和校徽**只限本人使用、佩戴**，不准转借、送人，学生证不准擅自涂改；将学生证或校徽转借他人使用或送人，或一人使用两个学生证、校徽，一经查出，根据情节予以**批评教育、纪律处分**。学生证遗失要先到院（系）教学主管部门挂失并写书面检查，经班主任同意、院系审查批准后才能补领；在校期间一般**限补领一次**，补领后停止享受乘车半价优待一学期。毕业或因转学、退学、开除学籍离校前，应将学生证交院系教学主管部门注销。

补办与注册的具体地点、材料见[注册、学籍异动与退学红线](/academics/registration-and-status/)；发现冒用他人学生证、校徽的情况，应立即报告学校保卫部门。

## 下一个动作

- 把请假流程做对：**先书面申请、拿到批准、按时销假**——大多数「意外违纪」都出在「我以为跟辅导员说一声就行」；
- 考试前只做一件事：**把不该带的东西全部放到监考指定位置**，包括手机和智能手表；
- 真遇到处分程序，**从拟处分告知书送达那天开始数日子**：五个工作日内提陈述申辩、十日内提申诉（开除学籍还要在十日内申请听证），错过就没有第二次。

绩点是一个被过度焦虑化的东西。搞清楚它**是怎么算的、影响什么、不影响什么**，能省下大量内耗。

## 先分清两个概念

这两个词经常被混着用，但它们不是一回事：

| 概念 | 怎么算 | 用在哪 |
| --- | --- | --- |
| **加权平均分** | 每门课成绩 × 该课学分，加总后除以总学分 | 部分奖学金评定、出国申请材料 |
| **平均绩点（GPA）** | 每门课**先换算成绩点**，再按学分加权平均 | 保研资格、评奖、部分项目选拔 |

关键区别：**加权平均分放大高分的影响，GPA 会把成绩压缩到几个档位**。所以「要不要为了从 89 提到 91 多花一倍时间」，取决于你们院系看的是哪个指标。

:::caution
成绩怎么换算成绩点、哪些课程计入（必修/限选/任选/体育/通识是否都算）、重修怎么处理——**这些规则每年、每个院系都可能不同**。请不要用学长口口相传的数字做决定，去教务系统看你们那一版的说明。
:::

## 它真正影响什么

按影响程度排序：

1. **保研资格**。通常是硬门槛 + 排名。这是绩点影响最大、也最不可逆的一件事。
2. **出国申请**。国外学校看的是成绩单本身和排名，GPA 只是其中一项。
3. **评奖评优**。奖学金评定几乎一定会看成绩。
4. **转专业、辅修、部分项目的选拔**。通常有成绩门槛。
5. **求职**。**影响很小**。除了少数明确要求成绩的岗位，实习经历和项目经验更重要。

:::tip
看懂这张表的意义在于：**如果你的目标是就业，为绩点从 3.5 卷到 3.8 的性价比，远低于把同样的时间花在一段像样的实习上**。但如果你要保研，绩点就是第一优先级。先想清楚目标，再决定投入。
:::

## 提升绩点的正确姿势

不是"更努力"，而是**把努力用在能被计量的地方**：

1. **先确认计入规则**。哪些课算、哪些不算，明确之后你就知道该在哪使劲。
2. **重视平时分**。多数课的最终成绩里，作业、小测、出勤、项目占相当比例。平时分是最稳的分，几乎不靠运气。
3. **搞清楚每门课的给分结构**。期末占比 70% 的课，平时混过去风险极高；平时分占 60% 的课，作业一次不落就是保底。
4. **不要挂科**。挂科的代价远大于你为了不挂多付出的努力——补考、重修、时间占用、心理压力，还有可能在成绩单上留痕。
5. **合理选课**。同样学分，不同课程的投入产出比差别巨大。这是**唯一"合法且高效"的提分手段**。
6. **早查分、早申诉**。成绩公布后如果发现漏登、算错，越早找任课老师/教务越好处理。

## 别为这些事内耗

- **和别人的绩点比**。院系、专业、选课难度都不同，横向比较没有意义。
- **为 0.01 的差距焦虑**。排名往往看区间而不是小数点后两位。
- **把绩点当成自我价值的度量**。它只反映你在**特定评价体系**下的表现，不反映你的能力上限，更不反映你这个人怎么样。
- **为了保 GPA 不敢选有挑战的课**。如果你不打算保研，这个策略的收益很低。

## 关于重修和刷分

知道有人会为了刷绩点重修低分课程。**这件事的可行性和后果完全取决于你们院系的规则**（是否取最高分、是否在成绩单上显示、是否有次数限制）。

在动手之前，先确认三件事：**政策允许吗、成绩单长什么样、时间成本值不值**。别听"有人这么干成功了"就跟着上——每个人的处境不一样。

## 官方口径：哪些课算进 GPA，成绩单上留下什么

前面讲的是策略，这一节换成**制度原文的口径**。

来源：《清华大学学生手册（2024）》之《清华大学课程成绩管理办法》《清华大学本科生学籍管理规定》。**规则会随年份调整**，办事前请以注册中心和教务处的当年通知为准。

### 先看公式

学校采用**平均学分绩点**（GPA）作为评价学生学业水平的基本依据，计算方法是：

> GPA =（Σ 课程学分 × 课程绩点）÷（Σ 课程学分）

也就是说，**先算出每门课的绩点，再按学分加权平均**。所以同一门课，学分越高，它对 GPA 的拉动或拖累越大。

### 哪些课算、哪些不算

| 成绩记法 | 取得学分？ | 参与 GPA 计算？ |
| --- | --- | --- |
| **A+、A、A-、B+、B、B-、C+、C、C-、D+、D** | 取得 | **参与** |
| **P**（通过） | 取得 | **不参与** |
| **EX**（免修） | 取得 | **不参与** |
| **F**（不及格） | 不取得 | 见下 |
| **以 P、F 形式记载的课程** | 按 P/F 结果 | **不参与** |
| **W**（退课） | 不取得 | **不参与** |
| **I**（未完成） | 待考核 | **不参与** |

两条容易记错的：

- **以 P、F 形式记载的课程以及成绩记为 W、I 或 EX 的课程不参与 GPA 计算**——原文就是这么写的。所以"用 P/F 躲开一门低分课"在 GPA 上确实有效，但它同时也**不参与平均学分绩的计算**，全院系排名、评奖怎么看待它，原文没写，得问教务。
- **F 的绩点是 0**，不是"不计入"。等级—绩点映射表里 F 对应 0，也就是说挂科会**以 0 分拉的权重**进分母。

:::caution[待核对：A+ 与 A 的绩点]
原文的等级—绩点映射表把 A+、A、A- 三档合并标注为 **4.0**，映射表里**没有单列 A+ 的绩点**。网上流传的"满绩 4.0 还是 4.3"属于院系或系统层面的口径差异，**原文无法支撑，请不要按某个数字推算**——查你入学那年成绩单背面的说明。
:::

### 成绩单上会出现什么

| 记法 | 原文口径 | 会不会消失 |
| --- | --- | --- |
| **W**（Withdrew） | 学期初"补退选期间"的退课**不记载**；其后安排的"退课期间"办理的退课**在成绩单上予以记载** | 补退选期间退的不留痕，之后退的留 W |
| **F** | 考核不合格记 F；违反考核纪律的课程考核成绩无效（记 0 分或者 F 等级）；选课后在规定期间内**未办理退课手续**又不参加课程学习或考核的，该课程成绩**记 F** | 不会消失，只能靠重修再记一条 |
| **I**（Incomplete） | 因病等特殊情况不能参加考核，申请批准后备案记载 | 在学校规定期间内完成考核后**登载考核成绩、取消原 I 记录** |
| **EX**（Exempted） | 通过免修考核后按免修记载 | 不参与平均学分绩点或者平均学分绩计算 |
| **重修成绩** | **按学期记载**，在规定的学习年限内重修次数不限 | 原文没有写"覆盖原成绩"或"取最高分"这样的规则，只写了按学期分别记载 |

:::caution[待核对：重修到底会不会覆盖原成绩]
原文只写了重修成绩**按学期记载**。**"两次成绩都在成绩单上、还是只显示最高一次"由院系与注册中心的具体执行口径决定**，本文不替它下结论。决定重修之前，先向本院系教务确认你那一届的记载方式。
:::

### 关于 P/NP

- 原文用的是 **P、F**（Pass / Fail），没有出现"NP"这个记法；
- 考查课程成绩**一般以 P、F 形式记载**；
- 本科生**每学期可以选择一门任选课**，其成绩记为 P 或 F，**无绩点**；
- P 取得学分，但**不参与 GPA 计算**；F 同样不参与 GPA 计算，但按上面的表，课程本身没有通过。

### 对成绩有异议：去复议，别找老师

- **入口**：向**开课院系教学业务办公室**提交《成绩复议申请表》；
- **时限**：成绩复议期一般为**下学期开学第一周**，逾期不予受理；确需更改的，由任课教师提交成绩更改申请，经院系教学主管审核后在**开学第二周（含）前**报注册中心；
- **不要直接找任课教师要求改分**：学校明确禁止学生以种种理由、各种方式直接要求任课教师更改成绩，对严重干扰教师正常工作的会依规处理。

流程细节和表格下载路径见[考试、退课与重修](/academics/exams-and-retake/)那一节的复议行。

:::caution[待核对：具体课程是否计入]
原文写的是**记法层面**的规则（哪些记法参与 GPA 计算）。至于**哪些课程类别计入**（必修、限选、任选、体育、通识是否都算），以及有没有院系层面的附加规定，**不在这一节的原文范围内**，请以你所在院系的教务口径为准。
:::

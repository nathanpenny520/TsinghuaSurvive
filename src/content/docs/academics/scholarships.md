关于奖学金，最该先知道的一件事是：**它不从大一开始评**。多数院系的评定对象是**大二及以上**年级本科生，时间点一般在**秋季学期开学后（9 月）**，评的是**上一学年**的表现。

所以大一的你和奖学金的关系不是"等评选"，而是：**这一年你做什么，直接决定明年 9 月你有没有东西可讲。**

本文讲三件事：评的是什么、怎么走流程、这一年该攒什么。制度性内容用两个院系的真实细则做实例，**任何数字都请回到你院系当年的细则去核对**。

:::caution[本文的定位]
本站不是官方渠道。下面出现的比例、金额、时间、可兼得关系都来自**已公示的院系细则原文**，用来让你理解"这类规则长什么样"。
它们**每年变、每院系不同**，请以你所在院系当学年发布的细则为准。
:::

## 先看懂这套评定的三个设计

理解了这三条，后面的细节就都能推出来：

1. **先评荣誉，再配奖金。** 荣誉和奖金是分开的两件事：先按类别评出"荣誉"，再根据荣誉去匹配相应的奖学金。所以规则里会写"所匹配奖学金不低于某个数"，而不是"这个奖发多少钱"。工物系的细则把这条写成原则：**荣誉与奖金相分离**。
2. **分两大类：综合优秀奖，和一堆单项优秀奖。** 综合类看的是"全面发展"，单项类看的是"某一方面确实有东西"。两类之间通常**互斥**——拿到综合类原则上就不能再拿单项类（未央、工物两个院系的细则都这么写），所以申报时要选路线。
3. **学业是入场券，不是加分项。** 入围通常先看学业成绩（绩点排名），而且很多院系明确写着：**上一学年有课程（含实践环节）不通过，不得申请综合优秀奖和学业类荣誉**。也就是说，学业掉下去不是"少一块分"，而是**直接失去资格**。

## 荣誉地图

把两个院系的细则放在一起看，荣誉清单基本是同一套：

| 层级 | 荣誉 | 看什么 |
| --- | --- | --- |
| **综合类** | 综合优秀奖 | 学业成绩 + 多方面表现加权排名；通常要**答辩** |
| **单项类** | 学业优秀奖 | 成绩优秀，或（高年级）成绩进步明显 |
| | 科技创新优秀奖 | 竞赛、SRT、科研项目、论文、专利 |
| | 社会工作优秀奖 | 校/院系学生组织或班团骨干岗位上的实际成效 |
| | 社会实践优秀奖 | 实践支队、实践成果与社会影响 |
| | 志愿公益优秀奖 | 志愿服务与公益事业的实际贡献 |
| | 体育优秀奖 | 竞技成绩，或推动群体体育氛围 |
| | 文艺优秀奖 | 文艺比赛、作品产出，或文艺氛围建设 |
| | 全球胜任力优秀奖 | 海外学习实践、跨文化交流、国际组织实习等（部分院系**可空缺**） |
| | 好读书奖 | 阅读积累、书评/作品产出、带动他人读书（部分院系**可空缺**） |
| **校级之上** | 国家奖学金、国家励志奖学金，以及若干校级冠名奖学金 | 一般从综合优秀奖的获得者里进一步评定 |

:::tip[两个值得注意的细节]
- **单项奖不只奖励"赢的人"**。科技创新、社会工作、实践、志愿这几类的评选条件里，都明确包含"**组织工作**"和"**带动氛围**"——办过活动、组织过支队、把一件事从零推起来，和拿奖牌一样算数。
- **每类单项奖的具体条件，细则里写得很细。** 想知道自己这一年做的事算不算，最靠谱的办法是**把当年细则里那一类逐条对着自己的经历看**，而不是问别人"我这个能不能评上"。
:::

## 名额：不是"够格就有"

荣誉有名额上限，这是很多人第一次听到会意外的地方。以未央书院 2025-2026 学年度的细则为例（**仅作示例，务必看你自己的院系**）：

- 校级荣誉获得人数**不超过各年级参评人数的 50%**；
- 其中"**综合优秀奖**"不超过**各年级参评人数的 20%**。

这意味着两件事：**一是"达到条件"和"评上"之间还有一道排序**；二是**综合优秀奖的竞争强度明显高于单项奖**。选路线的时候，"我更适合冲综合，还是稳一个单项"，是个真问题。

## 流程：从申请到公示

两个院系的流程结构几乎一致，顺序如下：

1. **本人自愿申请**（在规定窗口内，一般通过问卷或系统提交材料）。未央书院 2025-2026 学年度给的申请窗口是**9 月 17 日至 24 日**——注意这类窗口通常只有**一周左右**，错过就是等一年。
2. **资格审查 + 公示**：工作组对满足基本参评条件的名单和申请材料进行**为期 3 个工作日的公示**（未央细则原文）。工物系的细则也要求申报材料真实有效、并愿接受公示。
3. **综合类走函评 + 答辩**：先对材料做函评，据此确定**入围答辩的名单**，再组织答辩。单项奖里科创、社工、文体、志愿、实践这几类一般也要答辩；读书类通常只函评。
4. **评审委员会审核 → 全系/全院公示 → 报学校复核**。
5. **匹配奖金**（荣誉先定，奖金后配）。

:::caution[别把公示当形式]
公示期是**别人能对你的材料提出异议**的窗口。材料写不实、业绩没有证明，风险都在这一步暴露。细则里通常明确要求申报人保证材料真实，并接受公示。
:::

## 材料：这一节最值得认真看

因为"你这一年做了什么"最终要变成**能被验证的材料**。工物系细则把证明方式写得很清楚，可以当通用参考：

| 证明方式 | 具体是什么 |
| --- | --- |
| **物证** | 比赛/奖励证书复印件、论文首页打印件或收录函、专利授权证明、学术专著封面及作者页等 |
| **书证** | 由分管这项工作的**证明人**签署情况属实。例如实验室科研活动的证明人是指导教师，团委任职经历由团委相关负责人证明，社团任职由社团部相关人员证明 |
| **成绩类** | 第二成绩单 + 上一学年已完工业绩的证明材料（申请单项荣誉通常必须提交） |

两个实操结论：

- **从大一开始就把"证明"留好。** 证书、论文首页、活动推送链接、盖章证明，随手存一个文件夹。到了 9 月再回头找一年前的东西，是非常常见的翻车方式。
- **岗位上做的事要说得出细节。** 个人自述里写"担任某职务"没有用，写"负责了什么、产出了什么、结果如何"才有用。这一条和[社工体系](/campus/student-organizations/)那一整页讲的是同一件事。

## 兼得规则：一年最多拿几项

这类规则最容易踩坑，因为它决定了你申请时该怎么排序：

- **申请时可以同时报多项**（未央细则：可同时申请至多**三项**荣誉，并需给出**志愿排序**）；
- **但最终拿到手的通常有上限**：未央是"最多 1 项综合优秀奖 + 1 项单项优秀奖，或最多 2 项不同类型的单项优秀奖"；工物系是"每名学生每年最多可获得**两项**不同的奖学金荣誉"；
- **同类通常不可兼得**：在两个体系里获评的同类单项奖不可兼得；在院系外获评的校级奖学金，一般视为占用一项单项名额；
- **有若干"不可兼得"的成组关系**（未央细则点名的：特等奖学金、一二·九奖学金、蒋南翔奖学金、王大中奖学金、邓稼先奖学金之间；国家奖学金与国家励志奖学金之间；全球胜任力优秀奖与社会实践/志愿公益优秀奖之间）；
- **金额也有上限**：工物系细则是"每学年获得奖学金总额原则上不超过特等奖学金奖励金额"。

:::tip[所以申请策略是什么]
**先想清楚你要哪一项**，再把志愿排序排好。常见的失误是"三项都报、排序乱填"，最后被分到一个自己并不匹配的类别，还占掉了名额。
:::

## 两个院系的实例对照

把两个已公示的细则并排放，差异一眼能看出来——**这也是为什么本文坚持用"实例"而不是给一套通用数字**：

| | 未央书院（2025-2026 学年度） | 工程物理系（2026 年） |
| --- | --- | --- |
| 评定对象 | 书院**大二及以上**本科生 | 全校**全日制本科生**，向所在院系申请 |
| 名单公示 | 资格名单与材料公示 **3 个工作日** | 初评人选上报→系内**公示**→校学生处复核 |
| 综合类 | 材料函评 → 入围名单 → **答辩** | 年级评审小组 → **答辩** → 评审委员会 |
| 单项类组织方式 | 按类别评审 | 读书类**函评**；科创/社工/文体/志愿/实践**答辩**，且不分年级 |
| 特色机制 | 校级荣誉 ≤ 参评人数 **50%**，综合优秀奖 ≤ **20%**；综合与单项原则上互斥 | 每类可推**首席获奖候选人**，全系评出少量首席获奖者，匹配**系设何东昌奖学金** |
| 成绩口径 | "上一学年"= 上一学年夏季 + 本学年秋季 + 本学年春季；**大二学生评奖不计入大一秋季成绩**（依书院决议） | 学业类参考**上一学年智育成绩**，并综合学习态度与进步幅度 |
| 兼得上限 | 最多 1 综合 + 1 单项，或 2 项不同类单项 | 最多 **2 项**不同荣誉 |

注意那两个"成绩口径"的差别：**同一个词"上一学年"，在两个院系指的学期范围不一样。** 这类细节只可能从细则原文里读到，问同学大概率得到的是"我那年好像是这样"。

## 反推：大一这一年该做什么

评选在大二，但材料在大一就攒下了。按重要性排：

1. **先把学业守住。** 它是入围门槛，而且"有课程不通过"会直接砍掉综合优秀奖和学业类荣誉的资格。方法见[绩点到底是怎么算的](/academics/gpa/)和[考试、退课与重修](/academics/exams-and-retake/)。
2. **选一条"有产出"的线深耕。** 科创（SRT、竞赛、论文）、社工（一个能干出结果的岗位）、实践（一次当支队长的经历）、志愿（累计服务时长）——**任一条做到有物证或书证，就有一个单项奖的着力点**。四条线都浅尝，往往一条都写不出材料。
3. **留证据。** 上面「材料」那一节说的事，从第一学期就开始做。
4. **别只盯着钱。** 奖学金在保研、申请、求职里是履历的一部分，而它的评定标准本身就是一份"大学里什么被看重"的清单。就算不为了评奖，照着它规划一年也不算亏。

## 信息从哪来

| 你要查的 | 去哪 |
| --- | --- |
| 今年评什么、什么时间、什么名额 | **你所在院系官网的学生工作/通知栏**，以及当年发布的**评定细则原文**——这是唯一有决定性的来源 |
| 某项经历算不算业绩、找谁开证明 | 院系奖学金工作组 / 对应类别的评审小组；细则里通常写了证明人是谁 |
| 荣誉与奖学金的层级关系 | 学校学生部（处）发布的校级规定与通知 |
| 答辩长什么样 | 部分校级荣誉的答辩有公开视频，可以看看别人怎么讲自己的事（**看结构，别照抄内容**） |

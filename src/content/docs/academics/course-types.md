选课真正难的地方，是**同一套判断标准套不到所有课上**。思政课的逻辑、数理课的逻辑、通识课的逻辑不是一回事。

这篇按**课程类别**拆开讲：每一类先讲它的考核逻辑，再给三个选课时真正该看的指标，最后是这类课最常见的坑。**只讲类型，不讲哪门课好。**

## 这篇文章不做什么

- **不评价任何老师**。本站不写对具体老师的指名评价，本文也不会出现任何老师姓名。
- **不给具体数字**。学分要求、成绩占比、考核次数、达标线，每一届、每个院系、每位开课老师都可能不同。
- **不替你做决定**。本文给的是判断框架；"这门课上不上"最终取决于你自己的目标。

:::caution
文中涉及规则的部分——考核构成、学分认定、选课限制——**一律以当年开课信息和院系通知为准**。本文用"常见""多数"这类措辞，它们描述的是通常情况，不是承诺。
:::

## 判断任何一门课，先看这三件事

不管哪一类课，这三条信息决定大部分判断：

| 要看什么 | 具体问什么 | 去哪看 |
| --- | --- | --- |
| **考核形式** | 期末闭卷？大作业？论文？小组展示？ | 课程大纲、第一节课的说明 |
| **投入曲线** | 每周稳定几小时，还是期末集中爆发？ | 上过这门课的人 |
| **成绩构成** | 平时分占多少，有没有一锤定音的环节 | 课程大纲、任课教师说明 |

**"投入曲线"比"总投入"更重要**。两门课总耗时一样，一门每周 3 小时，另一门期末两周集中 40 小时——后者会和你的其他期末任务正面撞车。

:::tip
课程大纲通常在网络学堂或院系选课信息里能找到。重点看"考核方式"和"成绩评定"两栏，这比看课名有用得多。
:::

## 思政类

**常见考核构成**：出勤与课堂参与 + 平时作业或小测 + 小组展示/实践报告 + 期末论文或考试。多数思政课把相当一部分分数放在平时，期末一考定音的情况相对少。

**该看的 3 个指标**：

1. **形式要求有多少**：有没有小组展示、实践调研、读书报告这类必须投入固定工时的环节。
2. **期末是论文还是考试**：论文类要提前选题、找材料；考试类要背的内容量差别很大。
3. **任务的时间分布**：是每周都有小任务，还是全部压在后半学期。

**最常见的坑**：把它当成"水课"整学期不参与，最后发现平时分已经扣得差不多；或者反过来，小组选题铺得太大，一个人扛下整组的调研。

**怎么自主核实**：培养方案里能查到思政类的学分与类别要求；具体开课形式看课程大纲和第一节课的说明；往届的实际节奏，问直系学长学姐。

## 英语类（含四六级与学术英语）

**常见考核构成**：分级后的听说读写综合课，成绩通常由课堂参与、口语展示、写作作业，加期末笔试或口试组成。学术英语类课程更偏论文阅读与写作。

**该看的 3 个指标**：

1. **和你的语言考试节奏是否冲突**：四六级、托福雅思的备考期和期末撞在一起会很痛苦。
2. **有没有强制口语展示或小组汇报**：这是固定的时间成本，不是"临场发挥"能解决的。
3. **培养方案要求你在第几学期前修完**：拖得越晚越难排进课表。

**最常见的坑**：拖到大三大四才修，正好和保研、申请、毕业设计撞车；以为英语课就是背单词，实际是持续性的写作与展示任务。

**怎么自主核实**：学分与分级要求看培养方案和当年的分级安排通知；课程的具体考核形式问上过的人；四六级报名与考试安排以官方通知为准。

## 体育类

**常见考核构成**：出勤 + 课堂表现与技能测试 + 体能测试（如长跑类项目）+ 部分项目有课外锻炼要求。

**该看的 3 个指标**：

1. **场地与时段**：体育课按场馆排课，和专业课的通行时间是否冲突，要提前算。
2. **项目强度与你的身体状态**：有旧伤或身体条件受限，选课前就要确认清楚要求。
3. **考核是否有硬性达标线**：有的项目按名次或达标成绩给分，和"参与就给分"是两种课。

**最常见的坑**：把体育课当送分课缺席；身体有特殊情况却不提前沟通，到考核时才发现没有补救空间；选的时段在两个相距很远的场地之间来回跑。

**怎么自主核实**：开课项目与选课规则以当年选课系统和体育课开课通知为准；身体条件有特殊情况时，**尽早**按流程向任课教师和院系说明（免修、缓测等具体流程以官方通知为准）。

## 通识核心课与新生研讨课

**常见考核构成**：通识核心课多数是"阅读 + 讨论课参与 + 平时小论文 + 期末论文或展示"的组合；新生研讨课通常以参与、小作业和结课报告为主，考核压力相对小，但对出席要求更严。

**该看的 3 个指标**：

1. **每周阅读量**：直接问"一周大概读多少页/几篇"，不要只看课名。
2. **是否要求连续出席讨论**：讨论课缺一次就很难补，也容易被看出来。
3. **它在培养方案里算哪一类学分**：不同院系的通识分类和学分要求不一样。

**最常见的坑**：只看课名有趣就选；把通识课当成"轻松的选修"，结果阅读量比专业课还大；学分归类没搞清，毕业审核时才发现这门课不算数。

**怎么自主核实**：培养方案里的通识课程分类与学分要求（**这一条只有培养方案说了算**）；课程大纲里的阅读量；上过的人的真实感受。

## 写作与沟通

**常见考核构成**：过程性考核为主——选题、提纲、初稿、互评、修改、终稿，加上课堂参与。多数课的成绩分布在多个环节，而不是终稿一锤定音。

**该看的 3 个指标**：

1. **主题方向是否和你的兴趣或专业相关**：要写一整个学期，别选一个自己完全无感的题。
2. **每篇文稿的篇幅与修改轮次**：改三轮和改一轮，投入差别很大。
3. **是否需要互评、课堂发言**：这是很多人低估的固定成本。

**最常见的坑**：把它当成"期末赶一篇论文"，但它是过程性的，中间环节不交就直接损失一块分；选题过大过长，材料找不齐；不重视修改——**分数差距往往来自修改环节，而不是初稿**。

**怎么自主核实**：开课主题与选课信息以当年选课系统和开课通知为准；引用格式与写作规范以任课教师说明为准，通用规则见[作业、引用与 AI：学术规范的边界](/academics/academic-integrity/)。

## 数理基础课

**常见考核构成**：每周作业 + 期中/期末闭卷考试，部分课程另设习题课与小测。作业基本是周更，负担来自持续性而不是单次难度。

**该看的 3 个指标**：

1. **先修链**：这门课是不是后续专业课的前置？退了或挂了会连锁影响什么？
2. **每周作业量**：比"考试难不难"更值得问。
3. **课程层次与命题方式**：同名课程可能有不同层次，难度和考试方式都不同。

**最常见的坑**：低年级同一学期堆好几门高强度数理课；用高中成绩预估大学数理课的投入；不去习题课和答疑，问题攒到期末。

**怎么自主核实**：培养方案里的先修关系与建议学期；课程层次与开课安排以当年开课信息为准；补基础可以看[校内常用链接](/guides/links/)和公开课资料库。

## 专业必修与限选

**常见考核构成**：差异极大。可能是"考试 + 大作业 + 项目答辩"，也可能是纯论文或纯项目；多数专业课会包含一次综合性的项目或设计。

**该看的 3 个指标**：

1. **它在培养方案里的类别**：必修、限选、任选，类别修错等于白修。
2. **它和后续课程的依赖关系**：是不是某门高年级课的默认基础。
3. **项目工作量与团队规模**：是个人项目还是小组项目，直接影响你这学期的排期。

**最常见的坑**：选了一门自己先修没修的课，前六周都在补前置知识；限选学分修到毕业前才发现差了或超了；小组项目分工不留痕，最后一个人扛。

**怎么自主核实**：培养方案是唯一权威；课程大纲看考核方式；直系学长学姐问时间投入；**选课限制、替代规则**这类问题，问院系教务最准。

## 不要靠往年评价做唯一决策

往年评价有用，但只能当**线索**，不能当**结论**。三个理由：

1. **样本有偏差**。愿意写评价的人，往往是体验特别好或特别差的那部分，中间的大多数人不说话。你看到的是分布的两端，不是均值。
2. **课程会变**。同一门课名，换一位开课老师、换一版大纲、换一种考核方式，往年的评价就整体失效。去年"轻松"的课今年可能改成闭卷。
3. **你的目标函数和别人不同**。有人要绩点，有人要学到东西，有人只想不被占时间——同一门课对这三种人的"好坏"结论是相反的。

:::tip
看到一条评价，先问三个问题：**这是哪一年的？开课老师是不是同一批？写评价的人目标和我的像吗？** 三个都能答上来，这条信息才有参考价值。
:::

## 选课信息从哪里来

三类渠道各有用途，别只用一个：

| 渠道 | 能得到什么 | 注意事项 |
| --- | --- | --- |
| **官方**：培养方案、选课系统、开课通知 | 学分要求、课程类别、先修关系、考核方式 | 唯一有决定性的信息源，以当年发布为准 |
| **人的渠道**：院系教务、学长学姐、助教 | 真实的时间投入、往年安排、限制条款的解释 | 一个人的经历不等于普遍情况，至少问两三个人 |
| **公开资料库**：学生自发维护的文档 | 课程笔记、复习资料、技能指引 | 基于往年经验，可能过期，只能当参考 |

几个公开资料库（均为学生自发维护，与学校官方无关）：

- [清华大学计算机系学生科协技能引导文档](https://docs.net9.org/)：计算机类技能与课程指引。
- [软件学院 ReadMe 互助文档](https://ssast-readme.github.io/)：课程笔记与作业攻略。
- [未央书院学习资料](https://weiyangxuexi.github.io/)：含一份按课程类别整理的选课指南。
- [CS 自学指南](https://csdiy.wiki/)：不依赖校内课程的计算机自学路线。

:::note
这些站点由学生维护、内容基于往年经验，**不代表学校口径，也可能过期**。用它们了解"有哪些选项"，用官方渠道确认"今年是什么规则"。
:::

## 三个跨类别的通用原则

1. **先锁必修，再填选修**。必修没有替代方案，冲突了就是毕业风险；选修永远有下一门。详见[培养方案与选课](/academics/course-selection/)。
2. **把"要交东西"的时间点画进日历**。选课时真正该评估的不是难度，而是**哪几周会被同时压满**。
3. **永远留一门备选**。选不上、试听不合适、和专业课冲突——这三件事每学期都会发生在某个人身上。

选课之后的事——退课窗口、考核形式对应的复习策略、重修代价——见[考试、退课与重修](/academics/exams-and-retake/)；绩点的影响见[绩点到底是怎么算的](/academics/gpa/)。

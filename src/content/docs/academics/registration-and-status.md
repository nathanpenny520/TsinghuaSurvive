学籍相关的事，绝大多数都是**流程问题**：知道找谁、什么时间办、材料带什么，就能办成；不知道，就会卡在「差一份证明」上，甚至卡到红线上去。这一页把最常遇到的几件事整理成查询表，**先看表，再看对应小节**。

:::note[事实来源与时效]
本文的制度细节来自《清华大学学生手册（2024）》（其中《清华大学本科生学籍管理规定》2019～2020 学年度第 30 次校务会议修订）与《清华大学本科生学习指南（2023）》（教务处，2023 年 8 月），由教务处发布。**规则会随年份调整**，办事前请以你所在院系和教务处的当年通知为准。
:::

## 先给结论：三句话

1. **每学期开学前要注册，秋季学期先交学费再注册。** 未请假、或请假未获批准，逾期超过 2 周未注册，视为放弃学籍，**予以退学处理**。
2. **退学处理有八种情形，最容易被忽略的一种是：考核不合格的必修和限选课程学分累计达到 20 学分。** 详见下文第四节。
3. **休学时间不计入学习年限，但累计休学原则上不超过两年。** 休学要在学期第 14 周之前办。

## 一、一张总表：遇到事先查这里

| 事项 | 触发条件 | 找谁/去哪办 | 常见坑 |
| --- | --- | --- | --- |
| 学期注册 | 每学期开学前 | 自助服务终端（紫荆 C 楼 102、六教 A 座 0 层入口处），或注册中心（紫荆 C 楼 201）人工办理 | 不得让他人代为注册；发现代注册会取消注册信息并严肃处理 |
| 交学费 | 秋季学期开学前 | 信息门户—综合—财务—网上交费，或学号关联的中国银行账户代扣 | 银行代扣后账户余额必须 ≥ 1 元；代扣期间网上缴费会暂时关闭 |
| 不能按期注册 | 开学前预计赶不上 | 先向所在院系请假，办暂缓注册 | 请假未获批准同样算「未请假」，逾期 2 周就是退学处理 |
| 提前毕业 | 已修满毕业所需学分 | 一般应提前 6 个月提出申请 | 申请表格在教学门户「办事流程与表格/学生相关/学籍学位」下载 |
| 延长学习年限 | 正常学制内达不到毕业要求 | 正常毕业年份春季学期**第 10 周之前**书面申请 | 不得以辅修学位相关事由申请延长 |
| 休学 | 疾病、心理压力、入伍、创业等 | 教学门户下载《学生休学申请表》，院系审核后交教务处学籍管理办公室（李兆基大楼 B329-1） | 需在第 14 周之前办理；第 2 周之后办，该学期已缴学费不退 |
| 复学 | 休学期满 | 拟复学学期开学前或开学两周内向院系提交《休学生复学申请表》+ 休学证明 | 学期第三周起不能再办复学 |
| 转专业 | 大一或大二，春季学期 | 关注教务公告，按院系接收计划和考核方案报名 | 每个院系大一转入/转出均不超过该年级总人数的 15%，大二不超过 10% |
| 专业确认 | 大类招生新生，大一春季学期 | 学校大类专业确认管理信息系统 | 本大类内**所有专业都要填**并排序 |
| 成绩单 | 需要中英文成绩单 | 自助终端打印，或紫荆 C 楼 201 人工办理 | 办理前先上网核对英文姓名与专业信息 |
| 在学证明 | 办出入境证件、贷款等 | 紫荆 C 楼 201（注册中心） | **必须本人办，不能委托代办**；休学期间不予办理 |
| 学生证补领 | 遗失或损坏 | 先到院系教学主管部门挂失并写书面检查 | 补领后停止享受乘车半价优待一学期；在校期间一般限补一次 |

## 二、学期注册：时间、方式与后果

学生应当于春季、秋季学期开学前，按学校规定的时间办理注册手续。**缴纳学费后方能注册**（2023 年版本写的是「缴纳学费后方能注册」，2024 年版本写的是「秋季学期缴纳学费后方能注册」——春季学期是否需缴费，以当年注册通知为准）。

### 怎么注册

注册时由**学生本人**携带学生 IC 卡，在自助服务终端机上（紫荆 C 楼 102、六教 A 座 0 层入口处）自助注册，或前往注册中心（紫荆 C 楼 201）人工注册。**不得让他人代为注册**；如发现代注册，会取消其注册信息并进行严肃处理。

注册成功后，可在教学门户的学籍页面下载**二维码注册标签**，自行粘贴在纸质学生证上。这个标签是购买火车票的重要凭证，建议及时下载打印。

休学复学的学生，要在院系和教务处学籍管理办公室办完复学手续之后才能注册。

:::danger[不注册的后果]
因故不能如期注册的，应当向所在院系请假、履行暂缓注册手续。**未请假或者请假未获得批准，逾期超过 2 周未注册的**，除因不可抗力等正当事由以外，**视为放弃学籍，予以退学处理**。
:::

### 学费怎么交

- 中国大陆和港澳台本科生：每学年**秋季学期开学前**缴纳本学年学费，春季学期无需缴纳。
- 国际本科生：秋季学期开学前、春季学期开学前各缴一次本学期学费。
- 缴费方式两种：**银行代扣**（学校通过学号关联的中国银行账户扣款，扣款后余额须 ≥ 1 元）与**网上缴费**（信息门户—综合—财务—网上交费，支持支付宝、微信、银联）。

具体时间和要求见信息门户的教务公告注册通知。2023 年口径下的学费标准是：中国大陆和港澳台本科生中美院（史论专业除外）10000 元/年、其余专业 5000 元/年；国际本科生按理工、经管人文法学、艺术类分档（30000、26000、40000 元/年）。**标准会调整，以当年通知为准**；需要办理临时贷款的同学，请提前到学生处办理相关手续。

## 三、休学与复学：什么时候能休、休多久、怎么回来

### 什么情况应当休学

在学校规定的最长学习年限内，学生可以申请休学、分阶段完成学业。**一学期因病假、事假缺课累计达该学期课程总学时三分之一的，应当休学。** 学生本人申请休学，或者学校认为应当休学的，经批准后休学，学校予以保留学籍。

常见休学原因：身体疾病、心理疾病、心理压力大、入伍、创业或其他个人原因。**休学时间不计入学习年限。**

### 办理流程与材料

1. 从教学门户（办事流程及表格/学生相关/学籍学位/休学相关表格）下载并填写《学生休学申请表》；需要办理休学手工退课的，同时填《清华大学休（退）本科生办理退课申请表》。
2. 材料准备：因病休学要校医院或二级甲等以上医院的诊断证明；入伍休学要学校武装部的同意入伍证明；国际学生回国服兵役休学要附相关证明；其他原因一般无需证明材料。
3. 材料经院系审核同意后，由院系出具《休学通知单》一式两联，其中一联连同退课申请表交教务处学籍管理办公室（李兆基大楼 B329-1），另一联自己留着复学时用。
4. 办理离校手续：经教务处学籍管理办公室审核后拿到《本科生休学离校手续单》，办完交回，休学手续才算完成。

### 时间上的三条硬规则

| 规则 | 具体规定 |
| --- | --- |
| 办理截止 | 休学手续应在春、秋学期**第 14 周之前**办理（含第 14 周） |
| 学费 | 学期**第 2 周之后**办理休学手续的，该学期已缴学费不退 |
| 时长 | 休学时间以学期为单位，累计原则上**不超过两年**；休学创业经学校批准可延长至三年；应征入伍的，保留学籍至退役后两年 |

另外三条常见的：因病休学一年以内可享受公费医疗，其他情况不享受（具体咨询校医院）；填了退课申请表办休学退课的课程不会显示在成绩单上；休学期满还想继续休学的，要重新办理休学手续。

### 复学

休学期满后应办理复学手续。**在拟复学学期开学前或开学两周内**，向所属院系提交《休学生复学申请表》及院系休学时出具的休学证明；因病休学的还要提交校医院或二级甲等以上医院的恢复健康诊断证明，由院系批准后办理复学手续并报教务处备案。**学期第三周起不能办理复学手续。**

复学后编入哪个年级，依你修读课程的情况与院系教学办公室商定：可以编入原专业相应年级，也可以编入低年级。如果培养方案已变化、或需要重修的课程已停开，要在院系教务指导下选课，必要时做课程替代。

:::caution[个人联系境外访学要特别注意]
学生个人联系境外访学，如果返校后不认定境外课程学分，**需要办理休学手续**；如果经院系批准纳入培养方案、返校后认定学分，则按公派境外学习（境外在学）手续办理，**不办休学**——这种情况境外学习时间计入学习年限。相关背景见[境外学习与国际项目](/research/international-programs/)。
:::

## 四、转专业、专业确认：两条不同的路

### 转专业

学生在学习期间对其他专业有兴趣和专长的，可以在**一年级或者二年级**时按学校有关规定申请转专业。实行大类招生和大类培养后，**大一新生转专业工作融入大类专业确认过程**。学校**每学年组织一次**，统一安排在**春季学期**。

| 你不能转的情况 | 说明 |
| --- | --- |
| 以特殊招生形式录取 | 国家有相关规定，或录取前与学校有明确约定 |
| 艺术、体育类学生 | 不得转到普通类专业 |
| 外国语中学推荐保送录取的学生 | 不得转到非外语类专业 |
| 强基计划录取的学生 | 入校后原则上不得转到录取专业之外的专业 |
| 提前批（含定向及单独代码批次）及非强基双学位专业 | 转专业应征得有关部门同意 |
| 临床医学八年制 | 我校八年制专业及协和医学院与我校合作办学的八年制专业，均不再接收非八年制转专业学生 |

**比例限制**：原则上每个院（系）大一年级转入、转出学生人数均不超过该年级（专业）总人数的 **15%**，大二年级不超过 **10%**。

**工作流程**（春季学期）：

1. 院系制订接收计划和考核方案，教务处审核院系计划；
2. 学生转专业咨询、报名（关注教务公告）；
3. 院系考核、初步录取；
4. 教务处审核并统一公布录取名单（学校会统一公示拟接收名单）；
5. 学籍变更；
6. 学生进行转专业课程认定网上申请，院系对转入前所修课程进行认定或替代；
7. 学生进行课程预选、正选。

转专业学生要达到**转入专业**培养方案的要求才能取得毕业资格；因转专业需要延长学习时间的，按学校有关规定办理手续。**在获学校批准前，应当照常参加所在院系学习。**

想比较「转专业」和「读辅修/课程证书」两条路，见[辅修学位与课程证书](/academics/minor-and-certificates/)——辅修学位一般是 30 学分量级的要求，和转专业的代价完全不同。

### 专业确认（大类招生）

自 2017 年起，学校全面实施本科大类招生、大类培养和大类管理。除个别大类外，**新生在大一年级春季学期进行专业确认**。

学生通过学校**大类专业确认管理信息系统**，在本大类内填报专业志愿（**本大类内所有专业均应填报**）及排序，并按大类要求提交相关材料。各专业按学校核定的基准数进行确认，确保类内学生均确认到具体专业：先对第一志愿学生考评确认，未达到确认基准数的，再依次从第二志愿及后续志愿学生中确认。此前已进行过一次专业确认的学生，不参加专业确认。

## 五、退学与退学处理：八种情形

学校每学期对学生完成培养方案课程学分的情况、毕业资格和学籍状态进行审查。学生有下列情形之一的，**予以退学处理**：

| # | 情形 | 说明 |
| --- | --- | --- |
| 一 | **在学期间考核不合格的必修和限选课程（综合论文训练、已重新学习且考核合格的课程除外）学分累计达到 20 学分** | 这是最容易在不知不觉中触线的一条 |
| 二 | 连续两个学期（春季、秋季）每学期所取得学分少于 6 学分 | 注意是「连续两个学期」，不是累计 |
| 三 | 在规定的学习年限内未达到毕业或者结业要求 | 与最长学习年限（学制 + 两年）相关 |
| 四 | 根据学校指定医院诊断，患有疾病或者意外伤残不能继续在校学习 | — |
| 五 | 保留学籍期满，在学校规定期限内未提出复学申请，或申请复学经复查不合格 | 与休学复学直接挂钩 |
| 六 | 未经批准连续 2 周未参加教学计划规定的活动，或未经批准连续离校达 2 周 | 请假制度没走完就会踩到 |
| 七 | 未经批准逾期超过 2 周未注册 | 即上文注册一节的红线 |
| 八 | 在学期间出境，未经批准逾期超过 2 周未返校报到 | 出境前后都要和院系保持联系 |

关于第一条，两点需要知道：

- **只算必修和限选课**。任选课、以及综合论文训练不计入这个累计；**已经重新学习（重修）且考核合格的课程也不计入**——也就是说，及格重修之后这门课不再往那个 20 分里加。
- 国际和港澳台学生大一年级考核不合格的课程学分**不计入学籍处理学分**，自大二年级起执行学校统一标准。

:::caution[待核对]
「考核不合格的必修和限选课程学分累计达到 20 学分」这条在《清华大学本科生学习指南（2023）》第十九节与 2024 版《本科生学籍管理规定》第三十九条中的表述完全一致。本文未给出「多少门课、什么课最容易触线」的推算，因为各专业培养方案的学分构成差异很大；**需要评估自己的风险，请直接找院系教务拉一份自己的成绩清单核对**。
:::

### 处理程序与你有的权利

教务处审核退学学生名单，提交教务处处务会议讨论，向学生下达**拟退学处理告知书**，学生可以提出书面或口头陈述、申辩；学校法律事务部门进行合法性审查；由**校务会议**研究决定，学校下达退学处理决定书，学生办理退学离校手续。

退学处理决定书由教务处组织直接送达学生本人（有监护人的送达监护人）。对退学、取消学籍或取消入学资格处理决定有异议的，可以按学生申诉处理相关规定向**学生申诉处理委员会**提出书面申诉（指南给出的时限是接到决定书之日起十日内，申诉的完整程序见[考场纪律、处分与申诉](/academics/discipline-and-appeals/)）。

### 申请退学 vs 退学处理

自己申请退学：从教学门户「办事流程及表格/学生相关/学籍学位」下载并填写《清华大学本科生退学审批表》（需退课的同时填退课申请表），经院系审批后交教务处学籍管理办公室（李兆基大楼 B329-1），经主管校领导审批后办理后续手续，办完退学手续后学校发给**退学证明**；在校学满一学期的，发给**肄业证书**。

退学学生应当在学校批准后 **2 周内**办理退学手续离校；无故超过规定期限 2 周不办理的，学校予以注销学籍，不再出具任何证明。退学学生五年内重新参加入学考试、符合录取条件再次入学的，在校期间所修课程及已获得学分经院系认定后予以承认。

## 六、毕业、结业与补行毕业

| 情形 | 结果 | 之后能做什么 |
| --- | --- | --- |
| 在学习年限内修完培养方案规定内容，成绩合格，各方面达到毕业要求 | 准予毕业，发**本科毕业证书** | 符合学士学位授予条件的，颁发学士学位证书（双学士学位、辅修学士学位在证书中注明） |
| 修完培养方案内容，但因**个别课程或实践训练环节考核不合格**未达到毕业要求 | 准予**结业**，发给本科结业证书 | 结业学生应及时办理离校手续 |
| 结业后，在最长学习年限内以旁听方式修读不合格的课程或参加实践训练环节，考核合格并达到毕业要求 | **以结业证书换发毕业证书** | 同时符合学士学位授予条件的，发给学位证书 |

学制口径：本科四年学制（建筑学、雕塑五年，临床医学八年），**最长学习年限为所在专业学制加两年**，休学时间不计入学习年限，因创业等原因休学经学校批准可在加两年的基础上顺延相应时间。超过最长学习年限的，不予注册。

选课这件事，大部分人的问题不是"选哪门课好"，而是**根本没搞清规则就去抢课**。先把下面这套流程走一遍，再谈攻略。

这一页分两层：**2026 年的选课流程与规则**（轮次、学分上限、P/F、退课留痕，都标了年份）和**怎么判断一门课值不值得选**（问法、渠道、约束顺序）。**成绩构成与逐门课的投入强度仍然不写**——那是课程层面的事，每年每门课都不一样，只能靠你自己问。

## 第一步：把培养方案读成一张表

培养方案长得像一份政府文件，但真正对你有用的只有四个数字：

| 你要找的 | 它决定什么 |
| --- | --- |
| **总学分要求** | 毕业的硬门槛 |
| **各类课程的学分下限** | 必修、限选、任选、通识、实践各要修多少 |
| **课程清单与先修关系** | 哪些课必须先上，否则后面选不了 |
| **建议修读学期** | 学校建议你什么时候上，别和大三的专业课挤在一起 |

:::tip
**别用眼睛读，用表格读**。新建一个表格：左边列课程，右边列学分、类别、建议学期、是否已修。每学期填一次，缺口一眼就能看到。

不想从零建这张表的话，用站内的[学分缺口拆解表](/academics/credit-planner/)：类别、学分下限、已修、缺口自动算，数据只存你自己的浏览器。你也可以在[资料与工具](/guides/resources/)里看还有哪些能直接在站上用的东西。
:::

**为什么这一步不能省**：每学期都有人到毕业前才发现"限选课还差几个学分"或者"实践环节没修"，那时候补救的空间非常小。

## 第二步：搞清选课的规则

选课系统一般分几轮，不同轮次能做的事不一样。**你要搞清的不是"怎么抢"，而是这三个问题**：

1. **这次选课我能不能选这门课**（年级、专业、先修限制）
2. **选不上怎么办**（补选、旁听、下一年再修、换一门替代课）
3. **选上了能不能退、什么时候退不扣分**（这个和绩点直接相关）

:::caution
轮次安排与开放时间**每年都在变**，下面写的是 **2026 年**的规则形状。换一年请以教务处和院系当学期发布的通知为准。
:::

### 选课界面：五个页面，志愿选课法

清华本科生选课采用**志愿选课法**，界面按培养方案分成五个页面：**必修课、限选课、任选课**（这三个来自培养方案）+ **体育课、重修课**（单独设）。

- 必修课、限选课页面里，直接列出你当学期教学计划中开设的课程；
- 任选课、体育课页面提供多种查询条件，可以做模糊查询；
- 重修课页面只列出你**尚不及格、且当学期有开课**的课程。

选课时**先对着培养方案确认各类课程的学分要求**，再考虑兴趣。只顾兴趣、忽略培养方案，代价可能是延迟毕业或错失推研机会。

### 2026 年的四个阶段

| 阶段 | 能做什么 | 关键机制 |
| --- | --- | --- |
| **① 选课报名（预选）** | 填报志愿选课，**报名人数不受课容量限制** | 报名超过容量就**抽签**；没抽中的按抽签级别进入该课 **WaitingList**，同级别内随机排序。正选或补退选第一阶段出现余量时，**按 WaitingList 队列顺序自动递补** |
| **② 选课调整** | 正选 → 补退选（第一阶段）→ 补退选（第二阶段） | **正选在正式开课前**。正选与补退选一：容量内**先选先得**，选满后进入 WaitingList（也可以主动退出）；**本科生体育课不执行 WaitingList** |
| **③ 选择课程以 P/F 记载** | 在当学期**课程属性为「任选」**的已选课程中，选**一门**记为 P（通过）/ F（不通过），**不计绩点** | 网选结束后**不可更改** |
| **④ 退课** | **只能退，不能选** | 所退课程在成绩单上记 **W**；**后八周开课的课程退课不记 W** |

**补退选第二阶段和第一阶段不一样**，这是最容易记错的地方：

- 体育课**不可选、也不可删**；
- 其他课程可以选，但**只允许删除已选课程**，删掉的课不记入成绩单；
- 各课程的 WaitingList **在这个阶段取消**。还想选课的话，要走**网上申请特殊原因补选**。

**退课阶段的差别**：

- **退课第一阶段**：除了本科生体育课、北外课程，其他课程都能退；
- **退课第二阶段**：只允许**后八周开课的课程**（第 9 周及以后开始上课的）退课，另外允许本科生「**综合论文训练**」退课；其他课程以及北大、北外课程都不能退。

:::caution[学分上限：一年级 26 分，二三年级 30 分]
本科生**一年级至三年级**每学期的选课学分实行**上限控制**，学生要在限制范围内选课：

| 年级 | 每学期选课学分上限 |
| --- | --- |
| 本科一年级 | **26 分** |
| 本科二、三年级 | **30 分** |
| 四年级及以上 | 没有限制 |

有特殊原因需要超过限制的，走**网上申请特批学分**，经所在院系审批通过后才能继续选课。**体育课和重修课不计入这个限制。**
:::

:::danger[P/F 用之前先问三件事]
- **每学期只有一门**，而且只对「课程属性为任选」的课有效。注意**课程属性和选课属性不是一回事**：没列入当学期教学计划的必修、限选课，选课属性会显示为任选，但课程属性仍是你培养方案里的必修或限选。
- **网选一结束就不能改了**。而且如果把这门已选 P/F 的课退掉，**本学期的 P/F 选择权直接作废**。
- **多学期课程**按结课学期选：春、秋季学期结课的要在结课学期选，否则会占用两个学期的选择权；夏季学期结课的要在春季学期选。
- **想申请辅修的先问双院系**：辅修课程能不能选成 P/F，必须两边都确认。
:::

**成绩查询**：每学期结束后成绩查询系统定时开放，在信息门户的「全部成绩」里看。

### 选课系统操作层面的坑

下面全是**要你去核实的类别**，不是规则本身。系统层面的坑有个共同点：它们和技术无关，全是"你没确认"造成的。

| 要确认的类别 | 具体确认什么 | 为什么容易出事 |
| --- | --- | --- |
| **轮次与开放范围** | 这门课在第几轮开放？哪些年级、哪些院系能选？ | 同一门课在不同轮次的可选人群可能不同；选不上不一定是手速问题，可能是这一轮根本没对你开放 |
| **志愿、抽签与先到先得** | 这一轮是填志愿后统一分配，还是按提交时间先到先得？ | 机制不同，策略完全不同。志愿制下卡点刷新没有意义，先到先得制下提前查好课程号才是关键 |
| **退课窗口与"留痕"** | 退课窗口开到什么时候？退了是彻底不留记录，还是会体现成绩单、排名或评优里？ | 2026 年的规则是退课记 **W**，后八周开课（第 9 周起）的课程退课不记 W——但**哪些课在哪个阶段能退**每年可能调整，仍以当年通知为准 |
| **选上了但没去上** | 不去上课、不交作业、不参加考核，分别会发生什么？ | 一般不会自动消失。必修课通常有出勤与考核要求，选修课也可能占着名额耗到学期末 |
| **同一门课的层次差别** | 同名课程有没有不同层次或不同代码？学分是否相同？你该修的是哪一个？ | 层次选错，可能不算你培养方案里那一类学分，事后调整的空间很小 |
| **跨院系、替代与免修** | 这三件事分别走什么申请路径？各需要谁签字、什么时候提交？ | 它们是三条不同的流程，不是"跟老师说一声"。均以当年通知为准，越早问越好 |

:::tip
把这张表当成**开选前的一次性 checklist**。其中任何一条，只要你在系统里点确认之前答不上来，就先别点——抢课的代价远小于选错课的代价。
:::

## 第三步：选课的优先级怎么排

按这个顺序决定，比"哪门给分高"理性得多：

1. **必修课先锁死**。必修课基本没有替代方案，冲突了就是延毕风险。
2. **检查先修链**。如果 A 是 B 的先修，而 B 是大三必修，那你大二必须把 A 修掉。
3. **把"建议学期"当成默认答案**。学校排的建议学期考虑了课程难度和你的承受能力，乱改容易自己给自己上强度。
4. **剩下的名额再考虑兴趣和给分确定性**。这才是真正的"攻略"环节。

## 第四步：信息从哪来

选课之前，值得花两天收集信息：

- **课程大纲**。教学门户/网络学堂上通常能找到，看考核方式（考试？大作业？还是论文）和成绩构成。
- **上过这门课的人**。问比你高一两届的学长学姐，一个问题就够：「这课一学期大概要花多少时间，考核是什么形式？」
- **课程评价**。学校有官方的评教数据，也有学生自发的评价渠道。**注意样本偏差**——抱怨的人更愿意发言。

:::tip
判断一门课适不适合你，看**三个东西**就够了：考核形式、每周平均投入时间、给分逻辑的确定性。名字取得再好听、介绍写得再漂亮，都不如这三点。
:::

按课程类别细拆的判断指标，见[各类课程怎么选](/academics/course-types/)；公开资料库清单见[校内常用链接](/guides/links/)。

## 二十分钟摸清一门课

你已经有一张候选课清单了。现在的问题不是"要不要选"，而是**关于这门课，你手上还剩多少「我不知道」**。

二十分钟足够消掉大部分。方法是照着下面这张表问，问完把答案直接填进你的候选表。顺序建议从上往下——成绩构成决定要不要继续问，投入曲线决定它和你这学期配不配。

这张表的产出正好是[选课决策工作台](/academics/course-decision/)要你填的那几栏：投入曲线、成绩构成、先修是否已修。问完顺手填进去，它才会给出有用的提示。

| 要问什么 | 答案长什么样算清楚 | 去哪问 |
| --- | --- | --- |
| **成绩构成**：平时分、期中、期末、论文、项目各占什么环节 | 你能说出"哪几个环节要交东西、各占什么位置、哪个环节最重"，而不是只知道"有期末考试" | 课程大纲的"考核方式/成绩评定"栏、第一节课的说明、任课教师或助教 |
| **投入曲线**：是每周稳定，还是压在某几周 | 你能标出"每周大约几小时"以及"哪几周会突然变重"。只答得出总时长，不算清楚 | 上过这门课的直系学长学姐、助教 |
| **先修与前置工具** | 先修课你修没修、以什么成绩修过；以及这门课默认你会用什么工具或环境（某门语言、某个软件、某种数学基础） | 培养方案里的先修关系、课程大纲的前置说明、开课院系教务 |
| **考核时间点会不会撞车** | 期中、期末、答辩、大作业提交的大致周次，以及和你另外几门候选课是否压在同一段 | 课程大纲、任课教师、同专业上过的人 |
| **有没有强制的小组、展示、实验环节** | 是小组合还是个人，有没有必须到场的展示/实验/讨论课 | 课程大纲、第一节课的说明、上过的人 |
| **教材与参考书**：自编还是统编 | 你需要买什么、能不能拿到讲义、考试内容和教材绑得紧不紧 | 课程大纲的书目栏、开课院系、学长学姐手上的旧资料 |

:::note[「我不知道」是一个有效答案]
问了一圈，某一格还是"不知道"，**不要用猜的把表填满**。把它标出来，它本身就是信息：

- 这门课的开课安排还没定下来（换老师、改大纲、教室未定都会导致这种回答）；
- 或者这门课本来就有弹性，不同人给你的答案不一样。

这两种情况都值得你在开课后、退课窗口关闭前**再问一次**。真正危险的不是空着的那一格，而是你用一个想当然的数字把它填上了。
:::

## 该问谁：五个渠道的分工

信息渠道不是越多越好，是**分工要对**。同一个问题问错人，得到的不是空白，而是错误的确定性。

| 渠道 | 能回答什么 | 不能可靠回答什么 |
| --- | --- | --- |
| **教务与院系教务** | 培养方案的解读、课程类别与学分归类、选课限制、免修/替代/跨院系的申请路径与流程 | 某门课的实际投入有多大、平时分怎么给——他们不参与具体考核，给不了这一层 |
| **任课教师与助教** | 考核构成、时间点、教材、先修要求、作业与展示的具体形式 | 「给分好不好」这类对课程整体难度的判断；他们对自己的课有立场，说"不难"是常态 |
| **直系学长学姐** | 真实的每周投入区间、往年的大致节奏、哪些周最挤、小组环节怎么分工 | 今年的规则（换开课老师、改大纲后整体失效）；一个人的经历不等于普遍情况，至少问两三个 |
| **课程大纲与开课通知** | 考核方式、成绩评定、教材、学时、开课对象——书面且权威 | 实际执行强度。"计划"和"真实"常有落差，大纲说"论文"但可能要求每两周交一次阶段稿 |
| **公开资料库** | 课程笔记、往年题、复习资料、技能指引——能低成本拿到 | 时效性（多数基于往年）、口径（学生维护，不代表学校）、以及只反映愿意分享的那部分人 |

:::tip
判断一个渠道靠不靠谱，看它**错了以后你要付什么代价**。教务给你的规则解释错了，你可能会选错类别；学长给你的印象错了，你顶多这学期忙一点。规则类的问题只认官方渠道。
:::

## 把课表当成约束问题

排课表最常见的失败方式是：**把所有东西都当成可以商量的**。于是花了大量时间纠结"这门课值不值得"，却漏掉了"这两门课时间冲突"这种一票否决的事。

先把约束分成两类，再按顺序解。

### 硬约束：没有替代方案，只能满足或放弃

| 硬约束 | 为什么硬 | 卡住了怎么办 |
| --- | --- | --- |
| **必修课** | 培养方案里指定的课程，通常没有等价替代 | 冲突时优先保必修，让选修移动 |
| **先修链** | 必修课的先后关系是硬的，不能靠加倍努力绕过 | 往前倒推：这门课的先修必须在哪个学期之前修完 |
| **时间与地点冲突** | 课表冲突无法通过努力解决，跨校区赶课同样不行 | 换一门，或者换到另一个开课班次；不要指望"两边跑" |
| **培养方案的类别与学分归类** | 一门课算不算你缺的那一类，是在系统里定死的 | 选课前就得问清类别，事后再改代价很大 |

硬约束值得花最多时间去**核实**，但不值得花时间纠结——它们没有讨价还价的空间。

### 软约束：可以权衡，但要先想清代价

| 软约束 | 权衡的是什么 | 该问自己什么 |
| --- | --- | --- |
| **兴趣** | 喜欢能降低你的实际投入感，但兴趣会变 | 我是对这门课的内容感兴趣，还是只对课名感兴趣？ |
| **投入强度** | 它和这学期其他安排能不能共存 | 这门课最挤的那两周，我还同时有别的什么？ |
| **给分逻辑的确定性** | 不是"给分高不高"，而是"你能不能预测它怎么给" | 规则清不清楚、平时分有没有托底，比平均分高低更影响你的决策 |
| **和你的其他安排撞不撞** | 社团、竞赛、实习、语言考试、保研准备 | 我知道这学期什么时候最忙吗？ |

把"给分逻辑的确定性"和"给分高低"分开，是这页最有用的一条。**确定性可以被核实**——有平时分托底、规则写清楚的课，你可以安排；"给分高"只是传闻，换一位开课老师就整体失效。这也是[各类课程怎么选](/academics/course-types/)整篇在讲的事。

### 按这个顺序解

1. **先落硬约束**：把必修、先修链、时间地点冲突的课先固定下来，形成一张"骨架课表"。
2. **再算真实余量**：骨架之外还剩几个时间块、每周还剩多少可支配小时。别按理想状态算，按你上学期实际能做到的算。
3. **最后用软约束排序候选课**：兴趣、投入强度、给分确定性、其他安排，四项里没有哪项天生更重要——但要在填之前定好权重，否则你会在两门课之间反复横跳。
4. **硬约束无解时，改的是别的东西**：换班次、换学期、确认替代或免修流程。**不要用"我努力一点"去解硬约束。**

把硬约束落定、再用软约束排序，做出来的东西就是一张候选课对比表。站内的[选课决策工作台](/academics/course-decision/)能替你算这张表里你自己手算很烦的部分——先修缺口、期末撞车、每周投入是否超过你填的基线——但它不会告诉你任何一门课的真实难度，那部分只能靠上面的问法去问。

## 官方口径：选课管理办法里的规则细节

上面讲的是怎么判断和怎么排，这一节补的是**办法条文层面的细节**——已经写在上面的（学分上限的三个数字、P/F 规则、五类选课端口、四阶段形状）这里不再重复。

来源：《清华大学学生手册（2024）》之《清华大学选课管理办法》《清华大学本科体育课程的有关规定及要求》；《清华大学本科生学习指南（2023）》第五章 选课与退课、第十五章 学生评教与课程咨询。**《学习指南》是 2023 年口径，办法是 2023 年 5 月修订版**，轮次周次每年可能调整，办事前以教务处和注册中心当年通知为准。

### 各阶段的周次与能做的事

| 阶段 | 通常安排在哪一周 | 这一阶段能做什么 | 不能做什么 |
| --- | --- | --- | --- |
| **选课报名（预选）** | 学期第 **13–14 周**（或秋季学期开学初） | 填报志愿报名，报名**不受课容量限制**；系统定时发布各门课的志愿填报统计，可据此调整志愿等级 | 不能即时确认选中；要等抽签 |
| **正选** | 学期第 **14–15 周** | 课容量范围内**先选先得**，选满后实行 WaitingList | — |
| **补退选第一阶段** | 新学期第 **1 周** | 同上：先选先得 + WaitingList | — |
| **补退选第二阶段** | 新学期第 **2 周** | 只能**删除**已选课程，所删课程**不记录在成绩单上** | 不可选课；**本科生体育课不可删** |
| **退课第一阶段** | 通常第 **6 周** | 除本科生体育课、清华-北外互选课程外，其他课程均可退 | 体育课、清华-北外互选课程不能退 |
| **退课第二阶段** | 通常第 **10 周** | 只允许**后八周开课**的课程退课 | 其他课程不能退 |

**预选阶段的志愿统计信息发布时间**：每天 **8:00、12:00、16:00、20:00** 公布一次，预选结束前最后一次发布时间为 **12:00**。

:::tip[新生的第一次预选不太一样]
新生入学后的**第一次预选只设一个志愿等级**（可以视为不用填志愿）。预选结束后，报名超过课容量的课程由系统抽签，抽签结果可以在开学前通过选课界面的**一级课表**查看。
:::

### 志愿填报与抽签的细则

- **本科生**的必修课、限选课、任选课、体育课选课**分别设三个志愿等级**：**第一志愿限报 1 门，第二志愿限报 2 门，第三志愿不限门数**；
- **任选课另设"优先志愿"**：当学生符合课程的选课优先条件时，系统**自动**把志愿调整为优先志愿；
- **除体育课外，每门课程只限填报一次志愿**；体育课允许填报同一门课程的不同课堂，但**每人每学期只能选中一门体育课**；
- 重修课和本科生重补修的体育课**不需要填报志愿**。

**抽签优先级**（除体育课外，按**课程属性 + 志愿等级**，由高到低）：

> 必修第一、二、三志愿 → 限选第一、二、三志愿 → 任选优先志愿 → 任选第一、二、三志愿

**体育课单独抽签**：按学生志愿等级由高至低逐级抽签，**高志愿课程一旦选中，低志愿课程自动作废**。所以体育课的"第三志愿"不是多一个机会，而是放弃前面的志愿之后才轮到。

:::caution[待核对：为什么别人优先级比你高]
上面是**优先级的排序规则**。至于"什么条件才算符合选课优先条件"，原文没有列出具体条件清单，**以当学期选课系统里那门课的说明为准**。
:::

### Waiting List 到底怎么排队

Waiting List（简称 WL）是**在每门课的课堂里建立的候选队列**，不是全站统一的排队池。规则有四条：

1. 课程容量已选满时，学生可以**选择进入**该课堂的 WL 候选，**也可以主动退出**（等于删掉这门候选课）；
2. 课程出现余量时，系统**按该课程 WL 的排队顺序自动递补**选课；
3. **预选没中签的人**，会**按抽签级别顺序**进入该课程的 WL，**同一级别的学生随机排序**——所以预选抽签的级别决定了你在 WL 里的位置；
4. 在正选、补退选第一阶段，学生提交选课时，对课余量为 0 的课程可以进入 WL，**按进入 WL 的时间顺序排在队尾**。

两条例外要记住：**本科生体育课不执行 WL**；**补退选第二阶段各课程的 WL 会取消**，这个阶段之后还想选课只能走特殊原因补选。

### 特殊原因补选课（旧称"手动选课"）

- **适用情形**：确有培养需要，但**因上课时间冲突、不符合选课限制条件**等原因无法正常选课的课程；
- **时间**：通常与**补退选第二阶段同期**安排；
- **流程**：由学生**网上提交补选申请**，经**任课教师和开课院系两级审批**通过后，**直接添加选课**；
- **提交时不受限制**：不受课程容量、选课限制、上课时间冲突等条件制约，都可以提交申请。但**任课教师和开课院系在审批时会考虑这些因素**，并且受课程的**可审批名额**制约——提交不等于能选上；
- **不开放网上补选申请的课程**：本科生体育课、研究生体育课、苏世民书院课程、MBA 课程，以及部分网上不选课的课程；
- **体育课另有一条**：体育课在**补退选第一阶段结束后**，不允许再进行退课及特殊原因选课。

### 另外四条容易踩到的规则

| 规则 | 原文口径 |
| --- | --- |
| **课程停开** | 正选结束后，选课人数**少于 10 人**的本科生课程（研究生课程为少于 5 人）**原则上予以停开**。确有培养需要的，院系可向教务处培养办、研究生院培养办提出申请，经审批同意后由注册中心保留该课程 |
| **二级选课** | 对于含实验、习题、辅导、研讨等教学环节的课程，学生应当**在一级选课中选定课程后，再通过二级选课选择项目或分组**。漏了二级选课等于没有完成这门课的选课 |
| **选课依据** | 本科生应依据**培养方案和教学计划**选课；未通过审核的跨选、非本培养方案课程，不保证计入你缺的那一类学分 |
| **突破学分上限** | 上面已经写过上限的三个数字。《选课管理办法》的表述是"确因特殊情况需突破学分限制的，学生需在网上申请，**经学生所在院系审批通过后**，方可继续选课"；《本科生学习指南（2023）》的表述是"由学生所在**班级的班主任**审批通过"。**审批人到哪一级以你当学期的系统流程为准** |

:::caution[待核对：P/F 的办理时间点]
《本科生学习指南（2023）》写的是"课程修读学期**第六周**在网上进行选择"，注册中心 2026 年的口径是"**网选一结束就不能改**"。本文上面的 P/F 一节用的是 2026 年口径，两处年份不同，**以你当学期系统里的截止时间为准**。
:::

:::note[关于评教数据]
学校对**所有开课教师**组织课堂教学质量学生问卷调查，问卷在系统中**匿名**，统计结果会通过多种途径**定期发布，供学生选课时参考**；学期中还有"课堂教学建议"模块可以随时向授课教师反馈。也就是说，"课程评价"这类信息里，**官方评教结果是可以主动去查的**，不必只依赖学生自发渠道。本文不替评教结果下结论，只说明它存在、可查。
:::

## 常见的坑

:::caution
- **只看课名选课**。「××导论」听起来轻松，实际可能是每周读 100 页文献加期末大论文。
- **把课表排满**。一天 6 节连排、四天满课，第一个月就废了。留白不是浪费。
- **忽略上课地点**。两门课之间隔 20 分钟、地点在校区两端，这是每年都有人干的事。
- **体育课和英语课拖到高年级**。越往后越难排，而且大三大四你要忙保研/考研/申请。
- **不看清考核方式**。所有分数都压在期末考试上的课，风险远高于平时分占相当比例的课。
- **把学分堆到极限**。上限是多少由你和培养方案决定，但"能修满"不等于"扛得住"。绩点崩了的代价比少修两门课大得多。
- **不敢问教务**。选课限制、类别认定、替代与免修流程，这些问题的唯一权威答案在教务，问同学只会得到上年度的版本。
:::

## 一个可执行的节奏

- **选课前两周**：读培养方案，更新你的学分表格。
- **选课前一周**：列出候选课程，用[二十分钟摸清一门课](#二十分钟摸清一门课)那张表逐个过一遍，问到的人不少于两个。
- **选课前两三天**：核实"系统操作层面的坑"那张 checklist；按硬约束排出骨架课表，确定每门课的备选。
- **选课当天**：先锁必修，再填限选，最后用任选填坑。**准备好备选课程**。
- **开学前两周**：去试听。不合适就趁退课窗口退掉，别硬撑一学期；同时把上次没问到的格子补上。
- **学期末**：把实际成绩和你当初的预期对一下，更新表格。这份记录到大四申请时会非常有用。

选课之后的退课窗口、重修代价，见[考试、退课与重修](/academics/exams-and-retake/)；成绩怎么影响后续，见[绩点到底是怎么算的](/academics/gpa/)。不清楚本站的写作与使用边界，先看[使用说明](/start/how-to-use/)和[免责声明](/start/disclaimer/)。
